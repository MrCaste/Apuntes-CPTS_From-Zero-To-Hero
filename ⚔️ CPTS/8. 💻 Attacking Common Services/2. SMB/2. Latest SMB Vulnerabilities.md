
## 1. SMBGhost - CVE-2020-0796

**SMBGhost (CVE-2020-0796)** es una vulnerabilidad crítica que afecta al mecanismo de compresión de **SMBv3.1.1**.

Afecta principalmente a:

- **Windows 10 versión 1903.**
    
- **Windows 10 versión 1909.**
    
- Determinadas versiones de Windows Server equivalentes.
    

La vulnerabilidad permite a un atacante remoto **sin autenticación** conseguir ejecución remota de código (RCE) con privilegios elevados.

**Características principales:**

|Característica|Descripción|
|---|---|
|CVE|CVE-2020-0796|
|Nombre|SMBGhost|
|Protocolo|SMBv3.1.1|
|Puerto|TCP/445|
|Vulnerabilidad|Integer Overflow|
|Componente|Compresión SMB|
|Autenticación|No requerida|
|Impacto|Remote Code Execution (RCE)|
|Privilegios|SYSTEM|

## 2. Funcionamiento de la vulnerabilidad

SMBGhost se produce por un **Integer Overflow** durante el procesamiento de paquetes SMB comprimidos.

El servidor SMB no valida correctamente determinados tamaños de datos recibidos durante el procesamiento de la compresión.

Esto puede provocar una corrupción de memoria que, bajo determinadas condiciones, permite ejecutar código arbitrario.

### Integer Overflow

Un **Integer Overflow** ocurre cuando una operación aritmética produce un resultado que no puede representarse correctamente dentro del rango permitido por un tipo de dato.

Por ejemplo, si una variable utiliza un entero sin signo de 8 bits:

```
Valor máximo: 255

250 + 10 = 260

Resultado almacenado: 4
```

El resultado supera el límite permitido y provoca un desbordamiento.

En SMBGhost, un cálculo incorrecto relacionado con el tamaño de los datos comprimidos puede provocar una gestión insegura de la memoria.

### Proceso del ataque

```
Atacante
   |
   | Paquete SMB comprimido manipulado
   v
Servidor SMB (TCP/445)
   |
   | Procesamiento de datos comprimidos
   v
Integer Overflow
   |
   | Corrupción de memoria
   v
Posible ejecución de código
   |
   v
SYSTEM
```

El ataque se desarrolla de la siguiente manera:

1. El atacante establece comunicación con el servidor SMB.
    
2. Envía un paquete SMB comprimido especialmente manipulado.
    
3. El servidor procesa los datos sin validar correctamente determinados tamaños.
    
4. Se produce un Integer Overflow.
    
5. El error puede provocar corrupción de memoria.
    
6. Si se consigue explotar correctamente, el atacante puede ejecutar código con los privilegios del proceso SMB.
    

**Importante:** el Integer Overflow no garantiza automáticamente RCE. La explotación requiere convertir la corrupción de memoria en ejecución controlada de código.

## 3. Identificación de SMBGhost

### Enumeración SMB

```
nmap -sC -sV -p445 <IP>
```

Debemos comprobar:

- Si el puerto TCP/445 está abierto.
    
- Si el servidor utiliza SMBv3.1.1.
    
- Si el sistema operativo corresponde a una versión vulnerable.
    
- Si la compresión SMB está habilitada.
    

### Comprobar SMBGhost con Nmap

Podemos utilizar un script específico de detección si lo tenemos instalado:

```
nmap -p445 --script smb-vuln-cve-2020-0796 <IP>
```

**Nota:** este script no forma parte necesariamente de la instalación estándar de Nmap. Es necesario disponer de un script compatible.

La identificación de SMBv3.1.1 por sí sola no confirma que el sistema sea vulnerable.

## 4. Conceptos importantes

### SMB Compression

SMBv3.1.1 incorpora mecanismos de compresión que permiten reducir la cantidad de datos transmitidos.

SMBGhost aprovecha un error en el procesamiento de determinados mensajes comprimidos.

### Integer Overflow

Error aritmético que ocurre cuando un resultado supera el rango permitido por el tipo de dato utilizado.

Puede provocar cálculos incorrectos de tamaños y problemas de gestión de memoria.

### Memory Corruption

Se produce cuando un programa modifica o utiliza memoria de forma incorrecta.

En determinadas circunstancias, puede aprovecharse para conseguir ejecución de código.

### Remote Code Execution

Permite ejecutar código en un sistema remoto.

En SMBGhost, una explotación exitosa contra el servidor SMB puede proporcionar ejecución con privilegios de **SYSTEM**.

## 5. Metodología para CPTS / OSCP

### Paso 1. Identificar SMB

```
nmap -sC -sV -p139,445 <IP>
```

### Paso 2. Identificar el sistema operativo

Comprobar si el objetivo utiliza una versión de Windows potencialmente vulnerable.

### Paso 3. Comprobar SMBv3.1.1

Identificar los dialectos SMB soportados por el servidor.

### Paso 4. Buscar CVE-2020-0796

Investigar si el sistema está afectado por SMBGhost y si dispone de los parches correspondientes.

### Paso 5. Validar la vulnerabilidad

Utilizar un método de detección compatible con el objetivo antes de considerar cualquier explotación.

**Precaución:** los exploits que manipulan memoria del kernel pueden provocar fallos del sistema o pantallazos azules (BSOD).

## 7. Puntos clave

- **SMBGhost = CVE-2020-0796.**
    
- Afecta al mecanismo de compresión de **SMBv3.1.1**.
    
- Las versiones vulnerables incluyen Windows 10 **1903 y 1909**.
    
- Se explota a través del puerto **TCP/445**.
    
- No requiere autenticación.
    
- La vulnerabilidad está relacionada con un **Integer Overflow**.
    
- Puede provocar corrupción de memoria y permitir **RCE**.
    
- Una explotación exitosa puede conseguir privilegios **NT AUTHORITY\SYSTEM**.
    
- Debemos comprobar la versión del sistema y su estado de actualización antes de considerarlo vulnerable.
    
- La explotación puede ser inestable y provocar un **BSOD**.
