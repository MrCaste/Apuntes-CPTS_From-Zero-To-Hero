
## 1. ¿Qué son los registros de Certificate Transparency?

Los **Certificate Transparency (CT)** son registros públicos de solo adición (*append-only ledgers*) que almacenan información sobre certificados SSL/TLS emitidos por las autoridades de certificación (CA).

Cuando una CA emite un certificado, este debe registrarse en múltiples registros CT, mantenidos por organizaciones independientes y accesibles públicamente.

### ¿Para qué sirven?

- **Detectar certificados fraudulentos:** identificar certificados sospechosos o emitidos incorrectamente.
- **Responsabilizar a las CA:** permitir la supervisión pública de sus prácticas de emisión.
- **Fortalecer la PKI web:** mejorar la transparencia y la seguridad de los certificados digitales.

## 2. Utilidad durante el reconocimiento web

Los registros CT permiten descubrir subdominios sin necesidad de adivinarlos mediante fuerza bruta.

Pueden revelar:
- Subdominios públicos que aparecen en certificados.
- Subdominios que no conocíamos y que no aparecen en nuestras wordlists.
- Nombres asociados a certificados antiguos o caducados.
- Posibles entornos de desarrollo, pruebas o servicios secundarios.

**Importante:** encontrar un subdominio en CT no significa que siga activo o que sea vulnerable. Es necesario comprobarlo posteriormente.

## 3. Herramientas de búsqueda CT

| Herramienta | Características | Uso principal |
|---|---|---|
| `crt.sh` | Búsqueda pública de certificados y nombres incluidos en ellos. | Enumerar subdominios rápidamente. |
| `Censys` | Motor de búsqueda con filtros avanzados por dominio, IP y atributos de certificados. | Realizar investigaciones más detalladas sobre certificados y hosts. |

### crt.sh

- Gratuito.
- No requiere registro.
- Permite consultar certificados y nombres alternativos asociados.
- Dispone de una API que podemos utilizar desde la terminal.

### Censys

- Permite búsquedas más avanzadas.
- Ofrece datos sobre certificados y dispositivos conectados a Internet.
- Dispone de una API.
- Requiere registro, aunque cuenta con un nivel gratuito.

## 4. Enumeración con crt.sh desde la terminal

Podemos consultar la API de `crt.sh` utilizando `curl` y procesar la respuesta JSON con `jq`.

### Ejemplo: buscar subdominios que contengan `dev`

```bash
curl -s "https://crt.sh/?q=facebook.com&output=json" | jq -r '.[] | select(.name_value | contains("dev")) | .name_value' | sort -u
```

Este comando realiza tres operaciones:

| Comando | Función |
|---|---|
| `curl -s` | Obtiene los resultados de crt.sh en formato JSON sin mostrar el progreso de la transferencia. |
| `jq -r` | Extrae los nombres de dominio del campo `name_value` y muestra las cadenas sin comillas. |
| `select(.name_value \| contains("dev"))` | Filtra las entradas que contienen la cadena `dev`. |
| `sort -u` | Ordena los resultados y elimina los duplicados. |

### Ejemplo de resultados

```text
*.dev.facebook.com
*.newdev.facebook.com
*.secure.dev.facebook.com
dev.facebook.com
devvm1958.ftw3.facebook.com
facebook-amex-dev.facebook.com
facebook-amex-sign-enc-dev.facebook.com
newdev.facebook.com
secure.dev.facebook.com
```

Estos resultados son ejemplos del módulo y muestran cómo pueden aparecer diferentes nombres relacionados con entornos de desarrollo.

## 5. Flujo práctico de reconocimiento

1. Consulta `crt.sh` para obtener nombres asociados a los certificados del dominio.
2. Filtra los resultados por términos interesantes, como `dev`, `test`, `stage` o `admin`.
3. Elimina duplicados con `sort -u`.
4. Comprueba qué nombres siguen resolviendo mediante DNS.
5. Investiga los hosts activos con herramientas de reconocimiento web.

## Cheat Sheet

### Consultar certificados de un dominio

```bash
curl -s "https://crt.sh/?q=inlanefreight.com&output=json"
```

### Extraer los nombres de dominio

```bash
curl -s "https://crt.sh/?q=inlanefreight.com&output=json" | jq -r '.[].name_value' | sort -u
```

### Buscar nombres que contengan `dev`

```bash
curl -s "https://crt.sh/?q=inlanefreight.com&output=json" | jq -r '.[] | select(.name_value | contains("dev")) | .name_value' | sort -u
```

### Conceptos clave para el examen

- **CT:** registros públicos que documentan certificados SSL/TLS emitidos.
- **crt.sh:** herramienta gratuita para consultar certificados y descubrir subdominios.
- **Censys:** permite búsquedas avanzadas sobre certificados y hosts.
- **`name_value`:** campo de la respuesta JSON que contiene los nombres asociados a los certificados.
- **`jq`:** permite filtrar y extraer información del JSON.
- **`sort -u`:** ordena los resultados y elimina duplicados.
- **Diferencia respecto al brute force:** CT utiliza información de certificados registrados, mientras que la fuerza bruta prueba nombres potenciales mediante una wordlist.

**Idea clave:** utiliza los registros CT como fuente pasiva de nombres de dominio y subdominios. Después, verifica cuáles siguen activos antes de continuar la enumeración.
