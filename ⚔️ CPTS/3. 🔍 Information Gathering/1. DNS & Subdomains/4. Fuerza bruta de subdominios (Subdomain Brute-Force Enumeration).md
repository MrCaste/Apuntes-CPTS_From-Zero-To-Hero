
## 1. ¿Qué es la fuerza bruta de subdominios?

Es una técnica de **enumeración activa** que utiliza una lista de posibles nombres para descubrir subdominios asociados a un dominio principal.

Ejemplo, para `example.com`:

```
dev.example.com
staging.example.com
admin.example.com
mail.example.com
api.example.com
```

La herramienta combina cada palabra de una _wordlist_ con el dominio y consulta DNS para comprobar si el nombre existe.

## 2. Proceso de enumeración

1. **Seleccionar una wordlist:** puede ser general, específica para una tecnología o personalizada.
    
2. **Generar nombres:** combinar cada palabra con el dominio objetivo.
    
3. **Consultar DNS:** comprobar si los nombres resuelven, normalmente mediante registros `A` o `AAAA`.
    
4. **Filtrar resultados:** guardar los subdominios encontrados.
    
5. **Validar los resultados:** comprobar si los nombres descubiertos corresponden a servicios accesibles.
    

### Tipos de wordlists

|Tipo|Características|
|---|---|
|General|Contiene nombres comunes como `dev`, `admin`, `mail` o `test`.|
|Dirigida|Se centra en una industria, tecnología o patrón de nombres.|
|Personalizada|Se crea a partir de palabras clave e información recopilada previamente.|

Una lista adecuada puede mejorar la eficiencia y reducir falsos positivos.

## 4. DNSenum

`dnsenum` es una herramienta de línea de comandos escrita en Perl que automatiza diferentes tareas de reconocimiento DNS.

### Funcionalidades principales

- **Enumeración de registros:** consulta registros `A`, `AAAA`, `NS`, `MX` y `TXT`.
    
- **Transferencias de zona:** intenta obtener información de los servidores DNS cuando lo permiten.
    
- **Fuerza bruta:** prueba nombres de subdominios mediante una wordlist.
    
- **Scraping de Google:** recopila información de resultados de búsqueda.
    
- **Búsquedas inversas:** intenta identificar nombres asociados a direcciones IP.
    
- **Consultas WHOIS:** recopila información sobre el registro y la propiedad de un dominio.
    

### Comando básico

```
dnsenum --enum inlanefreight.com
```

Ejecuta la enumeración del dominio utilizando las opciones asociadas a `--enum`.

### Fuerza bruta con SecLists

```
dnsenum --enum inlanefreight.com \
-f /usr/share/seclists/Discovery/DNS/subdomains-top1million-20000.txt
```

**Parámetros:**

|Parámetro|Función|
|---|---|
|`--enum`|Activa las opciones de enumeración asociadas a este modo.|
|`-f`|Especifica la ruta de la wordlist.|

La lista `subdomains-top1million-20000.txt` contiene los 20.000 subdominios más comunes, según la descripción del módulo.

### Fuerza bruta recursiva

```
dnsenum --enum inlanefreight.com \
-f /usr/share/seclists/Discovery/DNS/subdomains-top1million-20000.txt \
-r
```

El parámetro `-r` habilita la enumeración recursiva: si se encuentra un subdominio, la herramienta intenta buscar otros subdominios asociados a él.

### Ejemplo de resultados

```
Host's addresses:
inlanefreight.com.       300    IN    A    134.209.24.248

Brute forcing with /usr/share/seclists/Discovery/DNS/subdomains-top1million-20000.txt:

www.inlanefreight.com.       300    IN    A    134.209.24.248
support.inlanefreight.com.   300    IN    A    134.209.24.248
```

En este ejemplo se identifican los subdominios:

- `www.inlanefreight.com`
    
- `support.inlanefreight.com`
    

Ambos resuelven a la misma dirección IPv4 que el dominio principal. Esto **no significa necesariamente que sean el mismo servicio**, ya que un servidor puede alojar múltiples sitios web.

## 5. Metodología práctica

### Paso 1. Comprobar la herramienta y la wordlist

```
which dnsenum
ls -l /usr/share/seclists/Discovery/DNS/subdomains-top1million-20000.txt
```

Si la ruta no existe, comprueba dónde está instalada SecLists y adapta el comando.

### Paso 2. Enumerar el dominio

```
dnsenum --enum dominio.com \
-f /usr/share/seclists/Discovery/DNS/subdomains-top1million-20000.txt
```

### Paso 3. Ampliar la búsqueda con recursividad

```
dnsenum --enum dominio.com \
-f /usr/share/seclists/Discovery/DNS/subdomains-top1million-20000.txt \
-r
```

### Paso 4. Analizar los resultados

Para cada subdominio encontrado:

1. Registra su nombre.
    
2. Anota las direcciones IP obtenidas.
    
3. Identifica posibles servicios asociados.
    
4. Comprueba si el subdominio es accesible.
    
5. Investiga las aplicaciones que aloja.
    

Realiza estas pruebas únicamente contra objetivos para los que tengas autorización.

|Técnica utilizada|Fuerza bruta DNS|
|Registros habituales|`A` y `AAAA`|
|Resultado esperado|Nombres de subdominios que resuelven mediante DNS|

**Idea clave:** la fuerza bruta de subdominios combina nombres de una wordlist con un dominio principal y comprueba cuáles resuelven. `dnsenum` automatiza este proceso y también permite recopilar registros DNS y realizar otras tareas de reconocimiento.
