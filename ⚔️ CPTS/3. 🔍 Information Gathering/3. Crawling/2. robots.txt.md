
## 1. ¿Qué es robots.txt?

`robots.txt` es un archivo de texto ubicado normalmente en la raíz de un sitio web. Sigue el **Estándar de Exclusión de Robots** y contiene instrucciones que indican a los rastreadores web qué partes del sitio pueden o no deben rastrear.

Ruta habitual:

```
https://example.com/robots.txt
```

**Importante:** `robots.txt` no es un mecanismo de autenticación ni de control de acceso. Los bots pueden ignorar sus directivas y las rutas indicadas pueden seguir siendo accesibles directamente.

## 2. Estructura de robots.txt

El archivo utiliza directivas agrupadas según el agente de usuario (_User-agent_).

Ejemplo:

```
User-agent: *
Disallow: /private/
```

- `User-agent`: identifica el rastreador al que se aplican las reglas.
    
- `*`: comodín que representa a todos los agentes de usuario.
    
- `Disallow`: indica las rutas que el rastreador no debe recorrer.
    

Cada grupo de instrucciones puede separarse mediante una línea en blanco.

## 3. Directivas principales

|Directiva|Función|Ejemplo|
|---|---|---|
|`User-agent`|Especifica a qué bot se aplican las reglas.|`User-agent: Googlebot`|
|`Disallow`|Indica las rutas que no deben rastrearse.|`Disallow: /admin/`|
|`Allow`|Permite rastrear determinadas rutas.|`Allow: /public/`|
|`Crawl-delay`|Solicita un intervalo entre solicitudes sucesivas del bot.|`Crawl-delay: 10`|
|`Sitemap`|Indica la ubicación del mapa del sitio.|`Sitemap: https://example.com/sitemap.xml`|

El comportamiento exacto de algunas directivas depende del rastreador que las interprete.

## 4. ¿Por qué es importante para el reconocimiento web?

Analizar `robots.txt` permite obtener información sobre la estructura del sitio y descubrir rutas interesantes.

### Descubrir directorios

Las rutas incluidas en `Disallow` pueden revelar secciones que no aparecen en la navegación habitual.

Ejemplos:

```
Disallow: /admin/
Disallow: /private/
Disallow: /backup/
```

Estas rutas pueden justificar una investigación adicional, pero **no demuestran por sí mismas que existan ni que sean accesibles**.

### Mapear la estructura del sitio

Las directivas pueden revelar:

- Paneles de administración.
    
- Directorios privados.
    
- Secciones no enlazadas desde la página principal.
    
- Rutas que el propietario no quiere que los buscadores rastreen.
    

### Identificar posibles honeypots

Algunos sitios incluyen rutas destinadas a atraer bots maliciosos. Estas rutas pueden funcionar como _honeypots_ para detectar actividad sospechosa.

## 5. Ejemplo práctico

Contenido de un archivo `robots.txt`:

```
User-agent: *
Disallow: /admin/
Disallow: /private/
Allow: /public/

User-agent: Googlebot
Crawl-delay: 10

Sitemap: https://www.example.com/sitemap.xml
```

### Interpretación

1. **Todos los bots:** las reglas generales indican que no deben rastrear `/admin/` ni `/private/`.
    
2. **Ruta pública:** `/public/` aparece como una ruta permitida.
    
3. **Googlebot:** se le indica un retraso de 10 segundos entre solicitudes.
    
4. **Sitemap:** se proporciona la ubicación del mapa del sitio XML.
    

Las rutas `/admin/` y `/private/` son puntos de partida para investigar la estructura del sitio, pero su presencia no confirma que existan recursos vulnerables.

## 6. Metodología práctica

### Paso 1. Consultar robots.txt

Desde el navegador, visita:

```
https://<DOMINIO>/robots.txt
```

También puedes utilizar `curl`:

```
curl -s https://<DOMINIO>/robots.txt
```

### Paso 2. Identificar rutas interesantes

Busca directivas como:

```
Disallow: /admin/
Disallow: /private/
Disallow: /backup/
```

### Paso 3. Localizar el sitemap

Si aparece una directiva `Sitemap`, consulta la URL indicada para obtener más información sobre la estructura del sitio.

### Paso 4. Verificar los hallazgos

Comprueba las rutas descubiertas de forma autorizada. Recuerda que una ruta mencionada en `robots.txt` puede no existir, estar protegida o haber quedado obsoleta.

## Cheat Sheet

|Objetivo|Comando|
|---|---|
|Consultar robots.txt|`curl -s https://<DOMINIO>/robots.txt`|
|Consultar un sitemap|`curl -s https://<DOMINIO>/sitemap.xml`|
|Buscar rutas administrativas|Revisar las directivas `Disallow`.|
|Identificar el sitemap declarado|Buscar la directiva `Sitemap:`.|
|Identificar reglas para todos los bots|Buscar `User-agent: *`.|

### Conceptos clave para el examen

- `robots.txt` suele encontrarse en la raíz del dominio.
    
- `User-agent` identifica los bots a los que se aplican las reglas.
    
- `Disallow` indica qué rutas no debe rastrear un bot.
    
- `Allow` indica qué rutas puede rastrear.
    
- `Crawl-delay` solicita un intervalo entre peticiones.
    
- `Sitemap` indica la ubicación de un mapa del sitio.
    
- Las rutas indicadas pueden revelar información útil para el reconocimiento.
    
- `**robots.txt**` **no protege los recursos mediante autenticación ni impide el acceso directo.**
    

**Idea clave:** consulta `robots.txt` al principio del reconocimiento web. Puede revelar rutas que merece la pena investigar, aunque siempre debes comprobar si existen y si son accesibles.
