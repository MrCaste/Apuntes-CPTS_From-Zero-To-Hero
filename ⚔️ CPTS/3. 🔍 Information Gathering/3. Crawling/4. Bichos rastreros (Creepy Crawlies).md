
## 1. Herramientas de web crawling

El _web crawling_ automatiza la navegación por un sitio web para recopilar información, descubrir enlaces y mapear su estructura.

|Herramienta|Características|
|---|---|
|**Burp Suite Spider**|Rastrea aplicaciones web, mapea su estructura y descubre contenido.|
|**OWASP ZAP**|Escáner gratuito y de código abierto con funcionalidades de spidering manual y automático.|
|**Scrapy**|Framework de Python para crear rastreadores personalizados y extraer datos estructurados.|
|**Apache Nutch**|Rastreador extensible y escalable, adecuado para proyectos de gran tamaño.|

En esta sección utilizaremos **Scrapy** y el spider personalizado `ReconSpider.py`.

## 2. Instalar Scrapy

Instala Scrapy mediante `pip3`:

```
pip3 install scrapy
```

Esto instala el framework y sus dependencias para poder ejecutar rastreadores web.

## 3. Descargar ReconSpider

Descarga el archivo ZIP que contiene el spider personalizado de HTB:

```
wget -O ReconSpider.zip https://cdn.services-k8s.prod.aws.htb.systems/content/modules/144/ReconSpider.v1.2.zip
```

Extrae su contenido:

```
unzip ReconSpider.zip
```

Una vez extraído, tendrás disponible el script `ReconSpider.py`.

## 4. Ejecutar ReconSpider

Ejecuta el spider indicando la URL del objetivo:

```
python3 ReconSpider.py http://inlanefreight.com
```

Sustituye `inlanefreight.com` por el dominio que quieras analizar dentro del alcance autorizado.

El spider rastreará el sitio y recopilará distintos tipos de información. Los resultados se guardarán en:

```
results.json
```

## 5. Analizar results.json

El archivo `results.json` contiene los datos recopilados durante el rastreo en formato JSON.

Ejemplo de estructura:

```
{
    "emails": [],
    "links": [],
    "external_files": [],
    "js_files": [],
    "form_fields": [],
    "images": [],
    "videos": [],
    "audio": [],
    "comments": []
}
```

### Significado de las claves

|Clave|Información recopilada|
|---|---|
|`emails`|Direcciones de correo electrónico encontradas.|
|`links`|URL de los enlaces descubiertos.|
|`external_files`|URL de archivos, como documentos PDF.|
|`js_files`|URL de archivos JavaScript utilizados por el sitio.|
|`form_fields`|Campos de formularios encontrados.|
|`images`|URL de las imágenes descubiertas.|
|`videos`|URL de vídeos encontrados.|
|`audio`|URL de archivos de audio encontrados.|
|`comments`|Comentarios HTML presentes en el código fuente.|

Que una lista esté vacía no significa necesariamente que el sitio carezca de ese tipo de recurso; simplemente indica que el spider no ha registrado elementos en esa categoría.

## 6. ¿Qué información interesa durante el reconocimiento?

Una vez generado `results.json`, analiza cada categoría para identificar posibles puntos de interés.

- `**emails**`**:** recopila direcciones que pueden ayudar a identificar contactos y usuarios.
    
- `**links**`**:** permite descubrir páginas y ampliar el mapa del sitio.
    
- `**external_files**`**:** identifica documentos que pueden contener información relevante.
    
- `**js_files**`**:** permite localizar scripts que conviene examinar para comprender la funcionalidad de la aplicación.
    
- `**form_fields**`**:** ayuda a identificar formularios y posibles puntos de entrada.
    
- `**comments**`**:** puede revelar anotaciones o información adicional presente en el HTML.
    
- `**images**`**,** `**videos**` **y** `**audio**`**:** permiten identificar los recursos multimedia utilizados.
    

La información recopilada debe analizarse y correlacionarse para decidir qué elementos requieren una investigación adicional.

### Conceptos clave para el examen

- El _web crawling_ automatiza la navegación y recopilación de información de un sitio.
    
- Scrapy permite crear rastreadores personalizados mediante Python.
    
- `ReconSpider.py` es el spider personalizado utilizado en este ejercicio de HTB.
    
- El resultado del rastreo se almacena en `results.json`.
    
- Las categorías principales incluyen correos, enlaces, archivos, JavaScript, formularios, imágenes, vídeos, audio y comentarios HTML.
    
- La utilidad del rastreo depende de analizar los resultados y relacionarlos con otros hallazgos.
    

**Idea clave:** ejecuta `ReconSpider.py`, revisa `results.json` y utiliza los datos recopilados para ampliar el reconocimiento de la aplicación web.
