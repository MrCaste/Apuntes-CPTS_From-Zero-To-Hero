
## 1. Identificar Drupal

Podemos identificar Drupal mediante:

- El código fuente de la página.
    
- El mensaje `Powered by Drupal`.
    
- El archivo `CHANGELOG.txt` o `README.txt`.
    
- El archivo `robots.txt`.
    
- Las rutas `/node/`.
    

### Comprobar el código fuente

```
curl -s http://TARGET/ | grep Drupal
```

Ejemplo de resultado:

```
<meta name="Generator" content="Drupal 8 (https://www.drupal.org)" />
```

### Buscar nodos

Drupal organiza parte de su contenido mediante **nodes** (nodos), que pueden representar artículos, publicaciones u otro contenido.

Ejemplo:

```
http://TARGET/node/1
```

Las rutas `/node/<ID>` pueden ayudar a identificar Drupal incluso cuando utiliza un tema personalizado.

### Revisar robots.txt

```
curl -s http://TARGET/robots.txt
```

Busca rutas o referencias relacionadas con Drupal, como `/node`.

## 2. Identificar la versión

### Método 1: CHANGELOG.txt

```
curl -s http://TARGET/CHANGELOG.txt | head
```

Si el archivo está disponible, puede mostrar la versión instalada.

Ejemplo:

```
Drupal 7.57, 2018-02-21
```

**Importante:** las instalaciones modernas pueden bloquear el acceso a `CHANGELOG.txt` y `README.txt`. Un error 404 no significa que Drupal no esté instalado.

## 3. Enumerar con droopescan

`droopescan` permite analizar Drupal para encontrar versiones posibles, plugins y rutas interesantes.

### Ejecutar un escaneo

```
droopescan scan drupal -u http://TARGET/
```

Puede identificar:

- Plugins o módulos instalados o accesibles.
    
- Posibles versiones de Drupal.
    
- Rutas interesantes.
    
- Página de inicio de sesión.
    

Ejemplo de resultado:

```
[+] Plugins found:
    php http://TARGET/modules/php/

[+] Possible version(s):
    8.9.0
    8.9.1

[+] Possible interesting urls found:
    Default admin - http://TARGET/user/login
```

En este caso, las versiones `8.9.0` y `8.9.1` son posibilidades detectadas, no una confirmación definitiva.

### Instalar droopescan

Si no está instalado, el material propone:

```
sudo pip3 install droopescan
```

## 4. Página de inicio de sesión

La ruta habitual de acceso es:

```
http://TARGET/user/login
```

Drupal contempla tres tipos de usuarios predeterminados:

|Tipo de usuario|Descripción|
|---|---|
|Administrator|Control completo del sitio|
|Authenticated User|Usuario que ha iniciado sesión; sus permisos dependen de la configuración|
|Anonymous|Visitante sin autenticar; normalmente puede leer contenido público|

La página de inicio de sesión puede no estar accesible desde Internet en todas las instalaciones.

## 5. Metodología para el examen

1. **Identificar el CMS:** buscar `Drupal` en el código fuente.
    
2. **Revisar archivos públicos:** comprobar `CHANGELOG.txt`, `README.txt` y `robots.txt`.
    
3. **Buscar nodos:** comprobar rutas como `/node/1`.
    
4. **Escanear con droopescan:** obtener versiones posibles, módulos y rutas.
    
5. **Localizar el login:** probar la ruta `/user/login`.
    
6. **Investigar los resultados:** buscar vulnerabilidades relacionadas con la versión o los módulos identificados.
