
## 1. Identificar ColdFusion

Durante la enumeración, podemos identificar una aplicación ColdFusion mediante:

- **Extensiones:** `.cfm` y `.cfc`.
    
- **Cabeceras HTTP:** `Server: ColdFusion` o `X-Powered-By: ColdFusion`.
    
- **Mensajes de error:** referencias a funciones o etiquetas de ColdFusion.
    
- **Archivos y directorios:** `/CFIDE/`, `/cfdocs/` y `/CFIDE/administrator/`.
    
- **Puertos:** especialmente `80`, `443` y `8500`.
    

### Puertos asociados a ColdFusion

|Puerto|Servicio|
|---|---|
|80|HTTP|
|443|HTTPS|
|1935|RPC|
|25|SMTP|
|8500|SSL (según el material)|
|5500|Server Monitor|

Los puertos pueden variar dependiendo de la configuración.

## 2. Enumeración con Nmap

Escaneamos todos los puertos TCP del objetivo:

```
nmap -p- -sC -Pn 10.129.247.30 --open
```

**Resultado:**

```
PORT      STATE SERVICE
135/tcp   open  msrpc
8500/tcp  open  fmtp
49154/tcp open  unknown
```

El puerto `8500` es especialmente interesante porque está asociado a ColdFusion.

## 3. Enumeración web

Accedemos al servicio:

```
http://10.129.247.30:8500/
```

En la raíz encontramos dos directorios:

```
/CFIDE/
/cfdocs/
```

Estos directorios indican que probablemente estamos ante una instalación de ColdFusion.

### Rutas importantes

|Ruta|Utilidad|
|---|---|
|`/CFIDE/`|Directorio de archivos de ColdFusion.|
|`/cfdocs/`|Documentación de ColdFusion.|
|`/CFIDE/administrator/`|Panel de administración.|
|`/CFIDE/administrator/index.cfm`|Página de inicio de sesión del administrador.|
|`/CFIDE/Application.cfm`|Archivo de aplicación encontrado durante la enumeración.|
|`/CFIDE/install.cfm`|Archivo de instalación.|
|`/CFIDE/adminapi/`|Directorio de API de administración.|

Al explorar `/CFIDE/`, encontramos archivos `.cfm`, directorios administrativos y mensajes de error que permiten identificar la tecnología.

## 4. Identificación de la versión

Accedemos a:

```
http://10.129.247.30:8500/CFIDE/administrator/
```

La página de inicio de sesión identifica la aplicación como:

**Adobe ColdFusion 8**

Esto confirma la versión instalada y permite investigar vulnerabilidades específicas.

## 5. Vulnerabilidades conocidas

El material menciona las siguientes vulnerabilidades de ColdFusion:

|CVE|Vulnerabilidad|
|---|---|
|CVE-2013-0632|Ejecución remota de código (RCE).|
|CVE-2013-0629|Directory Traversal y divulgación de archivos.|
|CVE-2010-2861|Directory Traversal y lectura arbitraria de archivos.|
|CVE-2018-15961|Subida arbitraria de archivos que puede provocar RCE.|
|CVE-2023-26360|RCE sin autenticación previa.|

**Importante:** estas son vulnerabilidades conocidas de ColdFusion en distintas versiones. No significa que todas afecten a ColdFusion 8.

## 6. Checklist de enumeración

1. Escanear los puertos con Nmap.
    
2. Investigar servicios HTTP, HTTPS y el puerto `8500`.
    
3. Buscar directorios como `/CFIDE/` y `/cfdocs/`.
    
4. Identificar archivos `.cfm` y `.cfc`.
    
5. Revisar las cabeceras HTTP y los mensajes de error.
    
6. Localizar el panel `/CFIDE/administrator/`.
    
7. Identificar la versión de ColdFusion.
    
8. Investigar las CVE que afecten específicamente a esa versión.
