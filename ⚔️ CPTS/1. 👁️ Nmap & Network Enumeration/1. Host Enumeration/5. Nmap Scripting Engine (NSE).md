
## 1. ¿Qué es NSE?

El **Nmap Scripting Engine (NSE)** permite ejecutar scripts escritos en Lua para interactuar con servicios, obtener información y detectar posibles vulnerabilidades.

### Categorías principales de scripts

|Categoría|Función|
|---|---|
|`auth`|Determina credenciales de autenticación.|
|`broadcast`|Descubre hosts mediante broadcast.|
|`brute`|Intenta autenticarse mediante fuerza bruta.|
|`default`|Scripts predeterminados ejecutados con `-sC`.|
|`discovery`|Recopila información sobre servicios accesibles.|
|`dos`|Comprueba vulnerabilidades de denegación de servicio; puede afectar al objetivo.|
|`exploit`|Intenta explotar vulnerabilidades conocidas.|
|`external`|Utiliza servicios externos para procesar información.|
|`fuzzer`|Envía datos variados para identificar vulnerabilidades o comportamientos inesperados.|
|`intrusive`|Scripts que pueden afectar negativamente al sistema objetivo.|
|`malware`|Comprueba posibles infecciones por malware.|
|`safe`|Scripts no intrusivos ni destructivos.|
|`version`|Amplía la detección de servicios.|
|`vuln`|Identifica vulnerabilidades específicas.|

## 2. Ejecutar scripts NSE

### Scripts predeterminados

Ejecuta los scripts de la categoría `default`:

```
sudo nmap <IP> -sC
```

### Ejecutar una categoría específica

```
sudo nmap <IP> --script <categoria>
```

Ejemplo:

```
sudo nmap <IP> --script vuln
```

### Ejecutar scripts concretos

```
sudo nmap <IP> --script <script1>,<script2>
```

Ejemplo: enumerar el banner y los comandos disponibles en un servidor SMTP:

```
sudo nmap 10.129.2.28 -p 25 --script banner,smtp-commands
```

- `-p 25`: escanea únicamente el puerto SMTP.
    
- `banner`: obtiene información del banner del servicio.
    
- `smtp-commands`: muestra los comandos SMTP disponibles.
    

**Utilidad:** el banner puede revelar el software y su distribución, mientras que los comandos SMTP disponibles pueden aportar información útil para investigar el servicio y los posibles usuarios.

## 3. Escaneo agresivo con `-A`

La opción `-A` combina varias técnicas de enumeración:

- `-sV`: detección de servicios y versiones.
    
- `-O`: detección del sistema operativo.
    
- `--traceroute`: traza de ruta hasta el objetivo.
    
- `-sC`: ejecución de scripts NSE predeterminados.
    

Ejemplo:

```
sudo nmap 10.129.2.28 -p 80 -A
```

Este escaneo puede revelar:

- Servidor web y versión, como Apache.
    
- Aplicación web y versión, como WordPress.
    
- Título de la página web.
    
- Posibles sistemas operativos.
    
- Distancia de red y ruta hasta el objetivo.
    

**Importante:** las estimaciones del sistema operativo pueden ser poco fiables si Nmap no dispone de suficientes puertos abiertos y cerrados para compararlos.

## 4. Evaluación de vulnerabilidades con NSE

La categoría `vuln` permite ejecutar scripts destinados a identificar vulnerabilidades conocidas.

```
sudo nmap <IP> -p 80 -sV --script vuln
```

- `-p 80`: analiza únicamente el puerto HTTP.
    
- `-sV`: identifica el servicio y su versión.
    
- `--script vuln`: ejecuta los scripts de la categoría de vulnerabilidades.
    

Los resultados pueden incluir:

- Directorios o rutas interesantes de la aplicación web.
    
- Versiones detectadas de WordPress u otras aplicaciones.
    
- Posibles nombres de usuario.
    
- Resultados de comprobaciones de vulnerabilidades.
    
- Referencias a CVE asociadas al software detectado.
    

Ejemplos de información que pueden aparecer en los resultados:

- `/wp-login.php`: posible página de inicio de sesión.
    
- `http-wordpress-users`: script que puede identificar usuarios de WordPress.
    
- `vulners`: puede mostrar vulnerabilidades conocidas asociadas a la versión detectada.
    

**Importante:** que un script encuentre una versión vulnerable o muestre un CVE no confirma automáticamente que el objetivo sea explotable. Es necesario verificar los resultados.

## 5. Flujo práctico de enumeración

```
# 1. Enumerar servicios y versiones
sudo nmap <IP> -sV

# 2. Ejecutar scripts predeterminados
sudo nmap <IP> -sC

# 3. Enumerar un servicio concreto con scripts específicos
sudo nmap <IP> -p 25 --script banner,smtp-commands

# 4. Realizar un escaneo agresivo
sudo nmap <IP> -p 80 -A

# 5. Buscar posibles vulnerabilidades en un servicio web
sudo nmap <IP> -p 80 -sV --script vuln
```
