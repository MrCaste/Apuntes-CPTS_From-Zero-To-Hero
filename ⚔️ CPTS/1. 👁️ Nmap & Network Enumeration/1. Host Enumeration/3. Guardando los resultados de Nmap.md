
## 1. Formatos de salida

Nmap permite guardar los resultados de los escaneos en tres formatos principales:

|Formato|Opción|Extensión|Descripción|
|---|---|---|---|
|Normal|`-oN`|`.nmap`|Salida legible para consultar los resultados.|
|Grepable|`-oG`|`.gnmap`|Formato que facilita buscar y procesar resultados mediante herramientas de texto.|
|XML|`-oX`|`.xml`|Formato estructurado, útil para procesar resultados y generar informes.|
|Todos|`-oA`|Varias|Guarda los resultados en los tres formatos anteriores.|

## 2. Guardar un escaneo en todos los formatos

```
sudo nmap 10.129.2.28 -p- -oA target
```

- `10.129.2.28`: dirección IP del objetivo.
    
- `-p-`: escanea todos los puertos TCP.
    
- `-oA target`: guarda los resultados utilizando `target` como prefijo.
    

Se generan tres archivos:

```
target.nmap
target.gnmap
target.xml
```

Si no se especifica una ruta completa, los archivos se guardan en el directorio de trabajo actual.

## 3. Guardar los resultados en un formato específico

### Salida normal

```
sudo nmap 10.129.2.28 -p- -oN target.nmap
```

Consultar los resultados:

```
cat target.nmap
```

Es el formato más cómodo para leer directamente los resultados del escaneo.

### Salida grepable

```
sudo nmap 10.129.2.28 -p- -oG target.gnmap
```

Consultar los resultados:

```
cat target.gnmap
```

Este formato representa los hosts y sus puertos en líneas que facilitan la búsqueda y el procesamiento mediante herramientas de texto.

### Salida XML

```
sudo nmap 10.129.2.28 -p- -oX target.xml
```

Consultar los resultados:

```
cat target.xml
```

El formato XML almacena información estructurada, como los hosts detectados, los puertos, sus estados, los servicios y los motivos de los resultados.

## 4. Convertir XML a HTML

Podemos generar un informe HTML legible a partir de los resultados XML utilizando `xsltproc`.

```
xsltproc target.xml -o target.html
```

El archivo `target.html` permite visualizar los resultados en un navegador con una presentación estructurada, útil para documentar y compartir los resultados.

## 5. Flujo de trabajo recomendado

### Paso 1. Ejecutar el escaneo y guardar todos los formatos

```
sudo nmap <IP> -p- -oA target
```

### Paso 2. Consultar los resultados rápidamente

```
cat target.nmap
```

### Paso 3. Buscar o procesar resultados en formato grepable

```
cat target.gnmap
```

### Paso 4. Generar un informe HTML

```
xsltproc target.xml -o target.html
```

### Paso 5. Abrir el informe en el navegador

Abre `target.html` para revisar los resultados de manera visual.

## Resumen para el examen

- `-oN`: guarda la salida normal en formato `.nmap`.
    
- `-oG`: guarda la salida grepable en formato `.gnmap`.
    
- `-oX`: guarda la salida XML en formato `.xml`.
    
- `-oA`: guarda los tres formatos utilizando un mismo prefijo.
    
- `xsltproc archivo.xml -o archivo.html`: convierte los resultados XML en un informe HTML.
    
- Si no indicas una ruta completa, los archivos se guardan en el directorio actual.
    

**Comando clave:**

```
sudo nmap <IP> -p- -oA target
xsltproc target.xml -o target.html
```
