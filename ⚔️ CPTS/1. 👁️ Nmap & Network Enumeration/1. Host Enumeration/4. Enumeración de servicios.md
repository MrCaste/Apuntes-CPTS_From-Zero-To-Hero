
## 1. Objetivo

La enumeración de servicios permite identificar con precisión:

- Servicios que se ejecutan en los puertos abiertos.
    
- Versiones de las aplicaciones.
    
- Información adicional, como la distribución Linux o el nombre del host.
    
- Posibles vulnerabilidades asociadas a las versiones detectadas.
    

Conocer las versiones facilita buscar vulnerabilidades conocidas y exploits compatibles con el servicio y el sistema operativo del objetivo.

## 2. Detección de versiones con `-sV`

La opción `-sV` permite detectar los servicios y sus versiones en los puertos especificados.

### Escaneo completo con detección de versiones

```
sudo nmap <IP> -p- -sV
```

- `-p-`: escanea todos los puertos TCP.
    
- `-sV`: detecta los servicios y sus versiones.
    

**Recomendación del módulo:** realizar primero un escaneo rápido para obtener una visión general de los puertos disponibles y después investigar los servicios encontrados. Un escaneo completo puede tardar bastante tiempo.

### Consultar el progreso del escaneo

Durante la ejecución, puedes pulsar la **barra espaciadora** para mostrar el estado actual.

También puedes configurar la frecuencia con la que Nmap muestra estadísticas:

```
sudo nmap <IP> -p- -sV --stats-every=5s
```

En este caso, Nmap muestra el progreso cada 5 segundos.

### Aumentar la verbosidad

```
sudo nmap <IP> -p- -sV -v
```

Para obtener todavía más información:

```
sudo nmap <IP> -p- -sV -vv
```

La verbosidad permite consultar más detalles durante el escaneo, incluidos los puertos abiertos a medida que Nmap los descubre.

|Opción|Función|
|---|---|
|`-sV`|Detecta servicios y versiones.|
|`-p-`|Escanea todos los puertos TCP.|
|`--stats-every=5s`|Muestra estadísticas cada 5 segundos.|
|`-v`|Aumenta la verbosidad.|
|`-vv`|Aumenta todavía más la verbosidad.|

## 3. Interpretar los resultados

Ejemplo de salida:

```
PORT    STATE    SERVICE      VERSION
22/tcp  open     ssh          OpenSSH 7.6p1 Ubuntu
25/tcp  open     smtp         Postfix smtpd
80/tcp  open     http         Apache httpd 2.4.29
110/tcp open     pop3         Dovecot pop3d
143/tcp open     imap         Dovecot imapd
139/tcp filtered netbios-ssn
445/tcp filtered microsoft-ds
```

Debemos prestar atención a:

- **PORT:** puerto y protocolo.
    
- **STATE:** estado del puerto.
    
- **SERVICE:** nombre del servicio.
    
- **VERSION:** aplicación y versión detectadas.
    

En este ejemplo también se identifica información adicional:

```
Service Info: Host: inlane; OS: Linux; CPE: cpe:/o:linux:linux_kernel
```

Estos datos ayudan a orientar la investigación posterior.

## 4. Banner Grabbing

El _banner grabbing_ consiste en obtener la información que un servicio proporciona al establecer una conexión.

Nmap suele identificar los servicios examinando sus banners. Si no consigue determinar la versión mediante ellos, intenta identificarla mediante sondas y coincidencias basadas en firmas, lo que puede aumentar considerablemente la duración del escaneo.

Además, la detección automática puede omitir información que el servicio sí proporciona.

### Ejemplo: detectar información adicional en SMTP

```
sudo nmap <IP> -p 25 -sV
```

Nmap puede mostrar:

```
25/tcp open smtp Postfix smtpd
```

Sin embargo, el servidor puede proporcionar información adicional en su banner:

```
220 inlane ESMTP Postfix (Ubuntu)
```

Esta respuesta revela que el servidor utiliza Postfix y que está asociado a Ubuntu.

### Capturar manualmente el banner con Netcat

```
nc -nv <IP> 25
```

Ejemplo de respuesta:

```
Connection to <IP> port 25 [tcp/*] succeeded!
220 inlane ESMTP Postfix (Ubuntu)
```

Opciones utilizadas:

- `-n`: evita la resolución de nombres.
    
- `-v`: muestra información detallada.
    
- `-v`: junto con `-n`, permite observar el resultado de la conexión.
    

**Idea clave:** la conexión manual puede revelar información que no aparece en el resumen del escaneo de Nmap.

## 5. Capturar el tráfico con tcpdump

Podemos utilizar `tcpdump` para observar los paquetes intercambiados durante la conexión al servicio.

### Paso 1. Iniciar la captura

```
sudo tcpdump -i eth0 host <IP_ATACANTE> and <IP_OBJETIVO>
```

- `-i eth0`: escucha en la interfaz `eth0`.
    
- `host`: filtra el tráfico relacionado con las direcciones indicadas.
    

### Paso 2. Conectarse al servicio SMTP

En otra terminal:

```
nc -nv <IP_OBJETIVO> 25
```

### Paso 3. Interpretar el tráfico capturado

El módulo muestra el siguiente orden de paquetes:

|Paso|Indicadores TCP|Significado|
|---|---|---|
|1|`SYN`|El cliente inicia la conexión.|
|2|`SYN-ACK`|El servidor responde a la solicitud.|
|3|`ACK`|El cliente completa el saludo de tres vías.|
|4|`PSH-ACK`|El servidor envía los datos del banner y confirma la recepción correspondiente.|
|5|`ACK`|El cliente confirma la recepción de los datos.|

Ejemplo del paquete que contiene el banner:

```
Flags [P.], length 35: SMTP: 220 inlane ESMTP Postfix (Ubuntu)
```

- `PSH`: indica que se están enviando datos a la aplicación receptora.
    
- `ACK`: confirma la recepción de los datos correspondientes.
    

El banner se transmite después de establecer la conexión TCP, por lo que podemos obtener información adicional examinando el tráfico de red.

## 6. Flujo de trabajo práctico

### Paso 1. Realizar un escaneo inicial

```
sudo nmap <IP> -F
```

Obtén una visión general de los puertos principales.

### Paso 2. Escanear todos los puertos y detectar versiones

```
sudo nmap <IP> -p- -sV
```

### Paso 3. Consultar el progreso si el escaneo tarda

```
sudo nmap <IP> -p- -sV --stats-every=5s
```

### Paso 4. Investigar un servicio concreto

Por ejemplo, SMTP:

```
sudo nmap <IP> -p 25 -sV
```

### Paso 5. Obtener el banner manualmente

```
nc -nv <IP> 25
```

### Paso 6. Si necesitas analizar el intercambio de paquetes

```
sudo tcpdump -i eth0 host <IP_ATACANTE> and <IP_OBJETIVO>
```

## Resumen para el examen

- `-sV`: identifica servicios y versiones.
    
- `-p-`: escanea todos los puertos TCP.
    
- `--stats-every=5s`: muestra estadísticas periódicas.
    
- `-v` / `-vv`: muestran más información durante el escaneo.
    
- **Banner grabbing:** permite obtener información anunciada por el servicio.
    
- `nc -nv <IP> <PUERTO>`: permite conectarse manualmente y examinar el banner.
    
- `tcpdump`: permite observar los paquetes intercambiados durante la conexión.
    
- El saludo TCP de tres vías utiliza `SYN`, `SYN-ACK` y `ACK`.
    
- Un banner puede revelar información que no aparece en el resumen de Nmap.
    

**Comandos clave:**

```
# Detección de servicios y versiones
sudo nmap <IP> -p- -sV

# Mostrar el progreso cada 5 segundos
sudo nmap <IP> -p- -sV --stats-every=5s

# Aumentar la verbosidad
sudo nmap <IP> -p- -sV -v

# Capturar el banner manualmente
nc -nv <IP> 25

# Capturar el tráfico de red
sudo tcpdump -i eth0 host <IP_ATACANTE> and <IP_OBJETIVO>
```
