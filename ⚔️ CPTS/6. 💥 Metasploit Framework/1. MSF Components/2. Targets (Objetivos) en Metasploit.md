
## 1. ¿Qué son los Targets?

Los **Targets** son identificadores que permiten adaptar un módulo `exploit` a una versión específica del sistema operativo o del software objetivo.

Un mismo exploit puede necesitar configuraciones diferentes según:

- La versión del sistema operativo.
    
- La versión del software vulnerable.
    
- El Service Pack instalado.
    
- La arquitectura.
    
- El idioma del sistema.
    
- Las direcciones de retorno y otros parámetros internos.
    

### Mostrar los objetivos disponibles

El comando `show targets` muestra los objetivos compatibles con el exploit seleccionado.

Si no hemos seleccionado ningún exploit:

```
msf6 > show targets
[-] No exploit module selected.
```

Primero debemos seleccionar un módulo:

```
msf6 > use exploit/windows/browser/ie_execcommand_uaf
```

Después podemos consultar sus objetivos:

```
msf6 exploit(windows/browser/ie_execcommand_uaf) > show targets
```

---

## 2. Consultar información de los Targets

El comando `info` muestra información detallada del módulo, incluidos los objetivos disponibles.

```
msf6 exploit(windows/browser/ie_execcommand_uaf) > info
```

En el ejemplo de HTB, el módulo explota una vulnerabilidad de Internet Explorer relacionada con **MS12-063**, identificada como `CVE-2012-4969`.

Los objetivos disponibles son:

|ID|Target|
|---|---|
|0|Automatic|
|1|IE 7 on Windows XP SP3|
|2|IE 8 on Windows XP SP3|
|3|IE 7 on Windows Vista|
|4|IE 8 on Windows Vista|
|5|IE 8 on Windows 7|
|6|IE 9 on Windows 7|

Estos valores son específicos del módulo del ejemplo.

### Comandos importantes

```
info
```

Muestra información del módulo, sus objetivos y sus opciones.

```
show targets
```

Muestra los objetivos disponibles para el exploit seleccionado.

```
show options
```

Muestra las opciones configurables del módulo.

---

## 3. Seleccionar un Target

Por defecto, muchos módulos incluyen el objetivo `Automatic`.

Este modo permite que Metasploit intente determinar qué objetivo utilizar. Sin embargo, no todos los módulos pueden detectar automáticamente la versión correcta.

Si conocemos la versión exacta del sistema objetivo, podemos seleccionarla mediante su índice:

```
set target <ID>
```

### Ejemplo

Seleccionar Internet Explorer 9 en Windows 7:

```
msf6 exploit(windows/browser/ie_execcommand_uaf) > set target 6
```

Resultado:

```
target => 6
```

En este caso, el módulo utilizará la configuración correspondiente al objetivo con ID `6`.

**Importante:** debemos seleccionar el Target que corresponda al sistema real. Un exploit puede fallar si utilizamos una versión, arquitectura o configuración incorrecta.

---

## 4. Tipos de Targets y direcciones de retorno

Los objetivos pueden diferenciarse por características como:

- Versión del sistema operativo.
    
- Service Pack.
    
- Versión del software.
    
- Idioma del sistema.
    
- Direcciones de retorno y otros parámetros específicos del exploit.
    

Estas diferencias pueden afectar al funcionamiento del exploit.

### Direcciones de retorno

En determinados exploits, la dirección de retorno debe apuntar a una instrucción o secuencia de instrucciones adecuada para controlar el flujo de ejecución.

Algunos ejemplos mencionados en el material son:

|Dirección o secuencia|Descripción general|
|---|---|
|`jmp esp`|Salta a la dirección indicada por el registro `ESP`.|
|`pop/pop/ret`|Secuencia de instrucciones utilizada en determinados métodos de explotación.|

Las direcciones pueden cambiar debido a diferencias entre versiones del software, paquetes de idioma o mecanismos que alteran las direcciones de memoria.

Por ello, un Target puede necesitar parámetros específicos para una versión determinada.

---

## 5. Identificar correctamente un Target

El material indica dos pasos para identificar un objetivo durante el desarrollo de exploits:

1. Obtener una copia de los binarios del sistema objetivo.
    
2. Utilizar `msfpescan` para localizar una dirección de retorno adecuada.
    

La selección correcta depende de conocer las características del sistema y de comprender los requisitos específicos del exploit.

---

## 6. Flujo de trabajo

```
1. Seleccionar un módulo exploit con use.
2. Consultar sus características con info.
3. Mostrar los objetivos disponibles con show targets.
4. Identificar la versión del sistema y del software objetivo.
5. Seleccionar el Target adecuado con set target <ID>.
6. Revisar las opciones con show options.
7. Continuar con la configuración del módulo.
```

---

## 7. Comandos que debes recordar

|Comando|Función|
|---|---|
|`use <módulo>`|Seleccionar un módulo.|
|`info`|Consultar los detalles del módulo y sus objetivos.|
|`show targets`|Mostrar los objetivos disponibles.|
|`show options`|Mostrar las opciones configurables.|
|`set target <ID>`|Seleccionar un objetivo concreto.|

---

## 8. Ideas clave para el examen

- Los **Targets** adaptan un exploit a versiones específicas del sistema operativo o del software.
    
- `show targets` debe ejecutarse después de seleccionar un módulo exploit.
    
- `info` permite consultar los objetivos y las características del módulo.
    
- `Automatic` es el objetivo predeterminado en algunos módulos.
    
- `set target <ID>` permite seleccionar un objetivo concreto.
    
- Los índices de los Targets son específicos de cada módulo.
    
- Las diferencias de versión, idioma y Service Pack pueden afectar al funcionamiento del exploit.
    
- En determinados exploits, las direcciones de retorno son esenciales para controlar el flujo de ejecución.
    
- Seleccionar un Target incorrecto puede provocar que el exploit falle.
