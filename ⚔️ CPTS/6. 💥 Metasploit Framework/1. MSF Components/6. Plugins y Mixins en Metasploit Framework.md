
## 1. Plugins

Los **plugins** permiten ampliar las funcionalidades de Metasploit integrando herramientas y funciones desarrolladas por terceros.

Permiten:

- Añadir nuevos comandos a `msfconsole`.
    
- Automatizar tareas repetitivas.
    
- Integrar herramientas externas.
    
- Trabajar con la API de Metasploit para interactuar con el framework.
    
- Facilitar la gestión de hosts, servicios y vulnerabilidades mediante la base de datos.
    

### Directorio de plugins

La ubicación predeterminada es:

```
/usr/share/metasploit-framework/plugins/
```

Listar los plugins disponibles:

```
ls /usr/share/metasploit-framework/plugins/
```

## 2. Cargar y utilizar plugins

Para cargar un plugin desde `msfconsole`, utiliza `load` seguido de su nombre, sin la extensión `.rb`.

### Ejemplo: cargar Nessus

```
load nessus
```

Si se carga correctamente, aparecerá un mensaje indicando que el plugin se ha iniciado.

Para consultar los comandos disponibles:

```
nessus_help
```

Cada plugin dispone de sus propios comandos y funciones, por lo que conviene consultar su ayuda después de cargarlo.

### Error al cargar un plugin

Si el archivo no existe en el directorio esperado, aparecerá un error similar a:

```
[-] Failed to load plugin from /usr/share/metasploit-framework/plugins/Plugin_That_Does_Not_Exist.rb
```

Comprueba que el archivo `.rb` está instalado en el directorio correcto y que tiene los permisos necesarios.

## 3. Instalar plugins personalizados

Los plugins personalizados pueden obtenerse de los repositorios de sus desarrolladores e instalarse en el directorio de plugins de Metasploit.

### Paso 1. Descargar el repositorio

Ejemplo del material: plugins de DarkOperator.

```
git clone https://github.com/darkoperator/Metasploit-Plugins
```

Consultar los archivos descargados:

```
ls Metasploit-Plugins/
```

### Paso 2. Copiar el plugin

En el ejemplo se utiliza `pentest.rb`:

```
sudo cp ./Metasploit-Plugins/pentest.rb /usr/share/metasploit-framework/plugins/pentest.rb
```

### Paso 3. Cargar el plugin

Iniciar Metasploit:

```
msfconsole -q
```

Cargar el plugin:

```
load pentest
```

Si se carga correctamente, aparecerá un mensaje similar a:

```
[*] Successfully loaded plugin: pentest
```

### Paso 4. Consultar los nuevos comandos

```
help
```

La ayuda de `msfconsole` mostrará las funciones adicionales proporcionadas por el plugin.

El plugin `pentest` del ejemplo incorpora comandos para tareas como:

|Comando|Función|
|---|---|
|`check_footprint`|Comprobar la posible huella de un módulo post en un objetivo.|
|`show_client_side`|Mostrar exploits del lado del cliente relacionados con los datos importados de escáneres de vulnerabilidades.|
|`vuln_exploit`|Ejecutar exploits basándose en datos importados de escáneres.|
|`discover_db`|Ejecutar módulos de descubrimiento contra los hosts de la base de datos.|
|`network_discover`|Escanear puertos y enumerar servicios en redes que no son de pivote.|
|`pivot_network_discover`|Enumerar redes accesibles desde una sesión Meterpreter especificada.|
|`show_session_networks`|Mostrar redes accesibles mediante las sesiones Meterpreter activas.|
|`get_lhost`|Mostrar direcciones IP locales que pueden utilizarse como `LHOST`.|
|`multi_cmd`|Ejecutar comandos de shell en varias sesiones.|
|`multi_meter_cmd`|Ejecutar comandos de Meterpreter en varias sesiones.|
|`multi_post`|Ejecutar módulos post contra sesiones especificadas.|

**Importante:** Los comandos disponibles dependen del plugin instalado. Consulta siempre su documentación y el resultado de `help`.

## 4. Plugins populares

El material menciona los siguientes plugins e integraciones:

- **Nmap:** escaneo y reconocimiento.
    
- **Nessus:** integración con el escáner de vulnerabilidades Nessus.
    
- **NexPose:** integración con un escáner de vulnerabilidades.
    
- **Mimikatz:** funcionalidades relacionadas con credenciales y autenticación.
    
- **Stdapi:** funcionalidades de la API estándar de Meterpreter.
    
- **Railgun:** interacción con funciones de Windows.
    
- **Priv:** funcionalidades relacionadas con operaciones de privilegios.
    
- **Incognito:** funcionalidades relacionadas con tokens de Windows.
    
- **DarkOperator's:** colección de plugins adicionales para Metasploit.
    

La disponibilidad puede variar según la instalación y la versión.

## 5. Mixins en Ruby

Metasploit está desarrollado en **Ruby**, un lenguaje de programación orientado a objetos.

Los _mixins_ permiten incorporar funcionalidades de un módulo Ruby a diferentes clases sin necesidad de que esas clases hereden de una clase padre común.

Se utilizan principalmente cuando:

- Se quieren ofrecer funcionalidades opcionales a una clase.
    
- Se necesita reutilizar una funcionalidad en varias clases.
    

En Ruby, los mixins se implementan mediante módulos y la palabra clave `include`.

Ejemplo conceptual:

```
module MiModulo
  def mi_metodo
    puts "Funcionalidad reutilizable"
  end
end

class MiClase
  include MiModulo
end
```

En este ejemplo, `MiClase` incorpora el método definido en `MiModulo`.

Para empezar a utilizar Metasploit, no es necesario profundizar en los mixins. Son relevantes principalmente para comprender cómo se construye y personaliza internamente el framework.

## 6. Comandos esenciales

|Objetivo|Comando|
|---|---|
|Listar plugins instalados|`ls /usr/share/metasploit-framework/plugins/`|
|Cargar un plugin|`load <nombre>`|
|Consultar los comandos de un plugin|`<comando_de_ayuda_del_plugin>`|
|Consultar la ayuda general|`help`|
|Descargar la colección de DarkOperator|`git clone https://github.com/darkoperator/Metasploit-Plugins`|
|Instalar un plugin personalizado|`sudo cp <plugin>.rb /usr/share/metasploit-framework/plugins/`|

### Flujo de trabajo

1. Comprueba que el plugin está instalado en `/usr/share/metasploit-framework/plugins/`.
    
2. Cárgalo con `load <nombre>` desde `msfconsole`.
    
3. Comprueba que se ha cargado correctamente.
    
4. Consulta la ayuda específica del plugin.
    
5. Utiliza los comandos disponibles según las necesidades de la evaluación.
    

**Idea clave:** Los plugins amplían las capacidades de Metasploit mediante comandos e integraciones adicionales. Los mixins, por su parte, son un mecanismo de Ruby que permite reutilizar funcionalidades entre clases.
