
Durante la enumeración de Windows podemos encontrar **credenciales almacenadas en archivos, configuraciones o historiales de comandos**.

Estas credenciales pueden permitirnos:

- Acceder a cuentas de administrador local.
    
- Obtener acceso a otros equipos.
    
- Conseguir credenciales de usuarios de Active Directory.
    
- Escalar privilegios dentro del dominio.
    

## 1. Buscar contraseñas en archivos de configuración

Las aplicaciones pueden almacenar credenciales en texto plano dentro de archivos como `.txt`, `.ini`, `.cfg`, `.config` o `.xml`.

### Buscar archivos que contengan contraseñas

```
findstr /SIM /C:"password" *.txt *.ini *.cfg *.config *.xml
```

|Parámetro|Función|
|---|---|
|`/S`|Busca recursivamente en subdirectorios.|
|`/I`|Ignora mayúsculas y minúsculas.|
|`/M`|Muestra únicamente los nombres de los archivos.|
|`/C:"password"`|Busca la cadena literal `password`.|
|`*.txt *.ini ...`|Limita la búsqueda a esas extensiones.|

**Para mostrar las líneas que contienen las coincidencias**, eliminar `/M`:

```
findstr /SI /C:"password" *.txt *.ini *.cfg *.config *.xml
```

También podemos buscar varias palabras:

```
findstr /SIM /C:"password" /C:"passwd" /C:"credential" /C:"secret" *.txt *.ini *.cfg *.config *.xml
```

> **Importante:** la búsqueda se realiza desde el directorio actual y sus subdirectorios.

### Archivos de configuración de IIS

Los archivos `web.config` pueden contener credenciales de aplicaciones web.

Ubicación habitual:

```
C:\inetpub\wwwroot\web.config
```

Leer el archivo:

```
Get-Content C:\inetpub\wwwroot\web.config
```

Buscar archivos `web.config` dentro de IIS:

```
Get-ChildItem C:\inetpub -Filter web.config -Recurse -ErrorAction SilentlyContinue
```

- Contraseñas.
