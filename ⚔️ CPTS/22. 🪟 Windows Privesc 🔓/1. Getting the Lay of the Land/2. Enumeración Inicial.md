
## 1. Información del sistema

### Enumerar procesos y servicios

```
tasklist /svc
```

Muestra los procesos en ejecución, sus PID y los servicios asociados.

**Buscar:**

- Servicios de terceros como FileZilla, Apache, SQL Server, etc.
    
- Servicios que puedan tener configuraciones incorrectas.
    
- Procesos relacionados con antivirus, como `MsMpEng.exe`.
    
- Aplicaciones vulnerables o desactualizadas.
    

### Variables de entorno

```
set
```

Permite identificar variables interesantes:

|Variable|Utilidad|
|---|---|
|`PATH`|Directorios donde Windows busca ejecutables.|
|`USERNAME`|Usuario actual.|
|`USERPROFILE`|Directorio personal del usuario.|
|`APPDATA`|Directorio de datos de aplicaciones.|
|`TEMP`|Directorio temporal.|
|`HOMEDRIVE`|Unidad del directorio personal.|
|`LOGONSERVER`|Servidor de inicio de sesión.|

**Especial atención a** `**PATH**`**:**

Si encontramos un directorio en el `PATH` sobre el que tenemos permisos de escritura, podría existir una oportunidad de secuestro de ejecutables o DLL, dependiendo de cómo una aplicación los cargue.

### Información detallada del sistema

```
systeminfo
```

Información importante:

- **OS Name:** sistema operativo.
    
- **OS Version:** versión y build.
    
- **System Boot Time:** último arranque.
    
- **Hotfix(s):** actualizaciones instaladas.
    
- **Domain:** dominio o grupo de trabajo.
    
- **System Type:** arquitectura (x64/x86).
    
- **Network Card(s):** interfaces de red.
    

**Objetivo:** identificar versiones vulnerables y posibles CVE de escalada de privilegios.

## 2. Parches y actualizaciones

### CMD

```
wmic qfe
```

### PowerShell

```
Get-HotFix | ft -AutoSize
```

Permiten consultar las actualizaciones instaladas.

**Buscar:**

- Actualizaciones de seguridad ausentes.
    
- Fechas de instalación antiguas.
    
- KB relacionadas con vulnerabilidades conocidas.
    

> La ausencia de una KB en la salida no confirma por sí sola que el sistema sea vulnerable.

---

## 3. Programas instalados

### CMD

```
wmic product get name
```

### PowerShell

```
Get-WmiObject -Class Win32_Product | Select Name, Version
```

Permiten enumerar software instalado.

**Buscar:**

- Programas desactualizados.
    
- Aplicaciones con vulnerabilidades conocidas.
    
- Software que almacene credenciales.
    
- Programas instalados como servicios.
    

**Ejemplos interesantes:**

- FileZilla
    
- PuTTY
    
- SQL Server
    
- Java
    

Las versiones identificadas pueden utilizarse para investigar vulnerabilidades públicas.

## 4. Conexiones y puertos

```
netstat -ano
```

Muestra conexiones TCP/UDP, puertos y PID asociados.

**Ejemplo:**

```
Proto  Local Address    State       PID
TCP    0.0.0.0:21       LISTENING   1096
TCP    0.0.0.0:80       LISTENING   4
TCP    0.0.0.0:1433     LISTENING   3520
TCP    0.0.0.0:3389     LISTENING   968
```

**Buscar:**

- Servicios que escuchan únicamente en `127.0.0.1`.
    
- Puertos asociados con aplicaciones vulnerables.
    
- Servicios accesibles desde otras interfaces.
    
- PID de procesos interesantes.
    

Para identificar el proceso asociado a un PID:

```
tasklist /FI "PID eq 3520"
```

## 5. Enumeración de usuarios

### Usuario actual

```
whoami
echo %USERNAME%
```

### Privilegios del usuario

```
whoami /priv
```

Permite identificar privilegios que pueden aprovecharse para escalar.

**Ejemplos interesantes:**

- `SeImpersonatePrivilege`
    
- `SeAssignPrimaryTokenPrivilege`
    
- `SeBackupPrivilege`
    
- `SeRestorePrivilege`
    
- `SeDebugPrivilege`
    
- `SeTakeOwnershipPrivilege`
    

### Grupos del usuario actual

```
whoami /groups
```

**Buscar pertenencia a grupos privilegiados:**

- `Administrators`
    
- `Backup Operators`
    
- `Server Operators`
    
- `Remote Management Users`
    

La pertenencia a determinados grupos puede proporcionar permisos adicionales aprovechables para escalar privilegios.

### Usuarios con sesiones abiertas

```
query user
```

Muestra:

- Usuarios conectados.
    
- Tipo de sesión.
    
- Estado (`Active`, `Disc`).
    
- Tiempo de inactividad.
    

Puede revelar sesiones de administradores u otros usuarios interesantes.

## 6. Enumeración de cuentas y grupos locales

### Listar usuarios locales

```
net user
```

### Obtener información de un usuario

```
net user <usuario>
```

### Listar grupos locales

```
net localgroup
```

### Enumerar miembros de Administrators

```
net localgroup administrators
```

**Ejemplo:**

```
Administrator
helpdesk
sarah
secsvc
```

Estos usuarios tienen privilegios administrativos locales.

**Buscar:**

- Cuentas de servicio.
    
- Usuarios administrativos.
    
- Cuentas con nombres similares (`bob` y `bob_adm`).
    
- Posible reutilización de contraseñas.
    
- Archivos sensibles accesibles en perfiles de otros usuarios.

## 7. Política de contraseñas

```
net accounts
```

Permite consultar:

- Longitud mínima de contraseña.
    
- Caducidad de contraseñas.
    
- Historial de contraseñas.
    
- Umbral de bloqueo de cuentas.
    
- Duración del bloqueo.
    

**Ejemplo:**

```
Minimum password length: 0
Lockout threshold: Never
```

Una política débil puede facilitar ataques contra credenciales durante una auditoría autorizada.

## 9. ¿Qué debemos buscar para escalar privilegios?

|Hallazgo|Posible vía de escalada|
|---|---|
|Windows sin actualizar|Vulnerabilidades locales conocidas.|
|Servicio de terceros vulnerable|Explotación del servicio.|
|Servicio mal configurado|Abuso de permisos o configuración.|
|Directorio escribible en `PATH`|Posible secuestro de DLL o ejecutables.|
|`SeImpersonatePrivilege`|Técnicas de suplantación de tokens.|
|`SeBackupPrivilege`|Acceso privilegiado a archivos mediante mecanismos de copia de seguridad.|
|Usuario en grupo privilegiado|Abuso de permisos asociados al grupo.|
|Credenciales en archivos|Acceso a cuentas más privilegiadas.|
|Servicio escuchando en localhost|Posible explotación local de un servicio vulnerable.|

**Objetivo final:** identificar una configuración incorrecta, credenciales expuestas, un privilegio aprovechable o una vulnerabilidad que permita pasar de un usuario con pocos permisos a una cuenta administrativa o `NT AUTHORITY\SYSTEM`.
