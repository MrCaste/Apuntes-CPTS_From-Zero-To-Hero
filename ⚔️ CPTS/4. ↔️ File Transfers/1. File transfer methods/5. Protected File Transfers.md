 
## 1. Transferencias de archivos protegidas

Durante un pentest podemos acceder a información sensible, como credenciales, listas de usuarios, datos de enumeración o archivos de Active Directory como `NTDS.dit`.

Es importante **cifrar los archivos antes de transferirlos** o utilizar protocolos seguros como SSH, SFTP y HTTPS.

- **Cifrado:** protege el contenido del archivo si alguien lo intercepta.
    
- **Transporte seguro:** protege los datos durante la comunicación.
    
- **Contraseñas fuertes y únicas:** dificultan los ataques de fuerza bruta contra los archivos cifrados.
    

> **Importante:** no se deben extraer datos personales, financieros o secretos comerciales de un cliente sin autorización específica. Para probar las protecciones DLP o el filtrado de salida, se deben utilizar datos ficticios.

## 2. Cifrado de archivos en Windows con PowerShell

Podemos utilizar el script `Invoke-AESEncryption.ps1` para cifrar y descifrar cadenas de texto o archivos mediante AES.

### 2.1. Importar el módulo

Una vez transferido el script al equipo Windows:

```
Import-Module .\Invoke-AESEncryption.ps1
```

### 2.2. Cifrar una cadena de texto

```
Invoke-AESEncryption -Mode Encrypt -Key "p4ssw0rd" -Text "Secret Text"
```

El resultado es el texto cifrado codificado en Base64.

### 2.3. Descifrar una cadena de texto

```
Invoke-AESEncryption -Mode Decrypt -Key "p4ssw0rd" -Text "TEXTO_CIFRADO_BASE64"
```

Es necesario utilizar la misma clave con la que se cifró el contenido.

### 2.4. Cifrar un archivo

```
Invoke-AESEncryption -Mode Encrypt -Key "p4ssw0rd" -Path .\scan-results.txt
```

El script genera un archivo cifrado con la extensión `.aes`:

```
scan-results.txt
scan-results.txt.aes
```

### 2.5. Descifrar un archivo

```
Invoke-AESEncryption -Mode Decrypt -Key "p4ssw0rd" -Path .\scan-results.txt.aes
```

El archivo original se recupera sin la extensión `.aes`.

### Parámetros importantes

|Parámetro|Función|
|---|---|
|`-Mode Encrypt`|Cifra el contenido.|
|`-Mode Decrypt`|Descifra el contenido.|
|`-Key`|Especifica la clave de cifrado.|
|`-Text`|Indica que se trabaja con una cadena de texto.|
|`-Path`|Indica la ruta del archivo que se va a cifrar o descifrar.|

**Nota:** utiliza claves fuertes y únicas para cada cliente. No reutilices una contraseña en distintas evaluaciones.

## 3. Cifrado de archivos en Linux con OpenSSL

`openssl` permite cifrar y descifrar archivos mediante distintos algoritmos de cifrado.

### 3.1. Cifrar un archivo con AES-256

```
openssl enc -aes256 -iter 100000 -pbkdf2 -in /etc/passwd -out passwd.enc
```

El comando solicita una contraseña y su confirmación.

**Parámetros importantes:**

|Parámetro|Función|
|---|---|
|`enc`|Utiliza las funciones de cifrado de OpenSSL.|
|`-aes256`|Selecciona el cifrado AES-256-CBC.|
|`-iter 100000`|Establece 100.000 iteraciones para la derivación de la clave.|
|`-pbkdf2`|Utiliza PBKDF2 para derivar la clave a partir de la contraseña.|
|`-in`|Especifica el archivo de entrada.|
|`-out`|Especifica el archivo cifrado de salida.|

En este ejemplo, el archivo original es `/etc/passwd` y el resultado cifrado es `passwd.enc`.

### 3.2. Descifrar el archivo

```
openssl enc -d -aes256 -iter 100000 -pbkdf2 -in passwd.enc -out passwd
```

El comando solicita la contraseña utilizada durante el cifrado y recupera el contenido original en `passwd`.

**Parámetros adicionales:**

|Parámetro|Función|
|---|---|
|`-d`|Activa el modo de descifrado.|
|`-in passwd.enc`|Indica el archivo cifrado.|
|`-out passwd`|Indica dónde guardar el contenido descifrado.|

## 4. Comparativa rápida

|Método|Sistema|Uso|
|---|---|---|
|`Invoke-AESEncryption.ps1`|Windows|Cifrar y descifrar archivos o cadenas mediante PowerShell.|
|`openssl enc -aes256`|Linux|Cifrar archivos mediante AES-256.|
|`openssl enc -d -aes256`|Linux|Descifrar archivos previamente cifrados.|

## 5. Puntos clave para el CPTS

- **Cifra los datos sensibles antes de transferirlos** si el método de transferencia no ofrece protección suficiente.
    
- En Windows, importa `Invoke-AESEncryption.ps1` mediante `Import-Module`.
    
- Para cifrar o descifrar archivos con PowerShell, utiliza `-Mode`, `-Key` y `-Path`.
    
- En Linux, utiliza `openssl enc -aes256 -iter 100000 -pbkdf2` para cifrar archivos.
    
- Para descifrar con OpenSSL, añade `-d` y conserva los parámetros utilizados durante el cifrado.
    
- Usa contraseñas fuertes y únicas; un archivo cifrado puede ser objetivo de ataques de fuerza bruta si alguien obtiene una copia.
    
- Siempre que sea posible, combina el cifrado de los archivos con un canal de transferencia seguro, como **SSH, SFTP o HTTPS**.
    
- Cifrar un archivo y transferirlo mediante un protocolo seguro son medidas complementarias, no alternativas excluyentes.
