
## 1. Extension Fuzzing

Antes de buscar archivos ocultos en un directorio, debemos identificar qué extensiones utiliza la aplicación web (`.php`, `.html`, `.aspx`, etc.).

Podemos utilizar `ffuf` para descubrirlas mediante un diccionario de extensiones.

### Enumerar extensiones

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/web-extensions.txt \
-u http://TARGET:PORT/blog/indexFUZZ
```

**Importante:**

- Utilizamos `index` porque es un archivo habitual en aplicaciones web.
    
- La wordlist `web-extensions.txt` ya contiene el punto (`.php`, `.html`, etc.).
    
- Por eso utilizamos `indexFUZZ` y no `index.FUZZ`.
    

Ejemplo de resultados:

```
.php     [Status: 200, Size: 0, Words: 1, Lines: 1]
.phps    [Status: 403, Size: 283, Words: 20, Lines: 10]
```

Interpretación:

- `.php` devuelve `200`, indicando que `index.php` existe y es accesible.
    
- `.phps` devuelve `403`, indicando que el servidor rechaza el acceso a esa ruta.
    

Con estos resultados, podemos continuar buscando archivos PHP.

## 2. Page Fuzzing

Una vez identificada la extensión utilizada por la aplicación, podemos buscar archivos ocultos dentro de los directorios descubiertos.

### Enumerar archivos PHP

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt \
-u http://TARGET:PORT/blog/FUZZ.php
```

En este caso:

- `FUZZ` representa el nombre del archivo.
    
- `.php` es la extensión que hemos identificado.
    
- `/blog/` es el directorio descubierto anteriormente.
    

Ejemplo de resultados:

```
index    [Status: 200, Size: 0, Words: 1, Lines: 1]
admin    [Status: 200, Size: 465, Words: 42, Lines: 15]
```

Interpretación:

- `index.php`: archivo accesible que devuelve una respuesta vacía.
    
- `admin.php`: archivo accesible que devuelve contenido.
    

**Es importante revisar el tamaño de las respuestas (**`**Size**`**), ya que permite distinguir archivos vacíos de páginas con contenido.**

---

## 3. Verificar los archivos encontrados

Podemos comprobar manualmente las páginas descubiertas utilizando `curl`:

```
curl -i http://TARGET:PORT/blog/admin.php
```

O acceder directamente desde el navegador:

```
http://TARGET:PORT/blog/admin.php
```

Esto permite identificar información interesante, como mensajes, rutas adicionales o referencias a otros recursos.

## 5. Flujo de enumeración

Durante una enumeración web, podemos seguir este procedimiento:

**1. Descubrir directorios**

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt -u http://TARGET:PORT/FUZZ
```

**2. Identificar las extensiones utilizadas**

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/web-extensions.txt -u http://TARGET:PORT/blog/indexFUZZ
```

**3. Buscar archivos utilizando la extensión encontrada**

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt -u http://TARGET:PORT/blog/FUZZ.php
```

**4. Revisar las páginas interesantes**

```
curl -i http://TARGET:PORT/blog/ARCHIVO.php
```

---

## Conceptos clave

- **Extension Fuzzing:** permite descubrir las extensiones utilizadas por una aplicación web.
    
- **Page Fuzzing:** permite encontrar archivos ocultos utilizando una extensión conocida.
    
- `**indexFUZZ**`**:** se utiliza para descubrir extensiones cuando la wordlist ya incluye el punto.
    
- `**FUZZ.php**`**:** se utiliza para descubrir nombres de archivos PHP.
    
- `**Status: 200**`**:** indica que la petición se ha procesado correctamente.
    
- `**Status: 403**`**:** indica que el servidor rechaza el acceso al recurso.
    
- `**Size**`**:** permite identificar diferencias entre las respuestas del servidor.
    

**Para el examen:** primero descubre los directorios, después identifica las extensiones y finalmente busca archivos dentro de cada directorio utilizando la extensión correspondiente.
