
## 1. ¿Qué es ffuf?

`ffuf` es una herramienta de **Web Fuzzing** que permite descubrir directorios y rutas ocultas en aplicaciones web mediante diccionarios (_wordlists_).

Su funcionamiento consiste en sustituir la palabra clave `FUZZ` por cada entrada de un diccionario y analizar las respuestas HTTP del servidor.

### Instalación

```
sudo apt install ffuf -y
```

Consultar las opciones disponibles:

```
ffuf -h
```

---

## 2. Enumeración de directorios

Para descubrir directorios utilizamos principalmente dos parámetros:

- `-w`: especifica el diccionario.
    
- `-u`: indica la URL objetivo.
    

La palabra clave `FUZZ` marca la posición donde se probarán las entradas del diccionario.

### Comando básico

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt \
-u http://TARGET:PORT/FUZZ
```

También podemos asignar explícitamente la palabra clave al diccionario:

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt:FUZZ \
-u http://TARGET:PORT/FUZZ
```

**Ejemplo de funcionamiento:**

```
http://TARGET:PORT/admin
http://TARGET:PORT/blog
http://TARGET:PORT/uploads
http://TARGET:PORT/images
http://TARGET:PORT/backup
```

`ffuf` realiza una petición HTTP por cada palabra del diccionario y muestra las respuestas que coinciden con sus criterios de búsqueda.

---

## 3. Interpretar los resultados

Ejemplo:

```
blog    [Status: 301, Size: 326, Words: 20, Lines: 10]
```

|Campo|Significado|
|---|---|
|`blog`|Directorio encontrado|
|`Status: 301`|Redirección permanente|
|`Size: 326`|Tamaño de la respuesta en bytes|
|`Words: 20`|Número de palabras de la respuesta|
|`Lines: 10`|Número de líneas de la respuesta|

### Códigos HTTP importantes

|Código|Significado|
|---|---|
|`200`|OK: el recurso existe y es accesible|
|`204`|Respuesta correcta sin contenido|
|`301`|Redirección permanente|
|`302`|Redirección temporal|
|`307`|Redirección temporal|
|`401`|Requiere autenticación|
|`403`|Acceso denegado|
|`404`|Recurso no encontrado|

**Importante:** un directorio puede existir aunque devuelva una página vacía o una redirección. Por eso debemos comprobar los resultados encontrados.

---

## 4. Opciones importantes de ffuf

|Parámetro|Función|
|---|---|
|`-w`|Diccionario utilizado|
|`-u`|URL objetivo|
|`-H`|Añadir cabeceras HTTP|
|`-X`|Especificar método HTTP|
|`-b`|Añadir cookies|
|`-d`|Enviar datos POST|
|`-mc`|Mostrar determinados códigos HTTP|
|`-ms`|Mostrar respuestas de un tamaño específico|
|`-fc`|Filtrar códigos HTTP|
|`-fs`|Filtrar respuestas por tamaño|
|`-t`|Número de hilos|
|`-recursion`|Activar búsqueda recursiva|
|`-recursion-depth`|Profundidad máxima de recursión|
|`-o`|Guardar resultados en un archivo|

### Filtrar respuestas por código HTTP

Por ejemplo, para ocultar las respuestas `403`:

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt \
-u http://TARGET:PORT/FUZZ \
-fc 403
```

### Filtrar respuestas por tamaño

Útil cuando el servidor devuelve respuestas del mismo tamaño para rutas inexistentes.

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt \
-u http://TARGET:PORT/FUZZ \
-mc all -fs 42
```

- `-mc all`: considera todos los códigos HTTP.
    
- `-fs 42`: oculta las respuestas de 42 bytes.
    

### Guardar resultados

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt \
-u http://TARGET:PORT/FUZZ \
-o results.json
```

---

## 5. Controlar la velocidad del escaneo

Por defecto, `ffuf` utiliza 40 hilos.

Podemos modificar el número de hilos con `-t`:

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt \
-u http://TARGET:PORT/FUZZ \
-t 40
```

Aunque aumentar los hilos puede acelerar el escaneo, también puede saturar el servidor objetivo.

**Recomendación:** utilizar un número moderado de hilos para evitar interrupciones del servicio.

---

## 6. Verificar los directorios encontrados

Una vez localizado un directorio, podemos comprobarlo utilizando `curl`:

```
curl -I http://TARGET:PORT/blog
```

O acceder directamente desde el navegador:

```
http://TARGET:PORT/blog
```

Si el directorio existe, podemos continuar enumerando su contenido.

Por ejemplo:

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt \
-u http://TARGET:PORT/blog/FUZZ
```

Esto permite descubrir posibles subdirectorios dentro de `/blog/`.

ffuf -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt -u http://TARGET:PORT/blog/FUZZ

## Conceptos clave

- **Directory Fuzzing:** técnica para descubrir directorios ocultos utilizando diccionarios.
    
- `**FUZZ**`**:** marcador que ffuf sustituye por cada entrada de la wordlist.
    
- `**-w**`**:** especifica el diccionario.
    
- `**-u**`**:** indica la URL objetivo.
    
- `**-fc**`**:** excluye respuestas según su código HTTP.
    
- `**-fs**`**:** excluye respuestas según su tamaño.
    
- `**-mc**`**:** permite seleccionar los códigos HTTP que queremos mostrar.
    
- `**-t**`**:** controla el número de hilos utilizados.
    

**Para el examen:** lo más importante es dominar `-w`, `-u`, `FUZZ`, `-fc` y `-fs`, e interpretar correctamente los códigos HTTP para identificar directorios interesantes.
