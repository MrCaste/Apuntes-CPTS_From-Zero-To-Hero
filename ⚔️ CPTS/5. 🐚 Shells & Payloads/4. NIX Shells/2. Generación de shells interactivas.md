
## 1. `/bin/sh -i`

Ejecuta el intérprete de comandos en modo interactivo mediante la opción `-i`.

```
/bin/sh -i
```

Puede aparecer el siguiente mensaje:

```
sh: no job control in this shell
sh-4.2$
```

Aunque no exista control de trabajos, podemos disponer de un prompt interactivo.

También podemos utilizar `/bin/bash` si está disponible en el sistema.

---

## 2. Generar una shell con distintos intérpretes

Si Python no está instalado, podemos comprobar si existen otros lenguajes o herramientas capaces de ejecutar un intérprete de comandos.

### Perl

```
perl -e 'exec "/bin/sh";'
```

### Ruby

```
exec "/bin/sh"
```

El ejemplo de Ruby corresponde a código que debe ejecutarse desde un script.

### Lua

```
os.execute('/bin/sh')
```

Este ejemplo también debe ejecutarse desde un script Lua.

### AWK

```
awk 'BEGIN {system("/bin/sh")}'
```

AWK permite ejecutar comandos del sistema mediante la función `system()`.

---

## 3. Utilizar `find` para ejecutar una shell

El comando `find` permite buscar archivos y ejecutar comandos mediante la opción `-exec`.

### Ejecutar AWK desde `find`

```
find / -name nameoffile -exec /bin/awk 'BEGIN {system("/bin/sh")}' \;
```

- `/`: directorio desde el que comienza la búsqueda.
    
- `-name nameoffile`: nombre del archivo que se busca.
    
- `-exec`: ejecuta el comando indicado cuando encuentra coincidencias.
    
- `/bin/awk`: ejecuta AWK.
    
- `system("/bin/sh")`: inicia una shell.
    
- `\;`: marca el final del comando de `-exec`.
    

El nombre `nameoffile` debe sustituirse por el archivo que se quiera buscar.

### Ejecutar directamente `/bin/sh`

```
find . -exec /bin/sh \; -quit
```

- `.`: busca desde el directorio actual.
    
- `-exec /bin/sh \;`: ejecuta la shell.
    
- `-quit`: finaliza `find` después de procesar la primera coincidencia.

## 4. Generar una shell desde Vim

Vim también permite ejecutar comandos externos.

### Ejecutar `/bin/sh` desde Vim

```
vim -c ':!/bin/sh'
```

### Abrir una shell desde una sesión de Vim

Primero, iniciar Vim:

```
vim
```

Dentro del editor, ejecutar:

```
:set shell=/bin/sh
:shell
```

El primer comando establece el intérprete de comandos que utilizará Vim. El segundo inicia una shell.

## 5. Comprobar permisos sobre archivos y binarios

Una vez obtenida una shell, debemos comprobar los permisos de la cuenta actual y buscar posibles vías de escalada de privilegios.

### Listar permisos y propiedades

```
ls -la <ruta_del_archivo_o_binario>
```

Ejemplo:

```
ls -la /usr/bin/find
```

La salida permite examinar:

- Propietario y grupo.
    
- Permisos de lectura, escritura y ejecución.
    
- Permisos especiales, si existen.
    

Los permisos disponibles pueden determinar qué acciones podemos realizar con un archivo o binario.

## 6. Comprobar permisos de sudo

Ejecutar:

```
sudo -l
```

Este comando muestra los comandos que el usuario actual puede ejecutar mediante `sudo`.

Ejemplo de salida:

```
User apache may run the following commands on ILF-WebSrv:
    (ALL : ALL) NOPASSWD: ALL
```

En este ejemplo, el usuario `apache` puede ejecutar cualquier comando como cualquier usuario y grupo sin introducir una contraseña.

**Interpretación:** si esta configuración está realmente disponible para la cuenta actual, permite ejecutar comandos con privilegios elevados y constituye una vía crítica de escalada de privilegios.

### Consideraciones

- `sudo -l` puede no funcionar correctamente en una shell limitada o inestable.
    
- Si no devuelve información, conviene comprobar si la shell permite una interacción adecuada.
    
- Que un usuario pueda ejecutar determinados comandos mediante `sudo` no significa que pueda ejecutar todos los comandos como root.

## 8. Metodología práctica

Cuando obtengamos una shell limitada en Linux:

1. **Identificar el usuario actual:**
    
    ```
    whoami
    ```
    
2. **Comprobar si Python está disponible:**
    
    ```
    which python
    ```
    
3. **Si Python no está disponible, comprobar otras herramientas:** `/bin/sh`, Perl, Ruby, Lua, AWK, `find` o Vim.
    
4. **Intentar conseguir una shell interactiva** utilizando una herramienta disponible en el sistema.
    
5. **Comprobar los permisos de los archivos y binarios relevantes:**
    
    ```
    ls -la <ruta>
    ```
    
6. **Consultar los permisos de sudo:**
    
    ```
    sudo -l
    ```
    
7. **Analizar los permisos obtenidos** para identificar posibles vías de escalada de privilegios.
    

### Ideas clave para el examen

- Una shell limitada puede dificultar la ejecución de determinados comandos.
    
- Python no es la única herramienta que permite generar una shell interactiva.
    
- Perl, Ruby, Lua y AWK pueden ejecutar comandos del sistema cuando están disponibles.
    
- `find` y Vim también pueden utilizarse para iniciar un intérprete de comandos.
    
- `ls -la` permite examinar los permisos y las propiedades de archivos y binarios.
    
- `sudo -l` permite identificar qué comandos puede ejecutar el usuario mediante `sudo`.
    
- **Conseguir una shell interactiva no implica obtener privilegios de root.**
