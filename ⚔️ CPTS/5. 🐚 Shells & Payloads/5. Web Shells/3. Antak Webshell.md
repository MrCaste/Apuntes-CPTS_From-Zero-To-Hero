
## 1. ¿Qué es ASPX?

**ASPX (Active Server Page Extended)** es una extensión utilizada por páginas web desarrolladas con ASP.NET, el framework de Microsoft.

En un servidor que ejecuta ASP.NET, las páginas pueden procesar información en el servidor y generar contenido HTML para el navegador.

Si conseguimos que el servidor ejecute un archivo ASPX que contiene código capaz de ejecutar comandos, podemos utilizarlo para interactuar con el sistema operativo Windows mediante una Web Shell.

---

## 2. ¿Qué es Antak?

**Antak** es una Web Shell desarrollada en ASP.NET que forma parte de **Nishang**, un conjunto de herramientas ofensivas basadas en PowerShell.

Utiliza PowerShell para interactuar con el sistema Windows desde el navegador.

### Características principales

- Ejecuta comandos de PowerShell.
    
- Permite subir y descargar archivos.
    
- Puede codificar y ejecutar comandos.
    
- Permite ejecutar scripts en memoria.
    
- Incluye funciones para analizar archivos `web.config`.
    
- Dispone de una opción para ejecutar consultas SQL.
    
- Permite introducir comandos desde una interfaz similar a una consola de PowerShell.
    

### Ubicación en Kali Linux y Parrot OS

Los archivos de Antak se encuentran normalmente en:

```
/usr/share/nishang/Antak-WebShell/
```

Para consultar su contenido:

```
ls /usr/share/nishang/Antak-WebShell/
```

Archivos principales:

```
antak.aspx
Readme.md
```

## 3. Preparar Antak

Como en el caso de Laudanum, es recomendable crear una copia del archivo original antes de modificarlo.

```
cp /usr/share/nishang/Antak-WebShell/antak.aspx /home/administrator/Upload.aspx
```

En este ejemplo, el archivo se copia como `Upload.aspx`.

### Configurar las credenciales

Antes de utilizar la Web Shell, debemos revisar el archivo y configurar las credenciales de acceso que utiliza Antak.

El módulo indica que esta configuración se encuentra en la línea 14 del archivo original.

Debemos establecer un nombre de usuario y una contraseña adecuados para el laboratorio.

Estas credenciales se utilizarán al acceder a la Web Shell desde el navegador.

**Importante:** las credenciales configuradas en Antak son las de acceso a la Web Shell y no necesariamente las credenciales de una cuenta de Windows.

---

## 4. Configurar `/etc/hosts`

Para acceder al servidor mediante el nombre virtual del laboratorio, editar el archivo:

```
sudo nano /etc/hosts
```

Añadir la siguiente entrada:

```
<IP_OBJETIVO> status.inlanefreight.local
```

Sustituir `<IP_OBJETIVO>` por la dirección IP asignada al objetivo.

Esto permite acceder al servidor utilizando el nombre `status.inlanefreight.local`.

---

## 5. Subir Antak al servidor

El laboratorio utiliza la misma aplicación web que en la sección de Laudanum.

El procedimiento es:

1. Acceder a `status.inlanefreight.local`.
    
2. Localizar la funcionalidad de subida de archivos.
    
3. Seleccionar el archivo `Upload.aspx`.
    
4. Subir el archivo.
    
5. Comprobar la ubicación en la que se ha almacenado.
    

En el laboratorio, los archivos se guardan en el directorio `files`.

Por tanto, la ruta utilizada para acceder a la Web Shell es:

```
status.inlanefreight.local/files/upload.aspx
```

Una vez abierta la página, Antak solicita las credenciales que hemos configurado previamente.

Si son correctas, podremos acceder a su interfaz.

## 6. Utilizar la consola de Antak

Una vez autenticados, aparece una interfaz similar a una consola de PowerShell.

El mensaje inicial indica que podemos utilizar `help` para consultar información sobre las funciones disponibles.

### Funciones de la interfaz

|Función|Descripción|
|---|---|
|`Submit`|Envía el comando introducido para su ejecución.|
|`Browse`|Permite explorar archivos mediante la interfaz.|
|`Upload the File`|Permite subir archivos al servidor.|
|`Encode and Execute`|Codifica y ejecuta el comando mediante la función correspondiente.|
|`Download`|Permite descargar archivos.|
|`Parse web.config`|Permite analizar un archivo `web.config`.|
|`Execute SQL Query`|Permite ejecutar consultas SQL mediante la funcionalidad correspondiente.|

Las funciones disponibles dependen de la implementación y de los permisos del proceso web.

### Ejecutar comandos de PowerShell

Podemos introducir comandos para obtener información del sistema y explorar directorios.

Por ejemplo:

```
Get-Location
```

Muestra el directorio de trabajo actual.

```
Get-ChildItem
```

Lista los archivos y directorios de la ubicación actual.

```
Get-ChildItem C:\Users
```

Lista el contenido del directorio `C:\Users`.

```
whoami
```

Muestra la identidad de la cuenta con la que se ejecuta el comando.

Para consultar las funciones disponibles en Antak, utilizar:

```
help
```

Después de introducir el comando, pulsamos `Submit` y examinamos la salida devuelta por el servidor.

## 7. Antak y la ejecución de comandos

Antak utiliza PowerShell para ejecutar comandos en el servidor Windows.

Una particularidad importante es que **cada comando se ejecuta como un proceso nuevo**.

Por ello, no debemos asumir que el estado de una sesión de PowerShell se conserva automáticamente entre comandos.

La interfaz también permite trabajar con scripts y archivos, lo que amplía las posibilidades de interacción con el sistema.

---

## 8. Metodología práctica

Cuando encontremos un servidor Windows que permita ejecutar archivos ASPX:

1. **Identificar la tecnología:** comprobar si el servidor utiliza ASP.NET.
    
2. **Localizar Antak:** revisar los archivos disponibles en `/usr/share/nishang/Antak-WebShell/`.
    
3. **Preparar una copia:** guardar el archivo ASPX en el directorio de trabajo.
    
4. **Configurar las credenciales:** establecer el acceso a la Web Shell.
    
5. **Configurar el nombre virtual:** añadir el host del laboratorio a `/etc/hosts`.
    
6. **Subir el archivo:** utilizar la funcionalidad de carga disponible.
    
7. **Acceder a la ruta:** abrir el archivo ASPX desde el navegador.
    
8. **Autenticarse:** introducir las credenciales configuradas.
    
9. **Enumerar el sistema:** utilizar PowerShell para consultar el usuario, los directorios y la información disponible.
    
10. **Evaluar los permisos:** determinar qué acciones permite realizar la cuenta que ejecuta los comandos.

## 10. Ideas clave para el examen

- ASPX es una extensión utilizada en aplicaciones ASP.NET.
    
- Antak es una Web Shell basada en ASP.NET que forma parte de Nishang.
    
- Antak utiliza PowerShell para interactuar con el sistema Windows.
    
- Su ubicación habitual en Kali y Parrot OS es `/usr/share/nishang/Antak-WebShell/`.
    
- El archivo principal es `antak.aspx`.
    
- Es necesario configurar las credenciales de acceso antes de utilizar la Web Shell.
    
- En el laboratorio, el archivo se sube al directorio `files` y se accede mediante `status.inlanefreight.local/files/upload.aspx`.
    
- La interfaz permite ejecutar comandos, gestionar archivos y utilizar otras funciones.
    
- Cada comando se ejecuta como un proceso nuevo, por lo que no debe asumirse que el estado de PowerShell persiste entre comandos.
    
- La ejecución de comandos depende de los permisos de la cuenta que utiliza el proceso web.
    
- Una Web Shell permite ejecutar comandos, pero no implica automáticamente disponer de privilegios administrativos.
