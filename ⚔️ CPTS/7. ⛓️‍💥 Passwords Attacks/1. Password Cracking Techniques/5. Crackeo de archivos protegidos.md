
## 1. Conceptos clave

Los archivos protegidos mediante contraseña pueden contener información sensible, como documentos empresariales, contratos, informes o claves privadas.

Existen dos tipos principales de cifrado:

- **Cifrado simétrico:** utiliza la misma clave para cifrar y descifrar los datos. Un ejemplo es AES-256.
    
- **Cifrado asimétrico:** utiliza dos claves diferentes. El remitente cifra con la clave pública del destinatario y este descifra con su clave privada.
    

En esta sección aprenderemos a localizar archivos protegidos y a extraer sus hashes para intentar descifrar sus contraseñas mediante **John the Ripper (JtR)** y listas de palabras.

## 2. Buscar archivos protegidos en Linux

Podemos buscar archivos potencialmente protegidos utilizando sus extensiones.

### Buscar documentos y archivos comunes

```
for ext in $(echo ".xls .xls* .xltx .od* .doc .doc* .pdf .pot .pot* .pp*"); do
    echo -e "\nFile extension: $ext"
    find / -name "*$ext" 2>/dev/null | grep -v "lib\|fonts\|share\|core"
done
```

**Elementos importantes:**

- `find /`: busca desde la raíz del sistema.
    
- `-name "*$ext"`: busca archivos cuyo nombre coincida con la extensión.
    
- `2>/dev/null`: oculta los errores de permisos y otros mensajes de error.
    
- `grep -v`: excluye rutas que contengan los términos indicados.
    

Algunas extensiones habituales son:

|Extensión|Tipo de archivo|
|---|---|
|`.doc`, `.docx`|Documentos de Word|
|`.xls`, `.xlsx`|Hojas de cálculo de Excel|
|`.ppt`, `.pptx`|Presentaciones de PowerPoint|
|`.pdf`|Documentos PDF|
|`.odt`|Documentos de texto OpenDocument|
|`.ods`|Hojas de cálculo OpenDocument|
|`.odp`|Presentaciones OpenDocument|

Si encontramos extensiones desconocidas, podemos investigar qué tipo de archivo representan.

## 3. Buscar claves privadas SSH

Las claves privadas SSH pueden no tener una extensión concreta. Por ello, podemos buscarlas utilizando las cabeceras características de su contenido.

### Buscar claves privadas

```
grep -rnE '^\-{5}BEGIN [A-Z0-9]+ PRIVATE KEY\-{5}$' /* 2>/dev/null
```

Este comando busca recursivamente cadenas que coincidan con cabeceras de claves privadas.

Ejemplos de resultados:

```
/home/jsmith/.ssh/id_ed25519:1:-----BEGIN OPENSSH PRIVATE KEY-----
/home/jsmith/.ssh/SSH.private:1:-----BEGIN RSA PRIVATE KEY-----
/home/jsmith/Documents/id_rsa:1:-----BEGIN OPENSSH PRIVATE KEY-----
```

**Importante:** encontrar una clave privada no significa que esté protegida por contraseña. Debemos comprobarlo.

### Comprobar si una clave SSH está cifrada

```
ssh-keygen -yf ~/.ssh/id_ed25519
```

Si la clave no está cifrada, el comando puede mostrar la clave pública correspondiente.

Si está protegida por una frase de contraseña, solicitará introducirla:

```
Enter passphrase for "/home/jsmith/.ssh/id_rsa":
```

En claves RSA antiguas, también podemos encontrar indicadores de cifrado dentro del archivo:

```
Proc-Type: 4,ENCRYPTED
DEK-Info: AES-128-CBC,...
```

Las claves SSH modernas no siempre permiten identificar visualmente si están cifradas.

## 4. Localizar herramientas de extracción de hashes

John the Ripper incluye herramientas que extraen información de autenticación de diferentes archivos para facilitar ataques offline.

Podemos localizarlas mediante:

```
locate *2john*
```

Algunas herramientas importantes son:

|Herramienta|Archivo o formato|
|---|---|
|`ssh2john.py`|Claves privadas SSH|
|`office2john.py`|Documentos de Microsoft Office|
|`pdf2john.py`|Documentos PDF|
|`zip2john`|Archivos ZIP|
|`rar2john`|Archivos RAR|
|`7z2john.pl`|Archivos 7-Zip|
|`keepass2john`|Bases de datos KeePass|
|`gpg2john`|Archivos protegidos mediante GPG|
|`bitlocker2john`|Volúmenes BitLocker|
|`putty2john.py`|Claves privadas PuTTY, según la instalación|

La disponibilidad y el nombre exacto de cada herramienta pueden variar según la instalación.

## 5. Crackear claves SSH cifradas

El procedimiento consiste en extraer el hash de la clave privada y utilizar John the Ripper para intentar recuperar su frase de contraseña.

### Paso 1. Extraer el hash

```
ssh2john.py SSH.private > ssh.hash
```

- `SSH.private`: clave privada protegida.
    
- `ssh.hash`: archivo donde se guarda el hash extraído.
    

### Paso 2. Intentar descifrarlo con una wordlist

```
john --wordlist=rockyou.txt ssh.hash
```

También podemos especificar la ruta completa de la lista:

```
john --wordlist=/usr/share/wordlists/rockyou.txt ssh.hash
```

John probará las contraseñas de la lista contra el hash extraído.

### Paso 3. Mostrar los resultados

```
john ssh.hash --show
```

Ejemplo:

```
SSH.private:1234

1 password hash cracked, 0 left
```

En este ejemplo, la frase de contraseña recuperada es `1234`.

**Flujo de trabajo:**

```
Clave SSH cifrada
       |
       v
   ssh2john.py
       |
       v
    ssh.hash
       |
       v
 john --wordlist
       |
       v
 Contraseña recuperada
```

## 6. Crackear documentos de Microsoft Office

John the Ripper permite extraer hashes de documentos de Office protegidos mediante contraseña.

### Paso 1. Extraer el hash

```
office2john.py Protected.docx > protected-docx.hash
```

### Paso 2. Ejecutar John

```
john --wordlist=rockyou.txt protected-docx.hash
```

### Paso 3. Mostrar la contraseña recuperada

```
john protected-docx.hash --show
```

Ejemplo:

```
Protected.docx:1234

1 password hash cracked, 0 left
```

El mismo procedimiento puede aplicarse a otros formatos de Office compatibles con la herramienta.

---

## 7. Crackear documentos PDF

El procedimiento es prácticamente idéntico al de los documentos de Office, pero utilizamos `pdf2john.py`.

### Paso 1. Extraer el hash

```
pdf2john.py PDF.pdf > pdf.hash
```

### Paso 2. Intentar descifrarlo

```
john --wordlist=rockyou.txt pdf.hash
```

### Paso 3. Mostrar los resultados

```
john pdf.hash --show
```

Ejemplo:

```
PDF.pdf:1234

1 password hash cracked, 0 left
```

## 9. Puntos clave para el CPTS

- Los archivos cifrados pueden contener información útil para avanzar en una máquina o investigación.
    
- Busca documentos sensibles y claves privadas durante la enumeración y la postexplotación.
    
- Las claves privadas SSH pueden estar cifradas mediante una frase de contraseña.
    
- `ssh-keygen -yf` permite comprobar si una clave privada puede utilizarse sin introducir una frase de contraseña.
    
- Las herramientas `*2john` extraen hashes que pueden atacarse offline.
    
- El flujo habitual es **extraer el hash → ejecutar John → consultar los resultados con** `**--show**`.
    
- `ssh2john.py`, `office2john.py` y `pdf2john.py` son herramientas especialmente importantes.
    
- Una lista de palabras genérica puede funcionar con contraseñas débiles, pero las contraseñas largas y aleatorias son mucho más difíciles de recuperar.
    
- Recuperar una contraseña de un archivo no implica necesariamente descifrarlo: la herramienta debe ser compatible con el formato y la protección utilizada.
