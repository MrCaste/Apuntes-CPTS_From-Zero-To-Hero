
## 1. Conceptos clave

Los archivos comprimidos permiten agrupar múltiples documentos y carpetas en un único archivo. Algunos formatos admiten protección mediante contraseña, mientras que otros necesitan herramientas adicionales para cifrar su contenido.

**Formatos habituales:**

- `.zip`
    
- `.rar`
    
- `.7z`
    
- `.tar`
    
- `.gz`
    
- `.kdbx`
    
- `.vhd` (puede contener volúmenes cifrados con BitLocker).
    

No todos los formatos admiten protección por contraseña de forma nativa. Por ejemplo, los archivos TAR pueden cifrarse utilizando herramientas como OpenSSL o GPG.

El procedimiento general para atacar archivos protegidos es:

1. Identificar el formato del archivo.
    
2. Extraer el hash mediante una herramienta compatible, si corresponde.
    
3. Intentar recuperar la contraseña con John the Ripper o Hashcat.
    
4. Utilizar la contraseña recuperada para acceder al contenido.

## 2. Identificar extensiones de archivos comprimidos

Podemos consultar extensiones de archivos comprimidos desde FileInfo y guardar los resultados en una lista.

```
curl -s https://fileinfo.com/filetypes/compressed | html2text | awk '{print tolower($1)}' | grep "\." | tee -a compressed_ext.txt
```

**Comandos utilizados:**

- `curl -s`: descarga el contenido sin mostrar información adicional de transferencia.
    
- `html2text`: convierte el HTML en texto.
    
- `awk '{print tolower($1)}'`: extrae el primer campo y lo convierte a minúsculas.
    
- `grep "\."`: filtra las líneas que contienen un punto.
    
- `tee -a`: muestra los resultados y los añade al archivo `compressed_ext.txt`.

## 3. Crackear archivos ZIP

Para recuperar la contraseña de un ZIP protegido, utilizamos `zip2john` para extraer el hash y John the Ripper para intentar descifrarlo.

### Paso 1. Extraer el hash

```
zip2john ZIP.zip > zip.hash
```

El hash se almacena en `zip.hash`.

Podemos comprobar su contenido:

```
cat zip.hash
```

### Paso 2. Crackear el hash

```
john --wordlist=rockyou.txt zip.hash
```

También podemos utilizar la ruta completa de la wordlist:

```
john --wordlist=/usr/share/wordlists/rockyou.txt zip.hash
```

### Paso 3. Mostrar la contraseña recuperada

```
john zip.hash --show
```

Ejemplo de salida:

```
ZIP.zip/customers.csv:1234:customers.csv:ZIP.zip::ZIP.zip

1 password hash cracked, 0 left
```

En este ejemplo, la contraseña recuperada es `1234`.

**Flujo de trabajo:**

```
ZIP protegido
     |
     v
  zip2john
     |
     v
   zip.hash
     |
     v
John + wordlist
     |
     v
Contraseña recuperada
```

## 4. Descifrar archivos GZIP cifrados con OpenSSL

Un archivo puede estar cifrado aunque su extensión no indique claramente que está protegido por contraseña.

Para identificar el formato real, utilizamos `file`.

### Paso 1. Identificar el archivo

```
file GZIP.gzip
```

Ejemplo de resultado:

```
GZIP.gzip: openssl enc'd data with salted password
```

Esto indica que el archivo contiene datos cifrados mediante OpenSSL.

### Paso 2. Probar contraseñas con una wordlist

En el ejemplo del módulo, se utiliza un bucle para probar cada contraseña de `rockyou.txt`, descifrar el archivo y extraer su contenido si el resultado es válido.

```
for i in $(cat rockyou.txt); do
    openssl enc -aes-256-cbc -d -in GZIP.gzip -k "$i" 2>/dev/null | tar xz
done
```

**Funcionamiento:**

- `for i in $(cat rockyou.txt)`: recorre las contraseñas de la lista.
    
- `openssl enc -aes-256-cbc -d`: intenta descifrar el archivo con AES-256-CBC.
    
- `-in GZIP.gzip`: especifica el archivo cifrado.
    
- `-k "$i"`: utiliza la contraseña actual.
    
- `2>/dev/null`: oculta los errores de OpenSSL.
    
- `tar xz`: intenta descomprimir y extraer el contenido recibido.
    

Si la contraseña es correcta y los datos resultantes tienen el formato esperado, el archivo puede extraerse.

Comprobar los archivos del directorio actual:

```
ls -la
```

**Importante:** este procedimiento puede generar muchos errores mientras prueba contraseñas incorrectas. Además, no es un método universal para todos los archivos cifrados con OpenSSL: depende del algoritmo, del formato del contenido y del método de empaquetado utilizado.

## 5. Descifrar unidades BitLocker

**BitLocker** es una tecnología de Microsoft para cifrar unidades de almacenamiento completas. Utiliza AES con claves de 128 o 256 bits.

Para recuperar el acceso a un volumen, podemos utilizar:

- La contraseña de BitLocker.
    
- La clave de recuperación, una cadena de 48 dígitos generada durante la configuración.
    

La clave de recuperación suele ser difícil de adivinar porque se genera aleatoriamente.

### Paso 1. Extraer los hashes

```
bitlocker2john -i Backup.vhd > backup.hashes
```

Este comando extrae los hashes del archivo de disco virtual.

### Paso 2. Seleccionar el hash de contraseña

```
grep 'bitlocker\$0' backup.hashes > backup.hash
```

El módulo se centra en el primer tipo de hash, identificado por el prefijo `$bitlocker$0$...`.

### Paso 3. Crackear con Hashcat

```
hashcat -a 0 -m 22100 backup.hash /usr/share/wordlists/rockyou.txt
```

**Parámetros:**

- `-a 0`: ataque de diccionario.
    
- `-m 22100`: modo de hash correspondiente a BitLocker.
    
- `backup.hash`: hash que se va a atacar.
    
- `/usr/share/wordlists/rockyou.txt`: lista de contraseñas.
    

El proceso puede ser lento debido al coste computacional de la protección criptográfica de BitLocker.

### Paso 4. Consultar los resultados

```
hashcat -m 22100 backup.hash --show
```

Ejemplo de contraseña recuperada en el módulo:

```
1234qwer
```

**Nota:** la contraseña del ejemplo no es una contraseña universal. Debemos utilizar el hash extraído del volumen que estamos analizando.

## 6. Montar una unidad BitLocker en Windows

Cuando tenemos un archivo de disco virtual `.vhd` cifrado con BitLocker, podemos acceder a él desde Windows.

Procedimiento descrito en el módulo:

1. Haz doble clic en el archivo `.vhd` para montarlo.
    
2. Abre el volumen correspondiente desde el Explorador de archivos.
    
3. Windows solicitará la contraseña de BitLocker.
    
4. Introduce la contraseña recuperada para desbloquear la unidad.

## 7. Montar una unidad BitLocker en Linux

En Linux podemos utilizar `dislocker` para acceder a volúmenes BitLocker.

### Paso 1. Instalar Dislocker

```
sudo apt-get install dislocker
```

### Paso 2. Crear los directorios de montaje

```
sudo mkdir -p /media/bitlocker
sudo mkdir -p /media/bitlockermount
```

- `/media/bitlocker`: directorio donde Dislocker expondrá el contenido descifrado.
    
- `/media/bitlockermount`: directorio donde montaremos el sistema de archivos.
    

### Paso 3. Asociar el archivo VHD a un dispositivo de bucle

```
sudo losetup -f -P Backup.vhd
```

Este comando asocia el archivo de disco virtual con un dispositivo loop y detecta sus particiones.

**Importante:** el módulo utiliza `/dev/loop0p2` en el siguiente paso. Comprueba qué dispositivo se ha asignado realmente en tu sistema.

### Paso 4. Descifrar el volumen con Dislocker

```
sudo dislocker /dev/loop0p2 -u'1234qwer' -- /media/bitlocker
```

- `/dev/loop0p2`: partición BitLocker del ejemplo.
    
- `-u`: proporciona la contraseña de BitLocker.
    
- `/media/bitlocker`: directorio donde Dislocker expondrá el archivo descifrado.
    

Sustituye la contraseña y el dispositivo por los valores correspondientes a tu caso.

### Paso 5. Montar el sistema de archivos descifrado

```
sudo mount -o loop /media/bitlocker/dislocker-file /media/bitlockermount
```

### Paso 6. Acceder al contenido

```
cd /media/bitlockermount/
ls -la
```

Ahora podemos examinar los archivos del volumen.

### Paso 7. Desmontar la unidad

```
sudo umount /media/bitlockermount
sudo umount /media/bitlocker
```

Si configuramos un dispositivo loop manualmente, podemos consultar su asignación con `losetup -a` y liberarlo después de desmontar el volumen:

```
sudo losetup -d /dev/loop0
```

Utiliza el dispositivo que corresponda al archivo VHD y asegúrate de que ya no está en uso.

## 9. Puntos clave para el CPTS

- Identifica el formato real de un archivo con `file`; la extensión puede ser engañosa.
    
- Los archivos ZIP protegidos permiten extraer hashes mediante `zip2john`.
    
- Los archivos cifrados con OpenSSL pueden requerir probar contraseñas directamente contra el proceso de descifrado.
    
- `bitlocker2john` extrae varios hashes de un volumen BitLocker; el módulo se centra en `$bitlocker$0$...`.
    
- El modo de Hashcat utilizado para ese hash de BitLocker es `-m 22100`.
    
- Las contraseñas recuperadas pueden permitir acceder a documentos o volúmenes con información sensible.
    
- En Linux, `dislocker` permite exponer el contenido de un volumen BitLocker para montarlo y examinarlo.
    
- **Diferencia importante:** extraer un hash, recuperar una contraseña, descifrar un volumen y montar un sistema de archivos son pasos distintos.
    
- Una contraseña robusta puede resultar inviable de recuperar mediante un ataque de diccionario en un tiempo razonable.
