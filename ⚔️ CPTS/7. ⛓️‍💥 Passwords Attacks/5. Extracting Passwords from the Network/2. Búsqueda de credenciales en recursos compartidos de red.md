
## 1. Objetivo

Los recursos compartidos SMB pueden contener credenciales, contraseñas, tokens, claves y archivos de configuración sensibles.

El objetivo es **enumerar los recursos compartidos accesibles y buscar archivos o contenido que pueda revelar credenciales**.

### Patrones y archivos interesantes

Buscar palabras clave como:

- `passw`, `password`
    
- `user`, `username`
    
- `token`, `key`, `secret`
    
- `cred`, `config`, `initial`
    
- Nombres de dominio, por ejemplo `INLANEFREIGHT\`
    

Extensiones interesantes:

- `.ini`, `.cfg`, `.env`
    
- `.xlsx`
    
- `.ps1`, `.bat`
    

**Consejos:**

- Priorizar recursos compartidos de departamentos de TI y administración.
    
- Adaptar las palabras clave al idioma de la organización.
    
- Revisar manualmente los resultados: las herramientas pueden generar falsos positivos.
    
- Buscar tanto en los nombres de los archivos como en su contenido.

## 2. Búsqueda desde Windows

### Snaffler

Herramienta escrita en C# que permite descubrir recursos compartidos accesibles en un dominio y buscar archivos potencialmente sensibles.

**Ejecución básica:**

```
Snaffler.exe -s
```

Si no se especifican equipos ni rutas, Snaffler intenta descubrir recursos DFS y equipos del dominio para localizar recursos compartidos legibles.

Puede detectar archivos como `unattend.xml`, que podrían contener contraseñas de instalación de Windows.

**Parámetros importantes:**

|Parámetro|Función|
|---|---|
|`-s`|Ejecuta el análisis en el modo mostrado en el módulo.|
|`-u`|Obtiene usuarios de Active Directory y busca referencias a ellos en los archivos.|
|`-i`|Permite especificar recursos compartidos que se incluirán en la búsqueda.|
|`-n`|Permite especificar recursos compartidos que se excluirán de la búsqueda.|

**Importante:** revisa los resultados y comprueba si las coincidencias contienen información sensible real.

### PowerHuntShares

Script de PowerShell que permite enumerar recursos SMB, analizar sus permisos y detectar exposiciones potencialmente peligrosas.

No necesita ejecutarse necesariamente desde un equipo unido al dominio.

**Ejecución básica:**

```
Invoke-HuntSMBShares -Threads 100 -OutputDirectory C:\Users\Public
```

**Funciones principales:**

- Descubre equipos del dominio.
    
- Comprueba la conectividad y el puerto TCP 445.
    
- Enumera recursos compartidos SMB.
    
- Analiza los permisos de los recursos.
    
- Identifica accesos de lectura y escritura.
    
- Detecta recursos con permisos excesivos o riesgos potenciales.
    
- Genera informes HTML y archivos CSV para analizar los resultados.
    

**Importante:** en entornos grandes, el análisis puede tardar horas.

## 3. Búsqueda desde Linux

### MANSPIDER

Permite buscar archivos y contenido de forma remota en recursos compartidos SMB desde Linux. Se recomienda utilizar Docker para evitar problemas de dependencias.

**Ejemplo: buscar archivos que contengan** `**passw**`**:**

```
docker run --rm \
  -v ./manspider:/root/.manspider \
  blacklanternsecurity/manspider \
  10.129.234.121 \
  -c 'passw' \
  -u 'mendres' \
  -p 'Inlanefreight2025!'
```

**Parámetros:**

|Parámetro|Función|
|---|---|
|IP|Equipo objetivo que se analizará.|
|`-c`|Cadena que se buscará en el contenido de los archivos.|
|`-u`|Usuario para autenticarse.|
|`-p`|Contraseña para autenticarse.|
|`-v`|Puede utilizarse para mostrar información adicional, según la versión.|

Por defecto, el ejemplo mostrado limita el tamaño de los archivos analizados a 10 MB y utiliza cinco hilos.

Los archivos coincidentes se descargan en el directorio `loot` de MANSPIDER dentro del contenedor.

### NetExec

NetExec permite enumerar y buscar contenido en recursos SMB utilizando la opción `--spider`.

**Ejemplo: buscar** `**passw**` **en el recurso compartido** `**IT**`**:**

```
nxc smb 10.129.234.121 \
  -u mendres \
  -p 'Inlanefreight2025!' \
  --spider IT \
  --content \
  --pattern "passw"
```

**Parámetros importantes:**

|Parámetro|Función|
|---|---|
|`smb`|Selecciona el protocolo SMB.|
|`-u`|Usuario.|
|`-p`|Contraseña.|
|`--spider IT`|Analiza el recurso compartido `IT`.|
|`--content`|Busca dentro del contenido de los archivos.|
|`--pattern "passw"`|Especifica el patrón que se buscará.|

Puedes adaptar el recurso compartido y el patrón a los resultados obtenidos durante la enumeración.

## 4. Flujo de trabajo recomendado

1. **Enumerar los recursos compartidos SMB** accesibles con las credenciales disponibles.
    
2. **Priorizar los recursos interesantes**, especialmente los utilizados por TI y administración.
    
3. **Buscar archivos sospechosos** por nombre y extensión: `.ini`, `.cfg`, `.env`, `.ps1`, `.bat`, entre otros.
    
4. **Buscar palabras clave** como `passw`, `token`, `secret`, `key` y `cred`.
    
5. **Automatizar la búsqueda** con Snaffler, PowerHuntShares, MANSPIDER o NetExec.
    
6. **Revisar manualmente los resultados** para descartar falsos positivos.
    
7. **Identificar y validar las credenciales encontradas** dentro del entorno autorizado.
    
8. **Documentar los hallazgos**, indicando el recurso, el archivo y el tipo de información sensible expuesta.

## 5. Comparativa de herramientas

|Herramienta|Plataforma|Uso principal|
|---|---|---|
|Snaffler|Windows|Descubrimiento de recursos compartidos y búsqueda de archivos interesantes en un dominio.|
|PowerHuntShares|Windows|Enumeración SMB, análisis de permisos e informes HTML/CSV.|
|MANSPIDER|Linux|Búsqueda remota de contenido en archivos compartidos mediante SMB.|
|NetExec|Linux|Enumeración SMB y búsqueda de patrones en el contenido de los archivos.|

## 6. Puntos clave para CPTS/OSCP

- Los recursos compartidos SMB pueden exponer credenciales sin necesidad de explotar una vulnerabilidad.
    
- **Enumerar los permisos es tan importante como buscar contraseñas:** un recurso con escritura también puede representar un riesgo.
    
- Los archivos de configuración, scripts y archivos de instalación desatendida son objetivos interesantes.
    
- Utiliza herramientas automáticas para acelerar la búsqueda, pero inspecciona las coincidencias manualmente.
    
- Adapta las palabras clave al dominio, los usuarios y el idioma de la organización.
    
- Prioriza los recursos relevantes para reducir el tiempo de análisis.
    
- Distingue entre credenciales válidas, información sensible y simples falsos positivos.
