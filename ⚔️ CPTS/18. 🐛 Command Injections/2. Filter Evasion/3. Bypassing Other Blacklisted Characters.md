
## 1. Introducción

Además de los operadores de inyección y los espacios, las aplicaciones pueden bloquear otros caracteres, especialmente:

- `/`: barra utilizada para especificar directorios en Linux.
    
- `\`: barra invertida utilizada en rutas de Windows y en otros contextos.
    

Para evadir estos filtros, podemos **generar los caracteres necesarios mediante variables de entorno o desplazamientos de caracteres**, sin escribirlos directamente en el payload.

## 2. Linux: generar caracteres mediante variables de entorno

En Linux, podemos utilizar variables de entorno para obtener caracteres específicos de una cadena mediante la expansión de parámetros de Bash.

### 2.1. Obtener una barra `/` con `$PATH`

La variable `$PATH` suele contener rutas separadas por dos puntos.

Ejemplo:

```
echo ${PATH}
```

Salida posible:

```
/usr/local/bin:/usr/bin:/bin:/usr/games
```

Podemos seleccionar el primer carácter de la variable:

```
echo ${PATH:0:1}
```

Resultado:

```
/
```

**Sintaxis:**

```
${VARIABLE:inicio:longitud}
```

- `VARIABLE`: variable de entorno que contiene la cadena.
    
- `inicio`: posición desde la que comenzamos a extraer.
    
- `longitud`: número de caracteres que queremos obtener.
    

En un payload, no es necesario utilizar `echo`: la expansión de la variable genera directamente el carácter.

### 2.2. Obtener un punto y coma `;` con `$LS_COLORS`

También podemos obtener un carácter de una variable de entorno que lo contenga.

Ejemplo:

```
echo ${LS_COLORS:10:1}
```

En el entorno del laboratorio, devuelve:

```
;
```

La posición exacta depende del contenido de la variable `LS_COLORS`, que puede variar entre sistemas.

Para buscar variables útiles, podemos ejecutar:

```
printenv
```

Este comando muestra las variables de entorno disponibles.

### 2.3. Combinar caracteres generados

El material presenta el siguiente payload:

```
127.0.0.1${LS_COLORS:10:1}${IFS}
```

En el entorno del ejercicio, las expansiones generan:

- `${LS_COLORS:10:1}` → `;`
    
- `${IFS}` → caracteres separadores, normalmente espacios, tabuladores y saltos de línea.
    

Así, podemos construir un payload sin escribir directamente el punto y coma ni un espacio literal.

**Importante:** las expansiones deben realizarse en un shell compatible con esta sintaxis y las variables deben contener los caracteres esperados.

## 3. Windows: generar caracteres mediante variables de entorno

El mismo principio puede aplicarse en Windows, aunque la sintaxis depende de la consola utilizada.

### 3.1. Windows CMD

Podemos extraer una parte de una variable de entorno utilizando la expansión de variables con posiciones.

Ejemplo:

```
echo %HOMEPATH:~6,-11%
```

En el entorno mostrado por HTB Academy, el resultado es:

```
\
```

**Sintaxis general:**

```
%VARIABLE:~inicio,longitud%
```

En este caso, la expresión utiliza una posición inicial y una longitud negativa para seleccionar la barra invertida de la ruta.

El resultado depende del contenido de `HOMEPATH`.

### 3.2. PowerShell

En PowerShell, podemos acceder a los caracteres de una variable de entorno mediante índices.

Ejemplo:

```
$env:HOMEPATH[0]
```

Resultado en el entorno del laboratorio:

```
\
```

Otro ejemplo del material:

```
$env:PROGRAMFILES[10]
```

En el entorno mostrado no devuelve ningún carácter visible, lo que demuestra que hay que comprobar el contenido y los índices antes de utilizar una variable.

Para enumerar las variables de entorno disponibles:

```
Get-ChildItem Env:
```

Después, podemos identificar una variable que contenga el carácter que necesitamos y seleccionar su posición.

## 4. Generar caracteres mediante desplazamiento ASCII

Otra técnica consiste en transformar un carácter en otro mediante un desplazamiento.

En el ejemplo de HTB Academy se utiliza `tr` en Linux para desplazar caracteres una posición dentro de un rango ASCII.

### Ejemplo: obtener `\`

El carácter `\` tiene el valor ASCII decimal `92`. El carácter anterior es `[` (`91`).

Podemos generar la barra invertida utilizando:

```
echo $(tr '!-}' '"-~'<<<[)
```

Resultado:

```
\
```

La idea es introducir el carácter anterior al que necesitamos y utilizar `tr` para transformarlo en el siguiente carácter del rango.

Para consultar los valores ASCII:

```
man ascii
```

**Importante:** esta técnica depende de los rangos de caracteres y de la transformación aplicada. No debe asumirse que cualquier carácter se puede generar con la misma expresión sin adaptarla.

### Ejercicio: generar un punto y coma

Para obtener `;` mediante un desplazamiento de una posición:

1. Consulta su valor en la tabla ASCII.
    
2. Identifica el carácter inmediatamente anterior.
    
3. Sustituye `[` en el ejemplo por ese carácter.
    
4. Comprueba el resultado.
    

El carácter anterior a `;` es `:`.

## 5. Tabla resumen

|Técnica|Sistema|Objetivo|
|---|---|---|
|`${PATH:0:1}`|Linux/Bash|Obtener `/` en el entorno habitual del ejemplo.|
|`${LS_COLORS:10:1}`|Linux/Bash|Obtener `;` si la variable contiene ese carácter en dicha posición.|
|`${IFS}`|Linux/shell|Generar separadores sin escribir un espacio literal.|
|`%HOMEPATH:~6,-11%`|Windows CMD|Extraer `\` en el entorno del laboratorio.|
|`$env:HOMEPATH[0]`|PowerShell|Acceder a un carácter concreto de una variable de entorno.|
|`Get-ChildItem Env:`|PowerShell|Enumerar las variables de entorno.|
|`tr` y ASCII|Linux|Generar un carácter mediante el desplazamiento de otro.|

## 6. Procedimiento para el laboratorio

1. Identifica qué carácter está bloqueando el filtro.
    
2. Comprueba si alguna variable de entorno contiene ese carácter.
    
3. Utiliza la expansión de parámetros para extraerlo.
    
4. Si no encuentras una variable adecuada, consulta la tabla ASCII y considera el desplazamiento de caracteres.
    
5. Comprueba el resultado en el shell correspondiente.
    
6. Prueba la técnica en el laboratorio y verifica si la aplicación acepta el payload.
    

## Chuleta para el examen

- **Linux/Bash:** `${VARIABLE:inicio:longitud}` extrae una parte de una variable.
    
- **Windows CMD:** `%VARIABLE:~inicio,longitud%` permite extraer una parte de una variable.
    
- **PowerShell:** `$env:VARIABLE[indice]` permite acceder a un carácter por su posición.
    
- **Enumeración:** `printenv` en Linux y `Get-ChildItem Env:` en PowerShell.
    
- **Desplazamiento ASCII:** transforma un carácter en otro mediante una operación sobre rangos.
    
- **Idea principal:** los filtros basados únicamente en caracteres literales pueden ser insuficientes si no contemplan las formas alternativas de generar esos caracteres.
