
## 📌 Concepto

El **Website Defacing** consiste en modificar la apariencia de una página web para mostrar un mensaje o diseño diferente al original.

Una de las formas de conseguirlo es mediante **Stored XSS**, inyectando código JavaScript que se almacena en la aplicación y se ejecuta cuando los usuarios visitan la página.

El defacing puede utilizarse para mostrar mensajes que indiquen que una web ha sido comprometida.

### Elementos HTML que podemos modificar

|Elemento|Propiedad JavaScript|Función|
|---|---|---|
|Color de fondo|`document.body.style.background`|Cambia el color de fondo.|
|Imagen de fondo|`document.body.background`|Establece una imagen de fondo.|
|Título|`document.title`|Cambia el título de la pestaña.|
|Contenido HTML|`DOM.innerHTML`|Modifica el contenido HTML de un elemento.|

---

## 🎨 1. Cambiar el color de fondo

Podemos modificar el fondo de la página utilizando la propiedad `document.body.style.background`.

### Payload

```
<script>document.body.style.background = "#141d2b"</script>
```

Este código cambia el fondo de la página al color hexadecimal `#141d2b`.

Podemos utilizar otros colores, por ejemplo:

```
document.body.style.background = "black";
```

### Utilizar una imagen de fondo

También podemos establecer una imagen como fondo:

```
<script>document.body.background = "https://www.hackthebox.eu/images/logo-htb.svg"</script>
```

**Importante:** el recurso debe ser accesible desde el navegador y el comportamiento puede variar según el navegador y la aplicación.

Si utilizamos Stored XSS, el código almacenado puede volver a ejecutarse cuando otros usuarios visiten la página vulnerable.

---

## 🏷️ 2. Cambiar el título de la página

La propiedad `document.title` permite modificar el título que aparece en la pestaña del navegador.

### Payload

```
<script>document.title = 'HackTheBox Academy'</script>
```

El título original será sustituido por `HackTheBox Academy` cuando se ejecute el código.

**Uso práctico:** permite modificar el título visible de la página sin tener que cambiar directamente el código del servidor.

---

## 📝 3. Cambiar el contenido de un elemento

Podemos utilizar `innerHTML` para modificar el contenido HTML de un elemento específico.

### JavaScript

```
document.getElementById("todo").innerHTML = "New Text";
```

Este código:

1. Busca el elemento cuyo identificador es `todo`.
    
2. Sustituye su contenido por `New Text`.
    

### Utilizando jQuery

Si la página ha cargado la biblioteca jQuery, podemos hacer lo mismo con:

```
$("#todo").html("New Text");
```

Ambos ejemplos sustituyen el contenido del elemento seleccionado.

---

## 🖥️ 4. Sustituir el contenido completo de la página

Para reemplazar el contenido del elemento `body`, podemos utilizar:

```
document.getElementsByTagName('body')[0].innerHTML = "New Text";
```

### ¿Qué hace cada parte?

|Código|Función|
|---|---|
|`document.getElementsByTagName('body')`|Obtiene los elementos `body` del documento.|
|`[0]`|Selecciona el primer elemento de la colección.|
|`.innerHTML`|Permite establecer el contenido HTML del elemento.|
|`"New Text"`|Es el contenido que se mostrará.|

Al sustituir el contenido completo del `body`, los elementos anteriores dejan de aparecer en la página, aunque eso no significa que se hayan eliminado del servidor.

## 🧪 5. Crear un diseño HTML personalizado

Antes de incorporar HTML a un payload, podemos preparar el contenido por separado y comprobar cómo se representa en el navegador.

Ejemplo del módulo:

```
<center>
    <h1 style="color: white">Cyber Security Training</h1>
    <p style="color: white">by
        <img src="https://academy.hackthebox.com/images/logo-htb.svg"
             height="25px"
             alt="HTB Academy">
    </p>
</center>
```

Este fragmento muestra:

- Un encabezado con el texto `Cyber Security Training`.
    
- Un texto secundario con `by`.
    
- Una imagen del logotipo de HTB Academy.
    

### Integrar el HTML en JavaScript

Para insertar el contenido mediante `innerHTML`, podemos asignar el HTML como una cadena:

```
document.getElementsByTagName('body')[0].innerHTML =
    '<center><h1 style="color: white">Cyber Security Training</h1><p style="color: white">by <img src="https://academy.hackthebox.com/images/logo-htb.svg" height="25px" alt="HTB Academy"></p></center>';
```

En el laboratorio, este código se incorpora a un payload XSS y se ejecuta al visitar la página vulnerable.

**Consejo:** cuando el HTML se incluye dentro de una cadena JavaScript, hay que prestar atención a las comillas para evitar errores de sintaxis.

## ⚡ 6. Flujo práctico del laboratorio

En el ejercicio de Stored XSS, el proceso es el siguiente:

1. Iniciar el laboratorio vulnerable.
    
2. Identificar el campo de entrada vulnerable.
    
3. Comprobar que la aplicación permite ejecutar JavaScript.
    
4. Probar la modificación del fondo.
    
5. Probar el cambio del título.
    
6. Preparar el contenido HTML que se quiere mostrar.
    
7. Utilizar `innerHTML` para sustituir el contenido visible.
    
8. Recargar la página para comprobar si los cambios vuelven a aplicarse.
    

En el ejemplo del módulo se utilizan tres modificaciones:

- Cambiar el fondo.
    
- Cambiar el título.
    
- Sustituir el contenido del `body`.
    

Como se trata de Stored XSS, los cambios pueden reaparecer al cargar la página mientras el payload siga almacenado y se ejecute correctamente.

### ¿Por qué puede seguir existiendo el HTML original?

El JavaScript modifica el DOM cuando se ejecuta en el navegador. Esto no implica que el código original del servidor haya sido sustituido.

Por tanto, pueden darse dos situaciones distintas:

- **Código fuente original:** sigue siendo el que entrega el servidor.
    
- **DOM renderizado:** puede haber sido modificado por JavaScript después de cargar la página.
    

El momento en que se ejecuta el payload también puede afectar al resultado, porque otros scripts podrían ejecutarse después y modificar nuevamente el contenido.

### Conceptos clave

- **Defacing:** modificación de la apariencia visible de una página web.
    
- **Stored XSS:** permite que el payload almacenado se ejecute en las visitas posteriores.
    
- `**document.body.style.background**`**:** cambia el color de fondo.
    
- `**document.body.background**`**:** establece una imagen de fondo.
    
- `**document.title**`**:** cambia el título de la pestaña.
    
- `**innerHTML**`**:** modifica el contenido HTML de un elemento.
    
- **DOM:** estructura de la página que JavaScript puede modificar.
    
- **Persistencia:** depende de que el payload siga almacenado y se ejecute; cambiar la apariencia del navegador no modifica por sí solo el contenido guardado en el backend.
