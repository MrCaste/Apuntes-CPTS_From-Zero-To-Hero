
## 1. Operadores lógicos

SQL permite combinar varias condiciones mediante operadores lógicos. Los más comunes son:

- `AND`: ambas condiciones deben ser verdaderas.
    
- `OR`: al menos una condición debe ser verdadera.
    
- `NOT`: invierte el resultado lógico.
    

En MySQL, normalmente `1` representa `TRUE` y `0` representa `FALSE`.

## 2. Operador `AND`

Devuelve `TRUE` únicamente cuando **las dos condiciones son verdaderas**.

```
SELECT 1 = 1 AND 'test' = 'test';
```

Resultado: `1` (`TRUE`), porque ambas condiciones son verdaderas.

```
SELECT 1 = 1 AND 'test' = 'abc';
```

Resultado: `0` (`FALSE`), porque la segunda condición es falsa.

**Tabla de verdad:**

|Condición 1|Condición 2|Resultado|
|---|---|---|
|TRUE|TRUE|TRUE|
|TRUE|FALSE|FALSE|
|FALSE|TRUE|FALSE|
|FALSE|FALSE|FALSE|

## 3. Operador `OR`

Devuelve `TRUE` cuando **al menos una de las condiciones es verdadera**.

```
SELECT 1 = 1 OR 'test' = 'abc';
```

Resultado: `1` (`TRUE`), porque la primera condición es verdadera.

```
SELECT 1 = 2 OR 'test' = 'abc';
```

Resultado: `0` (`FALSE`), porque ambas condiciones son falsas.

**Tabla de verdad:**

|Condición 1|Condición 2|Resultado|
|---|---|---|
|TRUE|TRUE|TRUE|
|TRUE|FALSE|TRUE|
|FALSE|TRUE|TRUE|
|FALSE|FALSE|FALSE|

## 4. Operador `NOT`

Invierte el resultado de una condición:

- `NOT TRUE` → `FALSE`
    
- `NOT FALSE` → `TRUE`
    

Ejemplos:

```
SELECT NOT 1 = 1;
```

Resultado: `0` (`FALSE`).

```
SELECT NOT 1 = 2;
```

Resultado: `1` (`TRUE`).

## 5. Operadores simbólicos

En MySQL también podemos encontrar representaciones simbólicas de algunos operadores lógicos:

|Operador|Símbolo|Función|
|---|---|---|
|`AND`|`&&`|Ambas condiciones deben ser verdaderas.|
|`OR`|`||`|Al menos una condición debe ser verdadera.|
|`NOT`|`!`|Invierte el resultado lógico.|
|Distinto de|`!=`|Comprueba si dos valores son diferentes.|

Ejemplos:

```
SELECT 1 = 1 && 'test' = 'abc';
```

Resultado: `0`.

```
SELECT 1 = 1 || 'test' = 'abc';
```

Resultado: `1`.

```
SELECT 1 != 1;
```

Resultado: `0`, porque ambos valores son iguales.

**Nota:** en los ejemplos de HTB, MySQL muestra advertencias al utilizar `&&` y `||`. Para mayor claridad, es habitual utilizar `AND` y `OR`.

## 6. Operadores dentro de consultas SQL

Podemos utilizar los operadores lógicos en `WHERE` para filtrar registros.

### Excluir un usuario con `!=`

```
SELECT * FROM logins WHERE username != 'john';
```

Devuelve todos los registros cuyo nombre de usuario no sea `john`.

### Combinar condiciones con `AND`

```
SELECT * FROM logins
WHERE username != 'john' AND id > 1;
```

Devuelve los registros que cumplen **ambas condiciones**:

1. El nombre de usuario no es `john`.
    
2. El identificador es mayor que `1`.
    

### Resumen

```
-- Una condición
SELECT * FROM logins WHERE id > 1;

-- Dos condiciones que deben cumplirse
SELECT * FROM logins WHERE id > 1 AND username != 'john';

-- Al menos una condición debe cumplirse
SELECT * FROM logins WHERE id > 1 OR username = 'john';

-- Invertir una condición
SELECT * FROM logins WHERE NOT username = 'john';
```

## 7. Precedencia de operadores

Cuando una consulta contiene varias operaciones, SQL las evalúa siguiendo un orden de precedencia.

Según el orden presentado en esta sección de HTB Academy, de mayor a menor prioridad:

1. **División (**`**/**`**), multiplicación (**`*****`**) y módulo (**`**%**`**).**
    
2. **Suma (**`**+**`**) y resta (**`**-**`**).**
    
3. **Comparaciones (**`**=**`**,** `**>**`**,** `**<**`**,** `**<=**`**,** `**>=**`**,** `**!=**`**,** `**LIKE**`**).**
    
4. `**NOT**` **(**`**!**`**).**
    
5. `**AND**` **(**`**&&**`**).**
    
6. `**OR**` **(**`**||**`**).**
    

Las operaciones que aparecen antes se evalúan primero.

### Ejemplo práctico

```
SELECT * FROM logins
WHERE username != 'tom' AND id > 3 - 2;
```

**Paso 1. Evaluar la resta**

La resta tiene mayor precedencia que las comparaciones y los operadores lógicos:

```
SELECT * FROM logins
WHERE username != 'tom' AND id > 1;
```

**Paso 2. Evaluar las comparaciones**

Se comprueban las condiciones:

- `username != 'tom'`
    
- `id > 1`
    

**Paso 3. Aplicar** `**AND**`

Solo se devuelven los registros que cumplen ambas condiciones.

En el ejemplo de HTB, los resultados corresponden a los usuarios `administrator` y `john`.

## 8. Chuleta rápida

|Operador|Significado|Ejemplo|
|---|---|---|
|`AND`|Ambas condiciones verdaderas|`WHERE id > 1 AND username = 'admin'`|
|`OR`|Al menos una condición verdadera|`WHERE id = 1 OR id = 2`|
|`NOT`|Invierte una condición|`WHERE NOT username = 'john'`|
|`!=`|Distinto de|`WHERE username != 'john'`|
|`>`|Mayor que|`WHERE id > 1`|
|`<`|Menor que|`WHERE id < 4`|
|`>=`|Mayor o igual que|`WHERE id >= 2`|
|`<=`|Menor o igual que|`WHERE id <= 3`|
|`LIKE`|Coincidencia con un patrón|`WHERE username LIKE 'admin%'`|

## 9. Aplicación en SQL Injection

Estos operadores son importantes para comprender cómo las condiciones de una consulta pueden afectar a los resultados.

- `**AND**`: exige que todas las condiciones sean verdaderas.
    
- `**OR**`: permite que una condición verdadera sea suficiente.
    
- `**NOT**`: invierte el resultado de una condición.
    
- `**!=**`: permite excluir valores concretos.
    
- **La precedencia**: determina cómo se evalúan las condiciones cuando una consulta combina varios operadores.
    

Al analizar una posible SQL Injection, es importante entender cómo se combinan las condiciones originales de la consulta y cómo se evalúan sus operadores.
