
## 1. INSERT — Insertar registros

La sentencia `INSERT` permite añadir nuevos registros a una tabla.

### Insertar un registro con todas las columnas

```
INSERT INTO logins VALUES (1, 'admin', 'p@ssw0rd', '2020-07-02');
```

Esta sintaxis requiere proporcionar los valores correspondientes a todas las columnas de la tabla, en el orden definido.

### Insertar valores en columnas específicas

```
INSERT INTO logins(username, password)
VALUES ('administrator', 'adm1n_p@ss');
```

Al especificar las columnas, podemos omitir aquellas que no necesitan un valor explícito, por ejemplo, si tienen `AUTO_INCREMENT` o un valor `DEFAULT`.

**Importante:** omitir una columna obligatoria que no admita `NULL` ni tenga un valor predeterminado puede provocar un error.

### Insertar varios registros

```
INSERT INTO logins(username, password)
VALUES
    ('john', 'john123!'),
    ('tom', 'tom123!');
```

Permite insertar varios registros en una sola consulta.

> **Nota de seguridad:** las contraseñas no deben almacenarse en texto plano. Deben protegerse mediante un mecanismo adecuado de hash de contraseñas.

## 2. SELECT — Consultar registros

La sentencia `SELECT` permite recuperar información de una tabla.

### Seleccionar todas las columnas

```
SELECT * FROM logins;
```

- `SELECT`: indica qué datos queremos recuperar.
    
- `*`: selecciona todas las columnas.
    
- `FROM`: indica la tabla de origen.
    

### Seleccionar columnas específicas

```
SELECT username, password FROM logins;
```

Devuelve únicamente las columnas `username` y `password`.

**Diferencia principal:**

```
SELECT * FROM logins;
```

Recupera todas las columnas.

```
SELECT username, password FROM logins;
```

Recupera solamente las columnas indicadas.

## 3. DROP — Eliminar tablas o bases de datos

La sentencia `DROP` elimina objetos de la base de datos.

### Eliminar una tabla

```
DROP TABLE logins;
```

La tabla se elimina completamente, incluida su estructura y sus datos.

### Comprobar las tablas existentes

```
SHOW TABLES;
```

Si `logins` era la única tabla de la base de datos, después de eliminarla no aparecerá ninguna.

**Importante:** `DROP TABLE` es una operación destructiva. No debe confundirse con eliminar registros individuales.

---

## 4. ALTER — Modificar la estructura de una tabla

La sentencia `ALTER TABLE` permite modificar la estructura de una tabla existente.

### Añadir una columna

```
ALTER TABLE logins ADD newColumn INT;
```

Añade una columna llamada `newColumn` de tipo entero.

### Renombrar una columna

```
ALTER TABLE logins
RENAME COLUMN newColumn TO newerColumn;
```

Cambia el nombre de `newColumn` a `newerColumn`.

### Modificar el tipo de dato

```
ALTER TABLE logins
MODIFY newerColumn DATE;
```

Cambia el tipo de dato de `newerColumn` a `DATE`.

### Eliminar una columna

```
ALTER TABLE logins DROP newerColumn;
```

Elimina la columna de la tabla.

### Resumen de ALTER

|Operación|Sintaxis|Función|
|---|---|---|
|Añadir|`ADD`|Incorpora una columna.|
|Renombrar|`RENAME COLUMN`|Cambia el nombre de una columna.|
|Modificar|`MODIFY`|Cambia la definición o el tipo de dato.|
|Eliminar|`DROP`|Elimina una columna.|

Estas operaciones requieren privilegios suficientes sobre la tabla.

## 5. UPDATE — Actualizar registros

La sentencia `UPDATE` modifica los valores de los registros existentes.

### Sintaxis general

```
UPDATE table_name
SET column1 = newvalue1, column2 = newvalue2
WHERE condition;
```

- `UPDATE`: especifica la tabla que se modificará.
    
- `SET`: define los nuevos valores.
    
- `WHERE`: determina qué registros se actualizarán.
    

### Ejemplo

```
UPDATE logins
SET password = 'change_password'
WHERE id > 1;
```

Actualiza la columna `password` de todos los registros cuyo `id` sea mayor que `1`.

### Comprobar los cambios

```
SELECT * FROM logins;
```

Permite consultar los registros después de la actualización.

### Importancia de WHERE

**Utiliza** `**WHERE**` **para limitar los registros que deseas modificar.**

Por ejemplo:

```
UPDATE logins
SET password = 'change_password'
WHERE id = 2;
```

Modifica únicamente el registro cuyo identificador sea `2`, si existe.

En cambio:

```
UPDATE logins
SET password = 'change_password';
```

Modifica la contraseña de **todos los registros** de la tabla, porque no hay ninguna condición que limite la actualización.

## 6. Diferencias entre las sentencias SQL

|Sentencia|Función|Ejemplo|
|---|---|---|
|`INSERT`|Añadir registros.|`INSERT INTO logins(username) VALUES ('john');`|
|`SELECT`|Consultar datos.|`SELECT * FROM logins;`|
|`UPDATE`|Modificar registros.|`UPDATE logins SET username = 'admin' WHERE id = 1;`|
|`DROP`|Eliminar una tabla u otro objeto compatible.|`DROP TABLE logins;`|
|`ALTER`|Modificar la estructura de una tabla.|`ALTER TABLE logins ADD email VARCHAR(100);`|

**Diferencia fundamental:**

- `INSERT`, `SELECT` y `UPDATE` trabajan con registros.
    
- `ALTER` modifica la estructura de la tabla.
    
- `DROP` elimina la tabla completa.

## 7. Chuleta de comandos

```
-- Insertar un registro
INSERT INTO logins(username, password)
VALUES ('john', 'john123!');

-- Insertar varios registros
INSERT INTO logins(username, password)
VALUES ('john', 'john123!'), ('tom', 'tom123!');

-- Consultar todos los datos
SELECT * FROM logins;

-- Consultar columnas específicas
SELECT username, password FROM logins;

-- Añadir una columna
ALTER TABLE logins ADD email VARCHAR(100);

-- Renombrar una columna
ALTER TABLE logins RENAME COLUMN email TO correo;

-- Modificar el tipo de una columna
ALTER TABLE logins MODIFY correo VARCHAR(200);

-- Eliminar una columna
ALTER TABLE logins DROP correo;

-- Actualizar un registro concreto
UPDATE logins SET username = 'admin' WHERE id = 1;

-- Eliminar una tabla completa
DROP TABLE logins;
```

## 8. Conceptos importantes para SQL Injection

Para continuar con el módulo, debes distinguir entre las operaciones que modifican datos y las que alteran la estructura de una tabla.

- `SELECT` recupera información.
    
- `INSERT` introduce nuevos registros.
    
- `UPDATE` modifica registros existentes.
    
- `ALTER` cambia la estructura de una tabla.
    
- `DROP` elimina tablas u otros objetos.
    

En el contexto de SQL Injection, comprender estas sentencias ayuda a reconocer qué operación está ejecutando una consulta y cómo una entrada manipulada podría alterar su comportamiento.

**Punto clave para el examen:** presta especial atención a `SELECT`, `UPDATE` y a la cláusula `WHERE`, porque determinan qué información se consulta o qué registros se modifican.
