
## 1. SQL y MySQL/MariaDB

**SQL (Structured Query Language)** es el lenguaje utilizado para interactuar con bases de datos relacionales.

Permite realizar operaciones como:

- Recuperar datos.
    
- Actualizar datos.
    
- Eliminar datos.
    
- Crear bases de datos y tablas.
    
- Añadir o eliminar usuarios.
    
- Asignar permisos.
    

**MySQL y MariaDB** son sistemas de gestión de bases de datos que utilizan SQL. La sintaxis puede variar entre distintos SGBD, por lo que en este módulo trabajaremos con MySQL/MariaDB.

---

## 2. Conectarse a MySQL desde la terminal

La herramienta `mysql` permite autenticarse e interactuar con una base de datos.

### Conexión local

```
mysql -u root -p
```

- `-u`: especifica el usuario.
    
- `-p`: solicita la contraseña de forma interactiva.
    

Es recomendable utilizar `-p` sin escribir la contraseña directamente en el comando para evitar que quede expuesta en el historial del terminal.

### Conexión a un servidor remoto

```
mysql -u root -h IP -P 3306 -p
```

|Parámetro|Función|
|---|---|
|`-u root`|Usuario con el que se intenta conectar.|
|`-h IP`|Dirección IP o nombre del servidor.|
|`-P 3306`|Puerto del servicio MySQL.|
|`-p`|Solicita la contraseña.|

**Importante:**

- El puerto predeterminado de MySQL/MariaDB es `3306`, aunque puede cambiar.
    
- `-P` mayúscula especifica el puerto.
    
- `-p` minúscula solicita la contraseña.
    
- No es recomendable escribir la contraseña directamente en el comando.
    

### Consultar los privilegios

Una vez conectado:

```
SHOW GRANTS;
```

Muestra los permisos asociados a la sesión actual.

Los privilegios disponibles determinan qué operaciones podemos realizar en la base de datos.

## 3. Crear y seleccionar bases de datos

### Mostrar las bases de datos disponibles

```
SHOW DATABASES;
```

### Crear una base de datos

```
CREATE DATABASE users;
```

### Seleccionar una base de datos

```
USE users;
```

A partir de ese momento, las consultas que dependan de la base de datos seleccionada se ejecutarán sobre `users`, salvo que se especifique otra.

### Sintaxis SQL

Las consultas ejecutadas desde la consola de MySQL deben terminar con un punto y coma:

```
SHOW DATABASES;
USE users;
```

Las palabras clave SQL no distinguen entre mayúsculas y minúsculas. Por ejemplo, `USE` y `use` representan la misma instrucción.

Sin embargo, la distinción entre mayúsculas y minúsculas en los nombres de bases de datos puede depender de la configuración y del sistema operativo. Conviene utilizar los nombres exactos.

## 4. Tablas y tipos de datos

Las bases de datos relacionales almacenan la información en tablas.

Una tabla está formada por:

- **Filas:** registros.
    
- **Columnas:** campos que almacenan información de un tipo determinado.
    
- **Celdas:** valores correspondientes a la intersección de una fila y una columna.
    

Algunos tipos de datos habituales en MySQL son:

|Tipo|Descripción|
|---|---|
|`INT`|Números enteros.|
|`VARCHAR(n)`|Cadenas de texto de longitud variable, con un máximo definido por `n`.|
|`DATETIME`|Valores de fecha y hora.|

### Crear una tabla

```
CREATE TABLE logins (
    id INT,
    username VARCHAR(100),
    password VARCHAR(100),
    date_of_joining DATETIME
);
```

Esta consulta crea la tabla `logins` con cuatro columnas:

- `id`: identificador numérico.
    
- `username`: nombre de usuario.
    
- `password`: contraseña.
    
- `date_of_joining`: fecha y hora de incorporación.
    

### Mostrar las tablas

```
SHOW TABLES;
```

Lista las tablas de la base de datos seleccionada.

### Consultar la estructura de una tabla

```
DESCRIBE logins;
```

Muestra los campos y sus tipos de datos.

Este comando es útil para conocer la estructura de una tabla antes de consultar o modificar sus datos.

## 5. Propiedades y restricciones de las tablas

MySQL permite establecer propiedades que determinan cómo se almacenan los datos y qué valores pueden introducirse.

### AUTO_INCREMENT

Incrementa automáticamente un valor numérico cuando se inserta un nuevo registro.

```
id INT NOT NULL AUTO_INCREMENT
```

Es habitual utilizarlo para generar identificadores.

### NOT NULL

Impide que una columna almacene un valor `NULL`.

```
username VARCHAR(100) NOT NULL
```

La columna debe recibir un valor no nulo.

### UNIQUE

Impide que existan valores duplicados en la columna o combinación de columnas a la que se aplica.

```
username VARCHAR(100) UNIQUE NOT NULL
```

En este ejemplo, los nombres de usuario deben ser únicos y no pueden ser `NULL`.

### DEFAULT

Establece un valor predeterminado cuando no se proporciona uno durante la inserción, siempre que se cumplan las demás restricciones.

```
date_of_joining DATETIME DEFAULT NOW()
```

En MySQL, `NOW()` devuelve la fecha y hora actuales.

### PRIMARY KEY

Define la clave primaria, que identifica de forma única cada registro de la tabla.

```
PRIMARY KEY (id)
```

Una clave primaria no admite valores duplicados ni valores `NULL`.

## 6. Ejemplo completo de creación de una tabla

```
CREATE TABLE logins (
    id INT NOT NULL AUTO_INCREMENT,
    username VARCHAR(100) UNIQUE NOT NULL,
    password VARCHAR(100) NOT NULL,
    date_of_joining DATETIME DEFAULT NOW(),
    PRIMARY KEY (id)
);
```

### Resumen de la estructura

|Columna|Tipo|Propiedades|
|---|---|---|
|`id`|`INT`|Obligatorio, autoincremental y clave primaria.|
|`username`|`VARCHAR(100)`|Obligatorio y único.|
|`password`|`VARCHAR(100)`|Obligatorio.|
|`date_of_joining`|`DATETIME`|Valor predeterminado: fecha y hora actuales.|

Esta estructura permite identificar cada registro mediante `id`, evitar nombres de usuario duplicados y asignar automáticamente la fecha de incorporación cuando no se proporciona.

```
-- Crear una tabla
CREATE TABLE logins (
    id INT NOT NULL AUTO_INCREMENT,

```

## 8. Conceptos importantes para SQL Injection

Para comprender las siguientes secciones del módulo, debes conocer:

- **Bases de datos:** contienen las tablas y otros objetos.
    
- **Tablas:** organizan los registros en filas y columnas.
    
- **Columnas:** almacenan campos como `username` y `password`.
    
- **Tipos de datos:** determinan qué clase de valores puede almacenar cada columna.
    
- **Consultas SQL:** permiten recuperar y modificar información.
    
- **Privilegios:** determinan qué operaciones puede ejecutar el usuario de la base de datos.
    
- **Estructura de las tablas:** puede consultarse mediante `DESCRIBE`.
    

Estos fundamentos permiten entender cómo interactúan las aplicaciones con MySQL/MariaDB y sirven como base para estudiar cómo una inyección SQL puede alterar una consulta construida por una aplicación.
